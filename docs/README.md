# Documentation

Start with the guide that matches your task. The public technote describes the
implemented instrument; design records also preserve experiments, decisions and
work that remains open.

- **Write scenarios:** the [English Rhai book](rhai_book/src/SUMMARY.md) and
  [Japanese Rhai book](rhai_book_ja/src/SUMMARY.md) cover the language and API.
- **Understand the implementation:** the public technote is maintained in
  [English](../web/content/technote.md) and [Japanese](../web/content/technote.ja.md).
- **Find design decisions:** the [design-note index](design-notes/README.md)
  introduces the core notes and the body-fitness registration/result records.
  The technote design ledger has a section index in
  [English](design-notes/technote-ledger.md) and
  [Japanese](design-notes/technote-ledger.ja.md).
- **Resume work:** the [current plan](roadmap/plan-current.md) defines the active
  stage; [next-session](roadmap/next-session.md) gives the next steps. Both link to
  preserved histories of earlier stages.
- **Operate and preserve evidence:** [operations](operations/) contains
  [evidence-location guidance](operations/evidence-locations.md) and
  [OOM prevention](operations/oom-prevention.md).
