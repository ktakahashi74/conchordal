# 新しい聴覚系の設計

状態：設計の草案（版 1）。実装、数値の受け入れ、作者の採用はどれも済んでいない。
作成：2026-10-23。branch `research/auditory-system-20261023`（main `a6b197d` から）。
入力：引き継ぎの版 2（`.orchestration/units/AUD-0/handoff.md`）、独立の review AUD-R1（`.orchestration/units/AUD-R1/report.md`）、SF-1 の試作の報告（`.orchestration/units/SF-1/report.md`）。引き継ぎの版 1 の数値と素案は使わない。

この文書は、H／R の前処理（今は NSGT、peak の抽出、subjective intensity）を、蝸牛の filter から始まる聴覚系に置き換える設計を書く。対象は Landscape へ入る観測の基盤であり、H／R／C の kernel、habituation、Voice と Flora の行動の規則は、§10 の判断 2 で別に決めるまで変えない。

## 0. 読み方と根拠の区別

数値と主張には、根拠の種類を付ける。

- **確認済み**：この session か AUD-R1／SF-1 が、code、記録、原典で確かめたもの。
- **導出**：式からの計算。人の測定値ではない。
- **数値実験**：`.orchestration/units/AUD-1/` の設計段の計算（定常の合成音だけ、Python）。受け入れの結果ではない。実装の受け入れは §8 の検証で行う。
- **未照合**：原典の本文で確かめていないもの。固定の閾には使わない。

## 1. 要約

**今の前処理で、遅れと H の質が引き換えになる理由。** 今の NSGT の帯域は、聴覚の filter よりずっと狭い。
- Q の上限は 80。nfft 16384 の打ち切りで、低域の窓は 341 ms になる。
- 帯域の等価雑音帯域幅（ENBW）と ERB の比は、110 Hz で約 1/6、1 kHz で約 1/5（§5.1、導出）。
- 近い成分を分ける力を、窓の長さで買っている。
- 一方、成分の周波数は power の山の bin（12.5 cent の格子）から読み、位相は捨てている。

窓の長さが「分ける力」と「位置の精度」の両方を担うので、どちらを良くしても遅れが増える。110 Hz では窓の重心だけで約 171 ms 遅れる（導出）。

**聴覚はこの二つを別の仕組みで持つ。**
- 分ける力は、蝸牛の filter の帯域（ERB）で決まる。
- filter を一つの成分が占める時、その成分の周波数は位相（時間の微細構造）が運ぶ。
- 一つの filter に入って分けられない組は、包絡のうなりとして残る。

設計はこの分担をそのまま写す。その結果は次のとおり。
- 分ける力は ERB で、人の聴覚と同じ尺度になる。
- 分けた成分の位置の精度は、窓の長さによらない。
- 遅れは filter 自身の群遅延で決まる。110 Hz で約 17 ms、1 kHz で約 5 ms（導出）。

**初期の構成**（§6）。
- 線形の複素 gammatone を使う。T2 と同じ定義で、4 次、帯域は ERB の 1.019 倍。
- channel は 1/4 ERB 間隔で、T2 の 30 の中心を含む格子に置く。
- hop ごとに、各 channel の power と位相の進みを読む。
- power を瞬時周波数の位置へ移す（再配置）。
- 臨界帯域の中で強さを足してから、指数 0.23 で圧縮する。
- Log2Space の scan に写し、今の H／R の kernel にそのまま渡す。
- 量は、今と同じく再生の音量によらない相対の量にする。

**SF-1 の二つの未達。**
- **15 Hz の二音を分ける要求**（SF-1 の brief、統括が置いたもの）は、原理から外す。分けられない組の粗さは、組を二つの位置に分けなくても、潜在の R の意味と包絡で扱える（§5.4）。
- **Flora の PCM oracle の不合格**は、設計の要件として取り込む。PCM から scan までの写像を入力に対して連続にし、閾値で成分の採否を決めない（§5.6）。

**作者に決めてもらうこと**は、いま二つ（§10）。音量の扱いと、初期の変更の範囲。前の二つの試みの失敗の理由は、別に確かめる。

## 2. 今の consumer と入力の履歴

### 2.1 混合の habitat に共通の時刻の契約

確認済み。

- hop K の初めに、audio worker は解析の id が K−1 以上になるまで待つ（`MAX_LANDSCAPE_LAG_FRAMES = 1`、`src/runtime/mod.rs:51`、`src/runtime/analysis_sync.rs:227`）。habitat の hop は render の後で解析へ送られる（`src/runtime/worker.rs:683`）。だから hop K が読む Landscape は、habitat の hop K−1 の解析そのものである。
- 観測の時刻の印は `frame_end_tick(K−1)`、つまり hop K の始まり（`src/runtime/analysis_sync.rs:300`）。NSGT の窓は右寄せなので、印は窓の右端である。証拠の重心は帯域ごとにもっと古い（§5.7）。帯域ごとの遅れの補償は無い。
- run の開始前の履歴はゼロで埋まる。つまり観測済みの無音として扱い、未知とはしない（`src/core/analysis_worker.rs:52`）。
- frame id が途切れると、stream を reset し、`(id, None)` で無効を知らせ、窓が満ちるまで publish しない（`analysis_worker.rs:98`、`:170`）。混合の解析が無効になると、固定の遅れでは回復できないので run を終える（`analysis_sync.rs:259`）。
- worker は受け取った H／R から、今の valuation で C を作り直す（`analysis_sync.rs:61`）。habituation は毎 hop、base の level と subjective intensity の H 射影で進み、`_eff` の view を書く（`analysis_sync.rs:127`）。

### 2.3 契約表から出る要件

1. **型を保つ。** H／R の kernel の入力は、Log2Space の scan で、ERB あたりの圧縮した質量の密度（`subjective_intensity`）。これを保てば、consumer の型と F1〜F4 の規則は変わらない。
2. **音量によらない。** 今の H01 は peak で正規化し、R01 は質量で正規化した密度から作る。subjective intensity の圧縮は全 bin に同じ冪を掛けるので、全体の利得 g は g^0.46 の共通の倍率になって、正規化で消える。だから H／R／C は、密度の正規化の床と peak の抽出の床を除いて、音量によらない（導出）。新系もこの性質を保つ（§5.8）。
3. **連続である。** Flora の PCM oracle（`src/life/pitch_loo_conformance_tests.rs:988`）は、`mix − own` と単独の Flora の PCM（差は丸め誤差だけ）から作った場の score が、bin ごとに 1e-3 以内で一致することを求める。B-1 の LOO の門も同じ形である。入力の微小な差で場が跳ぶ写像は、この門を通らない（§5.6）。
4. **時刻の契約を保つ。** hop K が K−1 の解析を読むこと、印が frame end であること、gap の後は publish を止めることは変えない。変わるのは、帯域ごとの証拠の古さと、gap の後の warm-up の長さ（§5.7）。
5. **未知と無音を区別したままにする。** run の開始前は無音、gap は未知、という今の扱いを保つ。
6. **Flora の資源は別の契約。** 資源の power は知覚の量と揃えない。NSGT の FFT と \|K\|² の配分は、資源と研究の tap のために残す。
7. **研究の対照を保つ。** T2、時間の観測の tap、body capture の入力は変えない（AUD-R1 M9）。

## 3. consumer ごとの要求

AUD-R1 H1 に従い、知覚の閾を前処理の予算に直接使わない。consumer ごとに、判断、識別、刺激、支持区間、統合、参照の時刻、使える時刻、総遅れを分ける。要求の厳しい順に書く。

### 3.1 Voice の音高の提案（最も厳しい）

- **判断**：近くの候補の中から、次に動く音高を選ぶ（局所の提案。最良の全探索は要らない）。
- **必要な識別**：H の山の位置（協和の音程の位置）と、R の増分の形。山の位置の誤差は、Voice が落ち着く音程の誤差になる。誤差 e cent の音程は、重なる倍音 F Hz の所で約 F·e/1731 Hz のうなりを生む（導出）。
- **今の水準**：peak は bin に置かれるので、成分の位置は ±6.25 cent に量子化される（`landscape_spectral.rs:90` の `peak.bin_idx`）。H の kernel の平滑は 3 cent（`harmonicity_kernel.rs:67`）。
- **刺激**：倍音を持つ Voice の body と Flora の lane が重なる混合。低い F0 は 55 Hz まで。
- **支持区間**：今は窓（低域 341 ms）。新系は filter の記憶（最も低い channel で約 85 ms、§5.7）と hop。
- **統合**：hop（10.67 ms）と leaky の 10 ms。
- **参照の時刻と使える時刻**：§2.1 のとおり。
- **総遅れ**：証拠の遅れ、hop の量子化、待ち、pitch controller の動き。Burnett ほか（1998）の声の修正の潜時（実験 1 の平均 228 ms、範囲 60〜830 ms、確認済み）は、この総遅れ全体と比べる参照にはなる。ただし前処理の予算ではない。
- **受け入れの形**：厳密な成分の一覧（合成の正解、または renderer の `rendered_partials`）を同じ圧縮と kernel に通した場を正解とし、候補の選択がどれだけ変わるかを数える。今の NSGT の経路も同じ正解と比べ、新系の変化がそれを超えないことを確かめる（§8 V2）。新しい cent の閾は置かない。

### 3.2 Flora の成長と配置

- **判断**：ERB の cell ごとの biomass の増減と、配置の分布。
- **必要な識別**：cell の幅（ERB の尺度）の level と H01。位置の精度は Voice より緩い。
- **固有の要求**：自分の弱い部分音が、独立した位置として場に残ること（Coupling Contract 3、引き継ぎ §2）。今は全体の 5% の条件と 32 本の上限で、候補の出現の 72% が落ちる（SF-1、確認済み）。
- **総遅れ**：成長の時間の尺度は temporal DCC の拍と basin から決まる（`flora.md`）。閉じた環の遅れの注意書き（`flora.md:119`）は今の NSGT の遅れを前提にしている。新系では遅れが短くなるので、注意書きの数字を更新する。

### 3.3 出生、発音、habituation、予測

- 出生の分布、発音の level、habituation の駆動、予測の外挿は、場の形を粗く読む。位置の精度は 3.1 より緩い。
- 予測は観測の印（frame end）と前回の観測の差から外挿する。証拠の遅れが短くなれば、外挿の前提（印と証拠の時刻の差が小さい）は今より正しくなる。

### 3.4 listener

- 既定では report と UI だけ（DCC の coupling の既定は 0）。判断に使う時は、tension（安定と解決の可能性）を pressure に変える。
- 要求の形は 3.3 と同じ。presentation の bus を別の stream として解析する。

### 3.5 同期の body 解析（既定 off）

- 代表音の単独の render と環境の `mix − own` を同じ前処理に通す。Voice の LOO と同じ連続性が要る。
- 代表音の render の長さ（`observation_frames`）は、今の窓に合わせて決められている。新系の短い支持区間に合わせて見直せる（§7）。

### 3.6 原典の値の使い方

AUD-R1 §3 と SF-1 の照合を、この設計での役割と一緒に並べる。どれも条件の範囲でだけ使う。

- **ERB**（Glasberg & Moore 1990）：丸めた式 24.7(4.37 f/kHz + 1) Hz。AMT は 24.673(0.004368 f + 1)。T2 と新系は 24.7 + f/9.265 を使う（確認済み）。帯域幅の尺度であり、二音を分ける保証ではない。この設計では filter の帯域の定義に使う。
- **4 次の gammatone の帯域の係数 1.0186**：ENBW を ERB に一致させる値。(n−1)!²/(π(2n−2)! 2^−(2n−2)) で、ENBW/b = √π Γ(n−½)/Γ(n) と掛けると 1 になる（導出、`AUD-1/derive.py`）。T2 の `t2.rs:161` と同じ。AMT の `hohmann2002` は帯域の係数の既定を 1.0 とする（確認済み）。新系は T2 と同じ定義を採る。
- **分けられる倍音の数（約 10 次）**：Bernstein & Oxenham（2003）、Shackleton & Carlyon（1994）。条件付きで、本数の固定には使わない。新系では、分けられるかどうかは filter から出てくる（§5.2）。
- **粗さの変調の範囲 15〜300 Hz、最大 70 Hz 前後**：1 kHz、100% AM の条件の値。硬い境界は無く、Fastl は 25 Hz でも粗さと fluctuation の両方が生じるとする。この設計では分離の要求に使わない（§5.4）。
- **部分音が別の音として聴こえる閾 1〜3%**（Moore, Glasberg & Peters 1986）：等振幅の 10〜12 本、各 60 dB SPL、410 ms の条件。許容誤差には使わない。
- **純音の弁別 0.2〜0.5%**（Wier ほか 1977）：未照合。使わない。
- **声の修正の潜時**（Burnett ほか 1998）：総遅れの参照だけ（3.1）。
- **手拍子の同期の 8〜25 ms**（Chafe ほか 2010）、**時刻の弁別**（Friberg & Sundberg 1995）：時間の経路の量。H／R の前処理の要求には使わない。時間の経路はこの設計で変わらない。
- **相対マスキング**（Parncutt & Strasburger 1994、Eqs. 2〜7、SF-1 が数値で一致を確認）：新系の段にはしない。比較の参照にだけ使う（§5.5）。
- **specific loudness の指数 0.23**：今の既定値（`config.rs`）。Zwicker の specific loudness の式の指数とされる（Zwicker & Fastl の式 8.5 の二次の引用で確認、原典のページは未照合）。
- **臨界帯域の中での loudness の加算**（Zwicker, Flottorp & Stevens 1957、JASA 29, 548–557）：二つの成分が一つの臨界帯域の中にある間は、強さを足してから loudness が決まり、帯域の外へ離れると loudness が足し合わされる。書誌は確認済み、本文は未照合。新系の圧縮の段の根拠に使う（§5.5）。

## 4. 前の二つの試み

AUD-R1 M5 のとおり、二つは別の試みである。

- `67a5c81`（2025-10-23）：解析信号 → Hann → FFT の power → `potential_r_from_psd_direct`。包絡から粗さを出すのではなく、候補の周波数に沿う潜在の R に戻る形。
- `cochlea.rs`（2025-10-04 の `a5fbe8b6` で入り、2025-11-09 の `b0011ce` で削除）：heterodyne → 複素 LP の 4 段 → 包絡 → 平均で正規化 → HP 20 Hz → 任意の LP 300 Hz → RMS。
- 履歴の順は、cochlea（10-04）、kernel の畳み込みの R（10-22）、Hilbert 版（10-23）、NSGT（10-25〜10-30）、cochlea の削除（11-09）。
- 失敗の理由は記録に無い。作者に確かめる（§10）。

新系は、どちらとも次の点で違う。
- 粗さを包絡から直接作らない。潜在の R の意味は、今の kernel のまま保つ（§5.4）。
- 複素の filter の出力は、包絡ではなく位相の進みを読む。
- 圧縮の前に、power を位置へ移す。

前の試みが同じ所で躓いていたなら、作者の答えで新系の危険の場所が分かる。答えを待たずに設計は進める。

## 5. 原理からの導出

### 5.1 引き換えの所在

今の NSGT の帯域の ENBW は、4 項 Blackman–Harris の係数から 2.00435·fs/L（SF-1、確認済み）。L = min(80·fs/f, 16383)。

- 110 Hz：L = 16383、ENBW 5.9 Hz、ERB 36.6 Hz。比 6.2。
- 440 Hz：L = 8727、ENBW 11.0 Hz、ERB 72.2 Hz。比 6.6。
- 1 kHz：L = 3840、ENBW 25.1 Hz、ERB 132.6 Hz。比 5.3。
- 8 kHz：L = 480、ENBW 200 Hz、ERB 888 Hz。比 4.4。

今の窓は、人の聴覚の filter より 4〜7 倍狭い帯域で、近い成分を分けようとしている（導出）。その代償が長い窓で、作者の言う「周波数の解像度を上げると時間の遅れが著しくなる」はこれである。一方で bin に置いた位置は ±6.25 cent に量子化され、位相を捨てているので、長い窓でも位置の精度は上がらない。

### 5.2 分ける力

filter の帯域を ERB に合わせると、分ける力は人の聴覚の filter と同じ尺度になる。数値実験（1/4 ERB 間隔、理想の解析信号を入力、H の kernel と同じ 3 cent の平滑の後の山の位置）では次のようになった。

- 単音：誤差 0、質量の比 1.000。
- 等振幅の二音（1 kHz）：2 ERB 離れて 2.5 cent 以内、1.5 ERB で 6.5 cent、1 ERB で 11 cent。3 ERB で 0.5 cent。
- 1/h の振幅の倍音列：隣との間隔が約 1.5 ERB 以上の倍音（F0 = 110 Hz の 1〜4 次、220 Hz の 1〜4 次、440 Hz の 1〜5 次）は 2 cent 以内。間隔が 1.3 ERB 以下の倍音は 5〜25 cent ずれ、質量も周りへ広がる。
- 1/2 ERB 間隔では、F0 = 110 Hz の 2〜3 次で −9.5 cent。今の量子化の幅（±6.25 cent）を超える。

ここから二つが言える。
- 隣と約 1.5 ERB 以上離れた成分は、今の bin の量子化より正確な位置に置かれる。
- それより近い成分は位置が広がる。人の聴覚でも、近い倍音は個別の位置としては聴こえにくくなる。ただし境界の数値が人と一致するとは主張しない（AUD-R1 §3 の分けられる倍音の条件）。

H の common root は、分けられた低い倍音から根音を作る。分けられない高い倍音は位置が広がるので、H への寄与は弱く広くなる。これは H の意味（分けられた成分の位置からの common root）と矛盾しない。

### 5.3 一つの成分の周波数

channel の複素の出力 z[n] について、hop の中の S = Σ z[n]·conj(z[n−1]) の偏角から、power で重みづけた瞬時周波数 f̂ = fs·arg(S)/2π が出る。一つの定常な成分が channel を占めていれば、f̂ はその成分の周波数に一致する（導出、数値実験で誤差 0）。

隣の成分が漏れると偏る。最も近い channel で、隣の成分の振幅の比が r なら、偏りは約 r²Δ/(1 + r²)（Δ は周波数の差、うなりが hop の中で平均される場合、導出）。等振幅の隣が片側にある時は次のとおり（`AUD-1/derive.py`）。

- 1 ERB：−11.7 dB の漏れ、1 kHz で 14 cent。
- 1.5 ERB：−20 dB、3.4 cent。
- 2 ERB：−27 dB、0.8 cent。
- 3 ERB：−39 dB、0.08 cent。

倍音列では両側の隣の偏りが打ち消し合い、残るのは振幅の傾きの分である。AUD-R1 H2 のとおり、瞬時周波数は一つの成分が channel を占める時だけの推定量であり、二つの成分の一覧は返さない。新系はこの量を「成分の一覧」としてではなく、次節の再配置の位置として使う。分けられない組では、組の重みつきの平均の位置に質量が集まる。これがこの設計での「未分離」の扱いである。

### 5.4 分けられない組と R

潜在の R は「候補の位置に単位の純音を一本足した時の粗さの増分」で、今鳴る音どうしの粗さではない（`roughness_kernel.rs:322`、AUD-R1 M1）。単位の純音と既存の成分 j の組ごとの増分の和 Σ_j g(x − y_j)·m_j として計算される。

既存の二成分 y₁、y₂ が近くて一つの位置 ȳ に融合した時、候補 x での誤差は、g の二階の微分と (y₂ − y₁)² の積の程度になる（導出）。g の形は臨界帯域の尺度で変わるので、15 Hz（1 kHz で 0.11 ERB）の組の融合は、候補の場をほとんど変えない。誤差が大きいのは、融合した組のちょうど間に候補を置く場合だけで、そこはもともと粗い位置である。

組そのものの粗さ（今鳴る音の粗さ）は、組を二つの位置に分けなくても、その組が入る channel の包絡のうなりにそのまま現れる。包絡は tap B から読める（§6.1）。今その量を判断に使う consumer は無い。`roughness01_scalar` は assay と report だけで読まれている。

Voice の LOO では、自分の音を引いた後の混合を解析するので、Voice A が近くの Voice B から受ける粗さは、B が A と融合することなく B の位置で場に出る。融合が起きるのは混合の stream だけで、その consumer（出生、Flora、LOO の無い Voice）は 3.1 ほど細かい位置を要らない。

だから SF-1 の「15 Hz 離れた二音を分ける」要求は、どの consumer の判断からも出てこない。外す。代わりに次を要求する。
- 約 1.5 ERB 以上離れた成分は、別の位置に置く（§5.2）。
- それより近い組の、潜在の R の場への影響は、正解の一覧と比べて候補の選択が変わらないこと（§8 V2）。
- 組の粗さを判断に使う consumer が現れたら、tap B から読む。これは §10 の判断 2 の範囲の外で、そのとき作者が決める。

### 5.5 再配置、圧縮、マスキング

**再配置。** 各 channel c の hop の平均の power E_c を、その channel の瞬時周波数 f̂_c の位置へ、filterbank の全体の利得 G(f) = Σ_c |H_c(f)|² で割って移す。

- 一つの成分だけの時、移した power の合計はその成分の power に一致する（導出）。
- 複数の成分がある時、channel を占める成分の所へ、その channel の power が集まる。

これは reassignment（Kodera ほか、Auger & Flandrin）や synchrosqueezing と同じ考え方を、聴覚の filterbank に当てたものである。公表されたモデルをそのまま採るのではなく、工学的な推定量として名前を付けて使う。

**圧縮。** subjective intensity の今の定義は、peak ごとに (P·A_w/P_ref)^0.23。channel ごとに先に圧縮すると、遠い channel の裾（−100 dB）が重みを持ちすぎる（数値実験の v1、単音の位置が 300 cent 以上ずれた）。そこで、各位置の圧縮は、その位置の臨界帯域の power で決める。

- 位置 x に移った power を d、x の両隣の channel の励起から求めた臨界帯域の power を P_cb(x) とする。
- x の重みは (d/P_cb)·(A_w·P_cb/P_ref)^0.23。
- 一つの成分なら、合計は今の peak ごとの定義と一致する（導出、数値実験で比 1.000）。
- 一つの臨界帯域に入る二つの成分は、強さを足してから圧縮される。帯域の外へ離れた成分は、別々に圧縮されて足される。これは Zwicker, Flottorp & Stevens（1957）の loudness の加算の形である。

A_w は今の A-weighting を channel の中心で掛ける（今の慣行を保つ）。外耳・中耳の伝達の model へ替えることは、この設計の範囲に入れない（AUD-R1 M2）。

**マスキング。** 弱い成分が強い成分の近くにあると、弱い成分の channel は強い成分に占められ、その power は強い成分の位置へ移る。数値実験（1 kHz の音の 1.5 ERB 上の弱い音、1/4 ERB）では、弱い音の質量の比は次のようになった。

- −5 dB：1.08
- −10 dB：0.88
- −15 dB：0.45
- −20 dB：0.07
- −30 dB：0

Parncutt & Strasburger の相対の重み（勾配 12 dB/ERB）は、同じ条件で 0.58、0.41、0.18、0、0。消える level はほぼ同じ所（−18〜−20 dB）にある。ただしこれはマスキングの閾の model ではない。部分的に占められた弱い音の位置は、強い音の方へ 30〜80 cent 寄る。P-S の段を加えないのは §5.6 の連続性のためで、P-S は離散の成分の一覧を要るので、成分のまとめ方に閾が入る。

全体に対する 5% の条件と 32 本の上限は無くなる。弱い成分が場から消えるのは、近くの強い成分に channel を占められた時だけである。Flora の弱い部分音の扱いは、これで Coupling Contract 3 の意図に近づく（V2 で SF-1 と同じ表を取る）。

### 5.6 連続性

Flora と B-1 の PCM oracle の門（§2.3 の 3）は、丸め誤差の差の入力から作った二つの場が、bin ごとに 1e-3 以内で一致することを求める。写像が入力に対して連続（Lipschitz 定数が小さい）なら、この門は自動的に通る。閾値で成分を採るか捨てるかを決める写像は、閾値の近くで場が跳ぶ。

SF-1 の v4 には、完全な窓の支持、局所の床、位相の候補の採否という離散の判定があった。Flora の門の不合格はこれで説明できる（推測。記録は門の不合格だけで、原因は特定していない）。

新系の各段は連続である。
- 線形の filter、hop の平均、偏角（S が 0 に近い channel は power も 0 に近く、移す質量が 0 に近づく）、Log2Space の隣り合う二 bin への線形の配分、leaky の平滑、臨界帯域の power による圧縮の重みは、どれも連続。
- 数値実験では、入力の相対の変化 1.1e-6 に対し、質量の相対の変化は 1e-6 以下だった。

残る不連続は、今もある共有の密度の正規化の床（質量が eps を横切る所）だけで、これは今の門の扱いのままにする。

### 5.7 遅れ

**群遅延。** 4 段の複素 one-pole の cascade の中心周波数での群遅延は、約 4/(2πb)（b = 1.0186·ERB、導出）。55 Hz で 20.4 ms、110 Hz で 17.1 ms、220 Hz で 12.9 ms、440 Hz で 8.7 ms、1 kHz で 4.7 ms、4 kHz で 1.4 ms、8 kHz で 0.7 ms。

**証拠の重心の遅れ。** hop の平均（重心 5.3 ms）と leaky の 10 ms（hop の one-pole の低周波の群遅延 5.6 ms）を足す。線形の段の重心であって、非線形の段（再配置と圧縮）を含む応答の時刻ではない（SF-1 の注意）。

- 新系：110 Hz で 28 ms、440 Hz で 20 ms、1 kHz で 16 ms、8 kHz で 12 ms。
- 今の NSGT：窓の重心、帯域の leaky、front end の leaky を足すと、110 Hz で 191 ms、440 Hz で 104 ms、1 kHz で 49 ms、8 kHz で 12 ms。

**ステップの応答**（SF-1 と同じ定義。6 倍音の複合音で、主観の質量が定常値の 10／50／90% に初めて達する hop の終わり。数値実験）

- 新系：root 110.7 Hz で 10.7／10.7／21.3 ms、root 1003.1 Hz で 10.7／10.7／21.3〜32 ms。
- 今の経路（SF-1 の実測）：110.7 Hz で 32／53.3／74.7 ms、1003.1 Hz で 10.7／21.3／32 ms。
- 圧縮のため、power が 10% でも質量は 59% になる。この表は質量の立ち上がりで、位置が正しくなる時刻ではない。

**使える時刻**は変わらない。hop K が K−1 の解析を読む。

**帯域の遅れは揃えない。** 蝸牛の進行波と同じく、低い帯域ほど証拠が古い。AMT の Hohmann の delay は再合成用で、認知の整列に採らない（AUD-R1 H4、ledger §9.3.13〜§9.3.14）。

**gap の後の warm-up。** IIR の filter には有限の窓が無い。インパルス応答の残りの energy が 1e-7 を下回るまでを warm-up と定義すると、最も低い channel で約 85 ms（導出、40 Hz で 81 ms、55 Hz で 77 ms）。今の 341 ms より短い。1e-7 は「cold start の出力が warm の出力と f32 の精度で一致する」ための値で、今の「窓が満ちるまで」の契約（FIR では厳密）に対応させた。

**準拠の注意。** これらの短い遅れは、遅れの予算を新しく置いた結果ではない。filter の帯域を ERB に合わせた結果として出てくる。DCC 地図 §6 のとおり、知覚の統合・分解能と解析の遅れを別に記録する。

### 5.8 音量によらないこと

- 利得 g を掛けると、E_c、d、P_cb は g² 倍、f̂ は不変。重みは g^0.46 の共通の倍率になり、H と R の正規化で消える（導出）。
- 線形の filter と、冪の圧縮と、相対の比較だけで作るので、再生の音量の仮定は要らない。
- 代わりに、音量に依存する現象（level で帯域が広がる tuning、上への広がりのマスキング、絶対の閾、level に依存する粗さ）は、受け入れの範囲の外になる。これを含めるには、非線形の蝸牛のモデルと音量の仮定が要る（§10 の判断 1）。

### 6.2 S1 の要否

実数の PCM をそのまま S2 に通すと、遠い channel の瞬時周波数は正と負の周波数の像の干渉で狂う。数値実験では、単音で位置の誤差が最大 1.6 cent（55 Hz）、見当違いの位置に落ちた質量が最大 2.7% だった。理想の解析信号を入れると、どちらも 0 になる。

因果の近似（二本の全域通過の chain の位相差を 90° にする回路）は、帯域の中で負の周波数を数十 dB 抑える代わりに、周波数に依存する群遅延を足す。抑えの深さと遅れは M1 で設計し、遅れは §5.7 の表に足す。

要否の判断は V2 で行う。実数の入力と S1 付きの入力で consumer の判断が変わらなければ、S1 は置かない。

channel の重みで遠い channel を抑える案（v5）は、単音では見当違いの質量を消したが、混合音で質量が保存されなかった（倍音で 1.1〜2.7 倍）。採らない。

### 6.3 蝸牛のモデルの選択

AUD-R1 H3 のとおり、Hohmann 型と CARFAC は差し替えのきく部品ではない。選択は §10 の判断 1 で決まる。

- **線形の Hohmann 型（推奨）**
  - 入出力：PCM → 複素の channel の出力。
  - 状態：channel ごとに 4 つの複素数。
  - 非線形：無い。
  - 校正：要らない。
  - tap：A。
  - LOO：tap A で z(mix − own) = z(mix) − z(own) が厳密に成り立つ（初期は使わない）。
  - T2：同じ定義で、格子が T2 の中心を含む。
  - 音量に依存する現象は表せない。
- **CARFAC**
  - CAR、OHC、IHC、AGC を一体にした非線形のモデル。level に依存する tuning と圧縮を持つ。
  - 校正（dBFS と音圧の対応）、非線形の履歴、版と IHC の型の固定、LOO の stream ごとの非線形の状態と出生の時の初期化が要る。
  - Hohmann 型と同じ意味の複素の位相の出力は持たないので、S3〜S4 の読み出しをそのまま使えない。
- **動的な compressive gammachirp**（Irino & Unoki）
  - level に依存する非対称な filter。校正と非線形の状態の要件は CARFAC と同じ側にある。

判断 1 で相対の量を選べば、線形の Hohmann 型に決まる。仮想の再生音量を選べば、CARFAC と gammachirp を、consumer が使う応答の差で比べる段が入る。

### 6.4 音高の読み出し

- H は今の common root の kernel のまま、分けられた成分の位置から根音を作る。
- 時間の自己相関による音高（Meddis & Hewitt 1991）は、分けられない倍音だけの音、欠けた基音、位相に依存する音高で H と違う答えを出す候補である。今の consumer にはその違いを使う判断が無いので、初期には入れない。
- 入れる条件：分けられない高い倍音が主になる body（強い高次と弱い低次）が sample で使われ、その音の H の場が V2 の正解と大きくずれる時。lag の状態の費用と、自己相関の音高を候補の H の場へ写す規則を、そのとき別に設計する。

### 6.5 Landscape との接続

- `subjective_intensity` と、H／R／C の field と、`_eff` の view は、型と意味を保つ。
- `nsgt_power` は、UI、report、spectral history の入力として、再配置した power の scan に替える（名前は実装で決める）。判断に使う consumer は無い。
- 研究の tap（時間の観測、arrival）は今の NSGT の power を読む。tap が有効な時だけ、混合の stream で NSGT を計算する。body capture は lane ごとの RtNsgt のまま。
- Flora の資源の power は、今の FFT と \|K\|² の配分のまま。Flora がある時、混合の stream はこの FFT を今と同じく計算する。
- test と診断の専用の近似の LOO（NSGT の power と peak の抽出を使う）は、移行の時に新系に合わせて直すか消す。
- H01 と R01 の正規化、密度の正規化の共有の床、F1〜F4 の規則は変えない。

T2 との関係。新系の格子は T2 の 30 の中心を含み、filter の定義も同じなので、T2 は将来 tap A の部分集合を読める。ただし新系は f32、T2 は f64 なので、共有すると T2 の数値は丸め誤差の分だけ変わる。T2 は研究の opt-in で、その数値は登録済みの対照なので、初期は共有しない。T2 を演奏の経路で使う判断の時に、共有の費用と数値の差を比べる（§10 の後で足りる判断）。

### 6.6 皮質の段

Chi, Ru & Shamma（2005）の spectro-temporal modulation、Elhilali の coherence は、consumer が決まるまで作らない（AUD-R1 M10）。H と R の kernel は、機能としては音高と粗さの中枢の処理にあたるが、それを神経の対応の検証とは呼ばない。各読み出しには、出所、観測の範囲、使える時刻を付ける。同じ音を複数の読み出しに通しても、独立した証拠は増えない。

## 7. 費用

費用は独立した stream ごとに数える（AUD-R1 M7）。

**stream の種類。**
- 混合の habitat：1 本。
- presentation：listener が有効な時に 1 本。
- Voice の LOO：自己除外のある Voice ごとに 1 本。
- 同期の body：選ばれた Voice ごとと代表音の render。
- Flora の資源：今のまま（新系の費用に入らない）。

非線形の段の後で F(mix) − F(own) として代用することはできない。どの stream も S1〜S7 を全部通す。

**1 stream・1 hop あたりの演算。**
- S2〜S3：137 channel × 512 sample × 約 41 flop ≈ 2.9 Mflop（導出）。
- 比べると、今の 16384 点の複素 FFT は 5N log₂N ≈ 1.15 Mflop で、これに帯域の疎な積と peak の抽出が加わる。
- S4〜S5 は channel の数に比例して小さい。
- S7（H／R の kernel）は今と同じ。
- channel の間に依存が無いので、SIMD で 8 channel ずつ並べて計算できる。漸化式は時間の方向に逐次。

**状態の大きさ。**
- channel ごとに複素数 4 つ（f32 で 32 byte）。137 channel で約 4.4 KB、S1 の状態、leaky の scan（690 の f32）。
- 今の ring は 16384 の f32（64 KB）と帯域の状態なので、出生の時の複製は今より小さい。

**出生、reset、退場。**
- 出生では、混合の stream の状態（filter と leaky）を複製する。今の契約（出生の前の履歴 = 混合の履歴）と同じ。
- gap では状態を 0 にし、warm-up（約 85 ms）の間は publish しない。
- 退場中の尾は今と同じく stream として残る。

**危険。** 今の記録では、自己除外の Voice は 1 人あたり約 0.3 ms/hop で、解析の thread 一本で約 30 人を超えると出力が途切れうる（2026-10-22 の L-1 の記録。この session では再測定していない）。

S2〜S3 の演算が今の FFT の約 2.5 倍なら、1 人あたりの費用が増え、上限の人数が下がりうる。下げる手段は次の三つ。いずれも consumer の判断の比較（V2）と費用の測定（V5）で選ぶ工学の近似で、DCC 地図 §6 の「標本の格子と計算の予算」にあたる。
- channel の密度を 1/2 ERB にして位置の偏りを補正する。
- 低い channel を間引いた rate で計算する（多 rate。anti-alias の filter とその遅れを §5.7 に足す）。
- S1 を省く。

上限の人数が今より下がる場合は、作者の判断にする。

## 8. 限定した検証

各検証に、変える判断、既存の根拠で足りない理由、選択肢を見分けられる理由を付ける。どれも未実行。

**V1 filter の数値の一致**
- 変える判断：S2 の実装を、採った定義（T2 と同じ gammatone）として受け入れるか。
- 足りない理由：数値実験は Python で、Rust の実装の正しさは保証しない。
- 見分け：閉じた形の周波数応答と、T2 の f64 の channel（共通の中心）との差。pole、利得、正規化の誤りを検出する。

**V2 consumer の判断の比較**（中心の検証）
- 入力：正解の成分の一覧を持つ音。
  - 合成：単音、1〜3 ERB の二音、F0 55〜440 Hz で傾きの違う倍音列、強い音の近くの弱い音、15 Hz の組。
  - sample：renderer の `rendered_partials` を持つ 17 と drone90 と数本の sample。
- 比べる三つ：新系、正解（一覧を同じ S5〜S7 に通したもの）、今の NSGT の経路。
- 数えるもの：H／R／C の場の差と、判断の差。判断は pitch_core の局所の候補の選択、出生の分布の距離、Flora の cell の増減の符号。SF-1 と同じ、Flora の部分音の対応の表も取る。
- 変える判断：次のどれを採るか。推定量をそのまま、S1 を足す、channel を密にする、漏れの補正、tap D。
- 足りない理由：数値実験は定常の合成音と山の位置の指標だけで、consumer の判断を数えていない。
- 見分け：各案は山の位置の偏りが違い（§5.2〜5.3）、判断の差の数で比べられる。

**V3 PCM の自己除外の不変**
- 内容：Flora 40、B-1 84 の今の門を、新系で通す。
- 変える判断：新系を LOO に入れられるか。
- 足りない理由：連続性は導出したが、実装が不連続を持ち込みうる（偏角の枝、床、早すぎる publish）。
- 見分け：今の門の合否。

**V4 時刻と未知**
- 内容：前置きの無音、gap、観測済みの無音、出生の複製、warm-up の publish の規則。
- 変える判断：publish の規則と、出生の時の状態の複製の定義。
- 足りない理由：定常の一致は、履歴の取り違えや未来の参照を検出しない。
- 見分け：欠測の間に観測を更新しないこと、無音では観測があることを分けて確かめる。

**V5 実時間**
- 内容：まず今の producer の形の小さな場合で、1 stream の 1 hop の費用と LOO の N 人を測る。その後 M3 で、宣言の負荷（22 場面、FI-1b の規則、timing lock）で測る。
- 変える判断：channel の密度、多 rate、S1 の有無、LOO の上限。
- 足りない理由：演算の数の見積もりだけでは、cache、publish、待ちを評価できない。
- 見分け：hop の予算 10.67 ms と miss の数。

**V6 今の粗さ**（判断 2 で範囲を広げた時だけ）
- 内容：tap B の包絡から作る粗さと、公表された粗さのモデル（Daniel–Weber か ECMA-418-2）の oracle の比較。
- 判断 2 の推奨の範囲では行わない。

**行わないもの。**
- 15 Hz の二音の分離（§5.4）。
- 人の閾の全面の再現（AUD-R1 §6）。
- P-S のマスキングの閾の再現（新系はマスキングの model を名乗らない）。

## 9. 移行の段

- **M0 参照の凍結。** main `a6b197d`、SF-1 の `6054956` と取得物、B-1、F-0、Q の参照を、そのまま残す。新しいモデルの oracle、不変の契約（PCM の自己除外）、変わる consumer の判断、sample の作者の採用を、別々に登録する（AUD-R1 M9）。
- **M1 試作。** test の中だけで、S1〜S6 と読み出しを実装する。V1、V2 の合成の部分、V3 を影の front end で、V5 の小さな場合。演奏の経路は変えない。
- **M2 影の比較。** 研究の build で新系を今の経路と並べて走らせ、sample で V2 の全体と V4。
- **M3 切り替え。** `SynchronousAnalysis` の front end を新系に替える。混合、listener、LOO、body の全部が対象。NSGT は Flora の資源と研究の tap に残す。V3 と V5 を宣言の負荷で。
- **M4 採用。** 作者の試聴で sample の採用と自由な量を決める。実装が入ったら technote を更新し、設計の判断を ledger に記録する。
- **M5 後の整理。** T2 の共有、使われなくなった peak の抽出と coherent の NSGT の経路の削除。

知覚の基盤が変わると sample の行動も変わる。それは統合の契約が壊れたことではない。V3、V4 の不変の契約と、V2 の判断の変化を分けて記録する。

## 10. 作者の判断

いま決める判断は二つ。

### いま決める

1. **音量の扱い。** 知覚の層を、再生の音量によらない相対の量で作るか。
   - 選択肢
     - (a) 相対の量（今と同じ）
     - (b) 仮想の再生音量を一つ置き、音量に依存する段まで含める
     - (c) 実際の再生の校正
   - 推奨は (a)。今のすべての consumer の契約が音量によらず、楽器の再生音量は演奏の場で分からないので、(b) の音量は原理から決まらない値になる。
   - 効くもの
     - モデルの family：(a) なら線形の Hohmann 型。(b)(c) なら CARFAC と gammachirp の比較の段が入る。
     - 受け入れの範囲：(a) では、音量に依存する tuning、マスキング、絶対の閾、粗さが範囲の外になる。
     - LOO の検証：(a) なら tap A で `mix − own` の厳密な関係が保てる。
   - (a) で増える仕事は無い。
   - (b)(c) で増える仕事
     - dBFS と音圧の対応の数値。作者の数で、原理の値ではない。
     - 非線形のモデルの比較。
     - stream ごとの非線形の状態と、出生の時の初期化の定義。
     - 校正の検証。
   - 後で変える費用：S2 を差し替えると、読み出しの契約（tap A の複素の出力）が保てなくなる場合があり、sample の採用をやり直す。

2. **初期の変更の範囲。**
   - 選択肢
     - (a) 観測の基盤と H／R の入力だけを替え、H／R／C の意味、habituation、行動の規則、Flora の資源を変えない
     - (b) 今の粗さ（包絡）や時間の音高を、新しい consumer として足す
     - (c) R の kernel も filterbank から導き直す
   - 推奨は (a)。consumer の型が変わらず、検証が consumer の判断の比較（V2）で閉じる。(b)(c) は、それを使う判断がまだ無い。
   - 効くもの
     - 検証の範囲：(a) は V1〜V5。(b) は V6 と consumer の設計が加わる。(c) は R の場の意味の再登録が加わる。
     - sample の再採用の範囲。
   - 後で変える費用：(a) の後に (b)(c) を足すのは分離でき、tap B と S2 はそのまま使える。

### 別の選択で自動的に決まる

3. **蝸牛のモデルの family** は、判断 1 で決まる（§6.3）。
4. **SF-1 の 15 Hz の分離の要求**は、原理と consumer の契約から外す（§5.4）。統括の brief が置いた要求で、作者の発言ではない。作者が別の意図で 15 Hz を求めていた場合だけ知らせてほしい。
5. **P-S の相対マスキングの段**は、連続性の要件（§5.6）から段にせず、比較の参照にする。

### 後で足りる

6. 皮質の段の位置づけ。consumer が現れた時。
7. 時間の自己相関の音高。§6.4 の条件が起きた時。
8. T2 の共有。T2 を演奏の経路で使う判断の時。
9. LOO の上限の人数。V5 で今より下がった時だけ。
10. 自由な量、sample の採用、統合の順。M3 の後の試聴で。

### 並行して確かめること

- **前の二つの試みの失敗の理由**（§4）。それぞれについて知りたいこと：どの入力・sample で、何が起きたか（音、数値、費用のどれか）、どの版か。答えで新系の危険の場所が分かる。答えを待たずに M1 は進められる。

**決まれば動くこと。** 判断 1 と 2 が推奨どおりなら、M1 の試作（test の中だけ、演奏の経路は変えない）の結果をそのまま M2 へ進められる。判断 1 が (b)(c) なら、M1 の S3〜S4 の読み出しの一部を残し、S2 のモデルの比較を先に置く。

## 11. 未確認と限界

- 数値実験は、定常の合成音、Python、hop 一つの読み出しに限る。過渡、glide、vibrato、雑音、実際の sample の PCM では未確認。
- 低い channel（55 Hz 付近）の複素 gammatone は解析信号の近似が粗い。S1 の要否は V2 で決める。
- 部分的に占められた弱い成分の位置は、強い成分の方へ寄る（§5.5）。consumer の判断への影響は V2 で数える。
- 15 Hz の組の位置は、うなりの周期で揺れる（数値実験で、振幅の比 0.5 の時、1 kHz で約 27 cent の幅）。leaky の平滑で一部ならされる。H の場の揺れの影響は V2 で数える。
- 費用は演算の数の見積もりだけで、実測していない。
- 指数 0.23 の原典のページと、Zwicker, Flottorp & Stevens（1957）の本文は未照合。
- 前の試みの失敗の理由は分かっていない。
