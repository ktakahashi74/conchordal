- **導出**：式からの計算。人の測定値ではない。
- **数値実験**：`.orchestration/units/AUD-1/` の設計段の計算。定常の合成音、理想の解析信号の入力、Python。指標は予備のもので、受け入れの結果ではない。

## 1. 要約

**今の前処理で、遅れと H の質が引き換えになる理由。** 今の NSGT の帯域は、聴覚の filter よりずっと狭い。
- Q の上限は 80。nfft 16384 の打ち切りで、低域の窓は 341 ms になる。
- 帯域の等価雑音帯域幅（ENBW）と ERB の比は、110 Hz で約 1/6、1 kHz で約 1/5（§5.1、導出）。
- 近い成分を分ける力を、窓の長さで買っている。
- 一方、成分の周波数は power の山の bin（12.5 cent の格子）から読み、位相は捨てている。

窓の長さが「分ける力」と「位置の精度」の両方を担うので、どちらを良くしても遅れが増える。110 Hz では窓の重心だけで約 171 ms 遅れる（導出）。

**聴覚はこの二つを別の仕組みで持つ。**
- 分ける力は、filter の帯域で決まる。
- filter を一つの成分が占める時、その成分の周波数は位相（時間の微細構造）が運ぶ。
- 一つの filter に入って分けられない組は、包絡のうなりとして残る。

設計はこの分担を写す。孤立した定常の成分なら、位置の精度は位相から取るので窓の長さによらない（混合、過渡、雑音での精度は別に確かめる）。残る引き換えは「どこまで近い成分を分けるか」と「遅れ」になり、主に帯域の幅という一つの量で決まる。

**帯域の幅は consumer から決める。** 人の蝸牛の filter の帯域は ERB で、これが末梢の分ける力の目安になる。ただし H の kernel（common root）は、聴こえる成分の正確な位置を前提にしている。試作の最初の取得（AUD-M1）では、ERB 幅の filter だと 1 ERB 離れた二音（220 Hz と 271 Hz）が同じ channel に混ざり、H の判断が今の経路より正解から遠くなった。

そこで、ERB を帯域の尺度にした、consumer のための狭帯域の分析にする。帯域を β·ERB（β ≤ 1）とし、β は consumer の判断の比較（§8 V2）で選ぶ。基準を満たす中で一番大きい β、つまり遅れが一番短いものを採る。人の音高の知覚で、分けられた低い倍音の時間の微細構造が働くこと（Oxenham, Micheyl & Keebler 2009 の要旨、AUD-R3 が確認）は着想の背景であり、β の則はそこから導けない。β < 1 の構成は、公表された聴覚のモデルそのものではない。
- 数値実験（§5.2）では、β = 1/3 で 1 ERB 以上離れた二音と倍音列の位置が 2 cent 以内に入った。
- このとき遅れ（群遅延に hop と leaky を足した重心）は、110 Hz で約 62 ms、1 kHz で約 25 ms。今の経路は約 191 ms と約 49 ms（導出）。

**初期の構成**（§6）。
- 4 次の複素 gammatone（T2 と同じ形）で、帯域を β·ERB にする。
- hop ごとに、各 channel の位相の進みの和 S を読む。
- S の大きさを質量に、S の偏角を位置にして移す（再配置）。
- 位置ごとの臨界帯域の power で、指数 0.23 の圧縮をかける。
- Log2Space の scan に写し、今の H／R の kernel にそのまま渡す。
- 量は、今と同じく再生の音量によらない相対の量にする。

**試作の結果と β。** test の中だけの試作（AUD-M1）で、49 の合成の入力を consumer の判断（音高、respawn、出生、Flora）で比べた。
- 選んだ構成は β = 1/4、統計の窓あり、臨界帯域（ERB）の文脈の圧縮、S1 なし（§5.2）。成分が 0.75 ERB 以上離れた分類で、離散の判断（音高、respawn）は今の経路以上、倍音列の音高の不一致は新系 0、今の経路 536。場を積分する consumer は、110 Hz の 6 倍音の onset の Flora で今の経路より大きく遠く（377 対 63）、110/150 Hz の組の Flora と出生でわずかに遠い（45 対 35、L1 0.052 対 0.032）。これらは登録した差とした。遅れは 110 Hz で約 96 ms（今は約 191 ms）、1 kHz で約 30 ms（今は約 49 ms）。
- 0.75 ERB 未満の組（15 Hz の組など）は、どの β でも今の経路ほどは分けられない。初期の範囲では、これらを分けることを目標にしない（設計の判断。0.75 ERB は聴き分けの実験を参考に登録した工学の分類の境で、人の普遍的な分離の限界ではない）。融合した組が潜在の R に偽の谷を作る偏りと、それによる行動の差は、登録した限界として記録し、範囲を広げるかを作者の判断に残す（§5.4、§10）。
- 聴き分けの実験（Moore ほか 2006）を参考に、分類の境（0.75 ERB）、統計の窓（その間隔の組のうなりの一周期、110 Hz で約 36 ms）、帯域（β ≈ 1/4）を設計の則として置いた（§5.2）。人の生理の下限や、情報の上で必要な時間を導いたものではない。

**SF-1 の二つの未達。**
- **15 Hz の二音を分ける要求**（SF-1 の brief、統括が置いたもの）は、固定の分離の試験としては外す。代わりに、近い組が残る場（LOO の中の他の Voice の組を含む）での判断の試験と、偽の協和の山の記録に置き換える（§5.4、§8 V2）。
- **Flora の PCM oracle の不合格**は、写像の連続性の要件として取り込む（§5.6）。

**作者の判断。** 作者の実装の指示（2026-10-24「astra reviewを通したうえで、実装を完了」）を受け、既存の相対の量と、H／R の入力だけを替える範囲を、作業の前提として続ける（§10）。これは統括の範囲の判断であり、作者が二つの選択肢を個別に採用したという記録ではない。前の二つの試みの失敗の理由は、別に確かめる。

## 2. 今の consumer と入力の履歴

### 2.1 混合の habitat に共通の時刻の契約

確認済み。

- **待ちの契約。** hop K の初めに、audio worker は解析の id が K−1 以上になるまで待つ（`MAX_LANDSCAPE_LAG_FRAMES = 1`、`src/runtime/mod.rs:51`、`src/runtime/analysis_sync.rs:227`）。habitat の hop は render の後で解析へ送られる（`src/runtime/worker.rs:683`）。
  - だから hop K が読む Landscape は、habitat の hop K−1 の解析そのものである。
  - K = 0 だけは待たず、初期の Landscape を使う（`analysis_sync.rs:3`）。
- **時刻の印。** 観測の印は `frame_end_tick(K−1)`、つまり hop K の始まり（`analysis_sync.rs:300`）。
  - NSGT の窓は右寄せなので、印は窓の右端である。
  - 証拠の重心は帯域ごとにもっと古い（§5.7）。帯域ごとの遅れの補償は無い。
  - 印は観測の側の時刻であり、消費する hop とは別に持つ。
- **run の開始前。** 履歴はゼロで埋まる。つまり観測済みの無音として扱い、未知とはしない（`src/core/analysis_worker.rs:52`）。
- **gap。** frame id が途切れると、stream を reset し、`(id, None)` で無効を知らせ、窓（nfft）が満ちるまで publish しない（`analysis_worker.rs:98`、`:170`）。混合の解析が無効になると、固定の遅れでは回復できないので run を終える（`analysis_sync.rs:259`）。
- **C と habituation。** worker は受け取った H／R から、今の valuation で C を作り直す（`analysis_sync.rs:61`）。habituation は毎 hop、base の level と subjective intensity の H 射影で進み、`_eff` の view を書く（`analysis_sync.rs:127`）。

### 2.3 契約表から出る要件

1. **型を保つ。** H／R の kernel の入力は、Log2Space の scan で、ERB あたりの圧縮した質量の密度（`subjective_intensity`）。
   - これを保てば、consumer の型と F1〜F4 の規則は変わらない。
   - 型が同じでも、単位と値の意味は同じではない。圧縮の則の違いは §5.5 で定義し、V2 で扱う。
2. **共通の利得による H／R／C の近似の不変。** 今の H01 は peak で正規化し、R01 は質量で正規化した密度から作る。圧縮は全 bin に同じ冪を掛けるので、履歴の全体に一定の利得 g を掛けると、床の無い理想の式では g^0.46 の共通の倍率になって正規化で消える（導出）。
   - 実際の今の経路は、peak 抽出の床と、正規化の `mass + eps` を持つので、厳密には不変でない。床と eps を十分上回る領域での近似の不変である。
   - その他の条件：既定の `gamma_root = 1`、利得を演奏の途中で変えない。
   - Flora の資源（無圧縮の power）と report の `loudness_mass` は、もともと音量によらない量ではない。
   - 新系も同じ領域での近似の不変を保つ（§5.8）。
3. **連続である。** Flora の PCM oracle（`src/life/pitch_loo_conformance_tests.rs:988`）は、`mix − own` と単独の Flora の PCM（差は丸め誤差だけ）から作った場の score が、bin ごとに 1e-3 以内で一致することを求める。B-1 の LOO の門も同じ形である。入力の微小な差で場が跳ぶ写像は、この門を通らない（§5.6）。
4. **時刻の契約を保つ。** hop K が frame K−1 を読むこと、印が frame end であること、gap の後は窓が満ちるまで publish を止めることは変えない。変わるのは、帯域ごとの証拠の古さ（§5.7）。
5. **未知と無音を区別したままにする。** run の開始前は無音、gap は未知、という今の扱いを保つ。
6. **Flora の資源は別の契約。** 資源の power は知覚の量と揃えない。NSGT の FFT と \|K\|² の配分は、資源と研究の tap と UI のために残す。
7. **研究の対照を保つ。** T2、時間の観測の tap、body capture の入力は変えない（AUD-R1 M9）。

## 3. consumer ごとの要求

AUD-R1 H1 に従い、知覚の閾を前処理の予算に直接使わない。consumer ごとに、判断、識別、刺激、支持区間、統合、参照の時刻、使える時刻、総遅れを分ける。要求の厳しい順に書く。

### 3.1 Voice の音高の提案、selection、respawn（最も厳しい）

- **判断**：近くの候補の中から、次に動く音高を選ぶ（局所の提案。最良の全探索は要らない）。respawn の peak bias も場の山を列挙して局所の探索をする。
- **必要な識別**：H の山の位置（協和の音程の位置）と、R の増分の形。
  - 山の位置の誤差は、Voice が落ち着く音程の誤差になる。
  - 誤差 e cent の音程は、重なる倍音 F Hz の所で約 F·e/1731 Hz のうなりを生む（導出）。
  - LOO は自分だけを除くので、他の Voice どうしの近い組や、一つの body の近い mode は LOO の stream にも残る（AUD-R2 H2）。
- **今の水準**：peak は bin に置かれるので、成分の位置は ±6.25 cent に量子化される（`landscape_spectral.rs:90` の `peak.bin_idx`）。H の kernel の平滑は 3 cent（`harmonicity_kernel.rs:67`）で、12.5 cent の格子の上の離散の畳み込みである。
- **刺激**：倍音を持つ Voice の body と Flora の lane が重なる混合。低い F0 は 55 Hz まで。
- **支持区間**：今は窓（低域 341 ms）。新系は filter の記憶と hop。
- **統合**：hop（10.67 ms）と leaky の 10 ms。
- **参照の時刻と使える時刻**：§2.1 のとおり。
- **総遅れ**：証拠の遅れ、hop の量子化、待ち、pitch controller の動き。
  - Burnett ほか（1998）の声の修正の潜時（実験 1 の平均 228 ms、範囲 60〜830 ms、確認済み）は、この総遅れ全体と比べる参照にはなる。
  - ただし前処理の予算ではない。
- **受け入れの形**：§8 V2 の一つの基準による。正解は合成音の成分の一覧から作り、新系の判断の不一致が、今の経路の不一致を超えないことを求める。新しい cent の閾は置かない。

### 3.2 Flora の成長と配置

- **判断**：ERB の cell ごとの biomass の増減と、配置の分布。
- **必要な識別**：cell の幅（ERB の尺度）の level と H01。位置の精度は Voice より緩い。
- **固有の要求**：自分の弱い部分音が、独立した位置として場に残ること（Coupling Contract 3、引き継ぎ §2）。
  - 今は全体の 5% の条件と 32 本の上限で、候補の出現の 72% が落ちる（SF-1、確認済み）。
  - これは候補の出現の脱落の率であって、物理的な部分音の総数の率ではない。
- **総遅れ**：成長の時間の尺度は temporal DCC の拍と basin から決まる（`flora.md`）。閉じた環の遅れの注意書き（`flora.md:119`）は今の NSGT の遅れを前提にしている。新系で遅れが変われば、注意書きの数字を更新する。

### 3.3 出生、発音、habituation、予測、listener

- 出生の分布、発音の level、habituation の駆動、予測の外挿、listener の tension は、場の形を粗く読む。位置の精度は 3.1 より緩い。
- 予測は観測の印（frame end）と前回の観測の差から外挿する。証拠の遅れが短くなれば、外挿の前提（印と証拠の時刻の差が小さい）は今より正しくなる。
- 3.1 の候補の順位が保たれても、場の高さ、質量、時間の差は保たれない（AUD-R3 H4）。だからこれらの判断の保存は、3.1 からは導けない。
  - V2 で判断の保存を確かめるのは、音高、respawn、出生、Flora の四つに限る（§8）。
  - 発音と selection の level と score、habituation、予測、listener は、判断の保存の受け入れに繋がない。H／R／C と level の差を診断として記録し、前処理の変更による行動の変化として登録する。
- **listener の移植**（AUD-M2 追補 2、3）。
  - listener の tension の検証（`tests/listener_twin_validation_fixture.rs`）が、新系で落ちた。落ちた条件は、安定な和音の平均 tension < 0.005、解決と落ち着きの窓の平均 tension < 緊張の窓の半分、の三つ。
  - 第一の原因は、一つの成分を隣り合う二 bin に線形に配る新しい表現にある。listener は bin ごとに改善の余地を数えるので、片方の bin を別の音として読んだ（安定な和音の窓で、部分音の ±6.25 cent の外の質量 15% が resolvability の 86% を生んだ。外の質量の距離の中央値は 11.25 cent）。
  - 旧い front end は peak を一つの bin に置いていたので、listener は暗黙に「成分 = 一つの bin」を前提にしていた。
  - そこで listener を、質量の局所の最大ごとにまとめた成分で数えるように移植した。成分の重みはまとめた質量、level は山の bin の値、改善の余地は成分の外の bin から探す。
  - 閾値、scenario、listener の定数は変えない。成分が一つの bin だけの疎な density では、結果は旧い実装と一致する（27 の場合で差 0）。
- **移植の後に残る差**（AUD-M2 追補 3〜5）。
  - 保存した同じ PCM で、窓ごとの平均 tension は次のとおり（旧は旧い front end と移植した listener の組）。
    - 安定：新 0.0165、旧 4e-23。
    - 緊張：新 0.0285、旧 0.0108。
    - 解決：新 0.0157、旧 6e-18。
    - 落ち着き：新 0.0150、旧 0。
  - 残りの大部分は、上の倍音の成分から来る。安定の窓の 4 hop で、改善の側の寄与の 82〜90% は次の三つの成分だった。
    - E の第 3 倍音（490.5 Hz）。
    - G の第 3 倍音（588.6 Hz）。
    - E の第 5 倍音（817.6 Hz）。
  - これらの成分の質量は全体の 1〜5%。山の level（0.50〜0.68）は、±220 cent の中の候補（523.25 Hz、784.0 Hz、level 約 0.84）より低い。
  - 旧い front end では、同じ部分音の質量がほぼ 0 だった（前の 2 hop で 1e-23 以下、後の 2 hop では成分がない）。listener は事実上、和音の基音だけを評価していた。どの段で消えたかは確かめていない。
  - 統括の見当（ERB 番号の差 0.41 の 490.5／523.2 Hz の組が一つの成分に融合した）は、成分の記録で否定された。この二つは 4 hop とも別の成分だった。
  - ただし 812.8 Hz の山は、784.9／817.6 Hz（ERB 番号の差 0.29）の間にある。分けられない組の限界（§5.4）の影響は除けない。
- **検証の条件の置き換え**（AUD-M2 追補 4、5）。
  - 三つの旧い数値の条件は、上の倍音がほぼ消えた旧い入力に合わせた値で、守る consumer の判断を名指せない。
  - そこで、安定、解決、落ち着きの窓の平均 tension が緊張の窓より小さい、という順序の条件に置き換えた。その他の条件は残した。
- **登録する行動の差。**
  - 安定な和音でも tension が 0 にならない。安定と緊張の対比が弱まる（平均の比は新 0.58、旧はほぼ 0）。
  - listener の「±220 cent の中で動けば良くなる」は、本来は動ける音について立てた考えである。新系では、一つの body に属して単独では動けない部分音にも当たる。
  - listener を音（部分音のまとまり）ごとに評価する直しは、範囲の外として §10 に置く。既定の coupling は 0 なので、既定の生成には効かない。report、UI、coupling > 0 の scenario の値は変わる。

### 3.4 同期の body 解析（既定 off）

- 代表音の単独の render と環境の `mix − own` を同じ前処理に通す。Voice の LOO と同じ連続性が要る。
- IIR の filter は ring に PCM を書くだけでは履歴を保てない。選ばれなかった hop の扱いを §7 で定義する（AUD-R2 H5）。

### 3.5 原典の値の使い方

AUD-R1 §3、SF-1、AUD-R2 の照合を、この設計での役割と一緒に並べる。どれも条件の範囲でだけ使う。

- **ERB**（Glasberg & Moore 1990）
  - 丸めた式は 24.7(4.37 f/kHz + 1) Hz、AMT は 24.673(0.004368 f + 1)。T2 と新系は 24.7 + f/9.265 を使う（確認済み）。
  - 帯域幅の尺度であり、二音を分ける保証ではない。
  - この設計では、末梢の帯域の上限（β = 1）と、帯域の尺度に使う。
- **4 次の gammatone の帯域の係数 1.0186**
  - ENBW を ERB に一致させる値（16/(5π)、導出、AUD-R2 で再計算）。T2 の `t2.rs:161` と同じ。
  - AMT の `hohmann2002` の `bandwidth_factor = 1.0` は、この変換の後の ERB 幅をさらに拡縮する指定で、対立する既定ではない（AUD-R2）。
  - 新系の帯域は、この ERB 幅にさらに β を掛ける。
- **分けられる倍音の数（約 10 次）**（Bernstein & Oxenham 2003、Shackleton & Carlyon 1994）：条件付きで、本数の固定には使わない。
- **粗さの変調の範囲 15〜300 Hz、最大 70 Hz 前後**：1 kHz、100% AM の条件の値。硬い境界は無い。この設計では分離の要求に使わない（§5.4）。
- **部分音が別の音として聴こえる閾 1〜3%**（Moore, Glasberg & Peters 1986）：等振幅の 10〜12 本、各 60 dB SPL、410 ms の条件。許容誤差には使わない。
- **部分音を聴き分けられる間隔**（Moore, Glasberg, Low, Cope & Cope 2006、JASA）：ERB 番号で等間隔に並べた非調和の複合音で、内側の部分音の聴き分けの成績は 0.75 ERB の間隔でほぼ偶然の水準、間隔を 2 ERB まで広げるにつれて上がる。要旨で確認（本文は未照合）。この設計では、V2 の「分けられる分類」と「分けられない分類」の境（0.75 ERB）に使う（§8）。
- **純音の弁別 0.2〜0.5%**（Wier ほか 1977）：未照合。使わない。
- **声の修正の潜時**（Burnett ほか 1998）：総遅れの参照だけ（3.1）。
- **手拍子の同期の 8〜25 ms**（Chafe ほか 2010）、**時刻の弁別**（Friberg & Sundberg 1995）：時間の経路の量。H／R の前処理の要求には使わない。
- **相対マスキング**（Parncutt & Strasburger 1994、Eqs. 2〜7、SF-1 が式を照合）
  - 新系の段にはしない。理由は、それを使う consumer の判断が今は無いことと、成分の一覧を作る推定と検証の費用。
  - 数値実験の比較では簡略の式（勾配 12 dB/ERB、LTFAT の ERB の距離）だけを使った。原典の h(f) と T(f) を使う式とは同じでない（AUD-R2 M3）。
- **specific loudness の指数 0.23**：今の既定値（`config.rs`）。Zwicker の specific loudness の式の指数とされる（Zwicker & Fastl の式 8.5 の二次の引用で確認、原典のページは未照合）。今の慣行として保つ。
- **臨界帯域の中での loudness の加算**（Zwicker, Flottorp & Stevens 1957、JASA 29, 548–557）
  - 原著の要旨で確認できたのは次の範囲：純音の群の間隔、または一定の SPL の雑音の帯域を広げた時、臨界帯域の幅までは loudness がほぼ一定で、それを超えると増える（AUD-R2 が原著の公開版で確認）。
  - 新系の S5 の圧縮は、この着想に沿って作った工学の則であり、原著から導いた式ではない（§5.5）。

## 4. 前の二つの試み

AUD-R1 M5 のとおり、二つは別の試みである。

- `67a5c81`（2025-10-23）：解析信号 → Hann → FFT の power → `potential_r_from_psd_direct`。包絡から粗さを出すのではなく、候補の周波数に沿う潜在の R に戻る形。
- `cochlea.rs`（2025-10-04 の `a5fbe8b6` で入り、2025-11-09 の `b0011ce` で削除）：heterodyne → 複素 LP の 4 段 → 包絡 → 平均で正規化 → HP 20 Hz → 任意の LP 300 Hz → RMS。
- 履歴の順は、cochlea（10-04）、kernel の畳み込みの R（10-22）、Hilbert 版（10-23）、NSGT（10-25〜10-30）、cochlea の削除（11-09）。
- 失敗の理由（作者、2026-10-24）：raw NSGT と gammatone で実装した時は、H の山がなまったので採らなかった。

新系は、どちらとも次の点で違う。
- 粗さを包絡から直接作らない。潜在の R の意味は、今の kernel のまま保つ（§5.4）。
- 複素の filter の出力は、包絡ではなく位相の進みを読む。
- 圧縮の前に、power を位置へ移す。

**なまりの原因と新系での扱い。**
- 二つの試みは、成分の power を分析の帯域の幅に広がったまま H に渡していた。
  - cochlea.rs は ERB 幅の channel の中心で包絡の power を読んだ。一つの部分音が約 1 ERB（1 kHz で約 230 cent）にわたって現れる。
  - raw NSGT は窓の主 lobe の幅に power が広がる。今の経路の peak の抽出は、この広がりを一点に畳むための手当てだった。
- 新系は、位置を channel の位相の進みから取り、分けられる成分の質量を隣り合う二 bin（12.5 cent 以内）に集める（§5.3、§5.5）。filter の幅が決めるのは、どの組を分けられるかだけで、H の入力の幅ではない。
- 帯域が分ける力を決めることは、M1 で確かめた（§5.2）。β = 1（ERB 幅）では、倍音列の 1〜8 次の位置の誤差が最大 25 cent、β = 1/4 では 0。V2 の倍音列の音高の不一致は、β = 1/4 で 0、今の経路で 536。
- 作者は GUI で、新系の H の山がなまっていないことを確かめた（2026-10-24）。
- なまりや位置のずれが残る場合は三つ。どれも登録した差と限界である。
  - 0.75 ERB 未満の組は一つの質量に融合し、その中間に置かれる（§5.4）。倍音列では、F0 110 Hz で約 1.13 kHz（約 10 次）より上、220 Hz で約 2.5 kHz（約 11 次）より上の隣り合う部分音がこれにあたる。
  - 低い帯域の onset の後、約 100 ms は位置が過渡的に配り直される（§5.2）。
  - 強い成分の近くの弱い成分の位置は、強い方へ寄る（§11）。

## 5. 原理からの導出

### 5.1 引き換えの所在

今の NSGT の帯域の ENBW は、4 項 Blackman–Harris の係数から 2.00435·fs/L（SF-1、確認済み）。L = min(80·fs/f, 16383)。

| 周波数 | L | ENBW | ERB | 比 |
|---|---|---|---|---|
| 110 Hz | 16383 | 5.9 Hz | 36.6 Hz | 6.2 |
| 440 Hz | 8727 | 11.0 Hz | 72.2 Hz | 6.6 |
| 1 kHz | 3840 | 25.1 Hz | 132.6 Hz | 5.3 |
| 8 kHz | 480 | 200 Hz | 888 Hz | 4.4 |

今の窓は、人の聴覚の filter より 4〜7 倍狭い帯域で近い成分を分けようとしている（導出）。その代償が長い窓で、作者の言う「周波数の解像度を上げると時間の遅れが著しくなる」はこれである。一方で bin に置いた位置は ±6.25 cent に量子化され、位相を捨てているので、長い窓でも位置の精度は上がらない。

新系では、位置の精度は位相が担う（§5.3）。帯域の幅が担うのは「分ける力」だけになり、引き換えは分ける力と遅れの二つに減る。

### 5.2 分ける力と帯域の係数 β

**試作の反例。** AUD-M1 の最初の取得（追補の前の推定量、β = 1、`.orchestration/aud-m1/report.template.md`、worktree の中の記録）では、次のようになった。
- 220 Hz と 271.16 Hz（1 ERB 差、等振幅）の二音で、330 Hz の近くで選ぶ候補が正解（329.6 Hz）から 12〜125 cent ずれた。構成は 1/4 と 1/2 ERB、S1 の有無の 4 通り。
- 今の経路は正解と一致した。
- 平均では、新系の方が今の経路より正解に近かった。音高の平均の距離は 90 cent 対 217 cent、山の入れ替わりは 761 対 1436。
- 近い組、弱い音、低い F0 の倍音列では、繰り返し今の経路より遠かった。

ERB 幅の filter では、1 ERB 離れた成分が同じ channel に入り、間の channel の質量は中間の位置へ移る。位相を使っても、一つの channel に二つの成分が入ればその間を分けられない（AUD-R1 H2 の解析的な反例）。

**H の kernel が要るもの。** H の common root（Terhardt 型の virtual pitch に近い考え方）は、聴こえる成分の正確な位置を前提にしている。末梢の ERB の filter だけでは、1 ERB 前後の成分の位置をこの精度で出せない。そこで、ERB を帯域の尺度にした、consumer のための狭帯域の分析にする。
- 実装は、帯域を β·ERB にした一つの 4 次の gammatone。AMT の Hohmann の構成も、4 次の filter の帯域に係数を掛ける操作を持つ。
- ERB の 4 次の filter に別の狭帯域の filter を重ねた cascade とは、一般には同じでない（AUD-R3 M2）。神経の位相同期の時間積分の model でもない。
- β は consumer の判断から選ぶ工学の量である（DCC 地図 §6 の「標本の格子と計算の予算」と同じ扱い）。

**数値実験**（`AUD-1/beta_v8.py`）。予備の指標を使った。理想の解析信号の入力で、質量を |S| から取り（§5.6）、H の kernel の平滑と同じ幅（3 cent）の連続の Gaussian で平滑した後に、真の位置の ±100 cent の中で山を探す。β ごとに乱数の列が進むので、β の間で二音の格子の位置と位相は同じではない（AUD-R3 H1）。同じ入力での比較は V2 で行う。山の位置の誤差の最大は次のとおり。

| β | 220/271 の組 | 等振幅の二音（220 Hz、0.75／1.0／1.5 ERB） | 等振幅の二音（1 kHz、同） | 1/h の 12 倍音の 1〜8 次（F0 110／220） |
|---|---|---|---|---|
| 1 | 13.8 cent | 82／82／9.3 | 89／16／4.5 | 最大 25 cent |
| 1/2 | 4.8 | 22／13.5／0.3 | 5.0／1.3／0.3 | 最大 2.3 |
| 1/3 | 2.0 | 10.8／2.0／0 | 0.5／0.3／0 | 最大 0.3 |
| 1/4 | 0.3 | 1.8／0.5／0 | 0.3／0／0 | 0 |

この指標は H の consumer の判断の代わりではない（AUD-R2 H3）。H の下方と上方の投影、自己項の補正、12.5 cent の格子への配分を通していない。β の採否は V2 で行う。

**遅れ。** 4 段の cascade の中心周波数の群遅延は 4r/(fs(1−r)) で、b/fs が小さい時は約 4/(2πb)（b = β·1.0186·ERB、導出、AUD-R2 で確認）。hop の平均（重心 5.3 ms）と leaky の 10 ms（5.6 ms）を足した証拠の重心の遅れ：

| β | 55 Hz | 110 Hz | 220 Hz | 440 Hz | 1 kHz | 4 kHz | 8 kHz |
|---|---|---|---|---|---|---|---|
| 1 | 31.3 ms | 28.0 | 23.8 | 19.5 | 15.6 | 12.2 | 11.6 |
| 1/2 | 51.7 | 45.1 | 36.7 | 28.2 | 20.3 | 13.6 | 12.3 |
| 1/3 | 72.1 | 62.1 | 49.6 | 36.9 | 25.0 | 15.0 | 13.0 |
| 1/4 | 92.5 | 79.2 | 62.5 | 45.5 | 29.7 | 16.4 | 13.7 |
| 今の NSGT | 191.4 | 191.4 | 190.1 | 103.8 | 49.4 | 17.6 | 12.3 |

新系の行は、離散の式 4r/(fs(1−r)) に hop の重心 5.323 ms と leaky の重心 5.597 ms を足したもの。今の NSGT の行は、窓の重心、帯域の leaky、front end の leaky の和（導出、AUD-R3 が再計算で確認）。どれも線形の段の重心であり、非線形の段（再配置と圧縮）、S1、publish を含む応答の時刻ではない。

**β の選び方（追補 3 の時点の規則）。** V2 の基準を「分けられる分類」（0.75 ERB 以上、§8）のすべての consumer で満たす中で、一番大きい β（遅れが一番短いもの）を採る。channel の間隔は、1/4 ERB と 0.75·β ERB の小さい方にする。この規則では追補 6 の 4 構成とも未達だった。現行の扱いは「改訂した工学の目標と暫定の候補」（下）と §8。

**試作の結果**（AUD-M1、追補 3 の固定の手順、49 の入力を同じ bytes で 8 構成に通した）。分けられる分類で基準を満たさなかった consumer は次のとおり（実数の入力と S1 で同じ）。
- β = 1：二音で音高、respawn、Flora、出生。倍音列で Flora、出生。弱い音で respawn。
- β = 1/2：二音で respawn、Flora、出生。弱い音で respawn。
- β = 1/3、1/4：無し。
- 倍音列の音高の不一致は、β = 1/3 と 1/4 で 0、今の経路で 536。

よって β = 1/3 を採る候補とする。S1 なしでも満たしたので S1 は置かない。

**分解能、観測の長さ、帯域の設計の則**（追補 5、6 の後）

その後の取り直しで、110 Hz と 150 Hz の組（1.03 ERB、LOO の残りの組）が、β = 1/3 でも今の経路より正解から遠かった。段ごとの切り分けで、原因は二つと分かった。
- hop の窓の中でうなりの交差項が平均されず、位置が一次で揺れる（§5.3）。
- 混ざった channel の中間の位置の質量が、圧縮で持ち上がる（§5.5）。

そこで、次の三つを設計の則として置く。どれも工学の則であり、人の生理の下限や、情報の上で必要な時間を導いたものではない（AUD-R4 H2）。
1. **分類の境**：0.75 ERB。Moore ほか（2006）の、ERB 番号で等間隔に並べた非調和の複合音の内側の部分音の聴き分けの実験（0.75 ERB でほぼ偶然の水準、2 ERB まで間隔とともに上がる）を参考に登録した境である。任意の二音、倍音、音量、onset の条件に共通の分離の限界ではなく、「これ以上なら人は分ける、未満なら分けない」という二値の保証でもない。
2. **統計の窓**：channel ごとに T_c = 1/(0.75·ERB(f_c)) を hop の整数倍に切り上げた boxcar（n_c = max(1, ceil(T_c/hop)) 個の hop）。境の間隔の組のうなりの交差項を抑えるための則である。N sample の矩形の和に残る交差項の係数は D_N(Δ) = sin(πNΔ/fs)/(N sin(πΔ/fs)) で、一周期以上にしても 0 にはならない（AUD-R4 の計算：110 Hz 付近の 4 hop、42.7 ms の窓で、40 Hz の差に対して約 0.149）。
3. **帯域**：境の間隔を帯域の約 3 倍（4 次の gammatone で漏れ約 −39 dB）にする目安から β ≈ 1/4。厳密に 3 倍以上なら β ≤ 0.2454。β = 1/3 では 2.2 倍（約 −31 dB）。「3 倍」「−39 dB」は人の実験から出た条件ではなく、V2 の consumer の比較で採否を決める候補の目安である。

統計の窓の重心の遅れは n_c·hop/2。帯域の群遅延と leaky を足した遅れ（計算値）：

| 構成 | 110 Hz | 220 Hz | 440 Hz | 1 kHz | 4 kHz |
|---|---|---|---|---|---|
| β = 1/3、統計の窓あり | 約 78 ms | 約 60 | 約 42 | 約 25 | 約 15 |
| β = 1/4、統計の窓あり | 約 95 ms | 約 73 | 約 51 | 約 30 | 約 16 |
| 今の NSGT | 191.4 | 190.1 | 103.8 | 49.4 | 17.6 |

**選んだ構成**（AUD-M1 追補 6、49 の入力を 4 構成に通した）

構成：**β = 1/4、統計の窓あり、P_cb は ERB 版（§5.5 の (e)）、S1 なし**。仕様は §6.0 にまとめた。

試作の中心の channel について計算した遅れ（群遅延 + boxcar の重心 + leaky）は次のとおり。信号の応答や consumer の利用の時刻を測った値ではない（AUD-R4 M3）。

### 5.3 一つの成分の周波数

channel の複素の出力 z[n] について、hop の中の S = Σ z[n]·conj(z[n−1]) の偏角から、瞬時周波数 f̂ = fs·arg(S)/2π が出る。一つの定常な成分が channel を占めていれば、f̂ はその成分の周波数に一致する（導出、数値実験で誤差 0）。

隣の成分が漏れると偏る。最も近い channel で、隣の成分の振幅の比が r なら、偏りは約 r²Δ/(1 + r²)（Δ は周波数の差）。成り立つ条件は二つ：交差項が統計の窓の中で平均で消えること、sample の間の位相の差が小さいこと（AUD-R2 で確認）。

うなりの周期が統計の窓より長い組では交差項が消えず、位置はうなりの位相に応じて一次の大きさ（約 r·Δ）で揺れる。試作の切り分け（AUD-M1 追補 5）では、110 Hz と 150 Hz の組（40 Hz のうなり、周期 25 ms）が、hop（10.7 ms）の窓で数 cent から 10 cent ほど揺れた。だから統計の窓を、分類の境（0.75 ERB）の間隔の組のうなりの一周期まで延ばす（§5.2）。一周期でも交差項の係数は 0 にならず、有限の窓の D_N に応じて残る。

β = 1 で、等振幅の隣が片側にある時（`AUD-1/derive.py`）：
- 1 ERB：−11.7 dB の漏れ、1 kHz で 14 cent。
- 2 ERB：−27 dB、0.8 cent。
- 3 ERB：−39 dB、0.08 cent。

β を掛けると、同じ ERB の距離が 1/β 倍の帯域の距離になる。たとえば β = 1/3 なら、1 ERB の隣は帯域の 3 倍の距離で、漏れは −39 dB になる。

AUD-R1 H2 のとおり、瞬時周波数は一つの成分が channel を占める時だけの推定量であり、二つの成分の一覧は返さない。分けられない組では、質量の位置は hop の中のうなりの位相で揺れ、組の外へ出ることもある。たとえば 1000 Hz と 1015 Hz、振幅の比 0.5、hop の中央で逆相の二成分を channel の出力とすると、S の偏角は約 988.2 Hz を返す（AUD-R3 の計算）。これを一般の「未分離の表現」とは呼ばない（AUD-R2 H2）。

### 5.4 分けられない組と R

潜在の R は「候補の位置に単位の純音を一本足した時の粗さの増分」で、今鳴る音どうしの粗さではない（`roughness_kernel.rs:322`、AUD-R1 M1）。単位の純音と既存の成分 j の組ごとの増分の和 Σ_j g(x − y_j)·m_j として計算される。

**融合の誤差。** 既存の二成分 y₁、y₂ を質量を保ってその重心 ȳ に融合し、対象の区間で g の二階微分が有界なら、一次の項が消え、誤差は二次の moment で抑えられる（導出）。ただし次の二点で、この評価だけでは済まない（AUD-R2 H2）。

- 新系の位置は有限の hop の位相の推定で、質量の重心とは限らない。圧縮も近い組の質量を変える。
- 今の kernel には狭い unison の谷（`suppress_sigma_erb = 0.06`、`g(0) = 0`）がある。
  - 1000 Hz と 1015 Hz の等質量の組を重心に融合すると、重心で元の組から受ける R は正なのに、融合の後は 0 になる。AUD-R2 の再計算では、合計の質量 1 の組の重心で約 0.165 対 0。
  - 融合は粗い位置に偽の谷を作る。

**LOO でも融合は残る。** Voice A の LOO は A だけを除くので、他の Voice B と C の近い組や、一つの body の近い mode は残る。

**今の経路との比較。** 今の経路も、1 kHz の 15 Hz の組は 16384 点の窓で一本に融合する（SF-1）。低い帯域では、今の長い窓が分けている。β を小さくすると、融合する距離は β に比例して縮む。

**要求の置き換え。** 以上から、SF-1 の「15 Hz 離れた二音を分ける」という固定の分離の要求は、次の判断の試験に置き換える。
- V2 の入力に、LOO で A を除いた後に残る近い組（110 Hz 付近と 1 kHz 付近、15 Hz と 40 Hz の差）、近い mode を持つ body、LOO の無い音高、respawn を含める。
- 新系の R の場と判断を、今の経路と並べる。

**試作の結果と原理による分け方**（AUD-M1、追補 3 の固定の手順）
- どの β（1、1/2、1/3、1/4）でも、15 Hz の組、LOO の近い組、近い mode の body で、完全な分解の正解との判断の一致は今の経路に及ばなかった。今の NSGT は 110 Hz で帯域 5.9 Hz の窓（重心の遅れ約 171 ms）を使い、これらの組を分けている。
- 低い帯域でこれらの組まで分けるには、帯域を今の窓と同じ程度に狭くする必要があり、遅れも同じ程度になる。時間と周波数の物理の制約で、位相を使っても消えない。作者が最初に挙げた引き換えそのものである。
- これらの組の間隔（110 Hz の 15 Hz で 0.41 ERB、1 kHz の 15 Hz で 0.11 ERB、40 Hz で 0.30 ERB）は、登録した分類の境（0.75 ERB、§5.2）より狭い。
- そこで、要求を人の聴覚から導く方針（作者の問い「人間の聴覚認知から定量的に導けるのでは」）に従い、0.75 ERB 未満の組を分けることは要求にしない。完全な分解の正解は、この範囲では人の知覚の参照ではない（AUD-R3 も同じ指摘）。
- 残る問題は、融合した組の内側の偽の協和の山（R の偽の谷）である。R は候補の位置に単位の純音を足した時の潜在の量で、今鳴る二音の知覚の粗さではない（AUD-R4 M2）。偽の谷は、まず採用した潜在の R と完全な分解の参照との差として示す。
- 試作では、広がりの変種（§6.2）でも谷は埋まらなかった（AUD-M1 追補 5）。一つの hop の遅れ L の整合度では、15 Hz のうなり（67 ms）が見えない。
- 原因は、R の kernel の狭い unison の谷（`suppress_sigma_erb = 0.06`、110 Hz で約 2 Hz、1 kHz で約 8 Hz）と、解析の分解能の食い違いにある。この谷の幅から見積もると、低い帯域で組の内側を知るには 0.5 s 程度の観測が目安になる（設計の目安で、普遍的に必要な観測の長さではない）。別の道として、組の粗さを包絡のうなりから作ること（作者が以前「いまそれができるなら、そっちのほうがよい」と言った方向）があるが、それを潜在の R に反映するには、どの consumer がどの規則で読むかを決める必要がある。
- どちらも初期の範囲（§10 の作業の前提 2）の外なので、偽の谷は門にせず、**登録した限界**として測って記録する（今の経路との比較を含む）。範囲を広げるかは作者の判断にする（§10）。
- 0.75 ERB 未満の組での音高、respawn、出生、Flora の判断の変化も、前処理の変更による行動の変化として登録する。sample の行動が変わりうる（近い mode を持つ鐘のような body、わずかにずれた unison）。

組そのものの粗さ（今鳴る音の粗さ）は、組を二つの位置に分けなくても、その組が入る channel の包絡のうなりに現れる。包絡は tap B から読める（§6.1）。今その量を判断に使う consumer は無い。`roughness01_scalar` は assay と report だけで読まれている。

### 5.5 再配置と圧縮（S4〜S5 の定義）

**再配置。** 各 channel c の hop の統計 S_c から、質量 |S_c|/N と位置 f̂_c を取る（N は hop の sample 数）。質量を filterbank の全体の利得 G(f) = Σ_c |H_c(f)|² で割って f̂_c に移す。
- 一つの定常な成分だけの時、移した power の合計はその成分の power に一致する（導出）。
- 複数の成分がある時、channel を占める成分の所へ、その channel の power が集まる。

これは reassignment（Auger & Flandrin 1995）の値の移動による局在化と同じ考え方で、公表された方法をそのまま採ったものではない（AUD-R2 で確認）。synchrosqueezing（Daubechies, Lu & Wu 2011）の分離と再構成の保証は、この hop の統計には引き継げない。

**圧縮。** 今の subjective intensity の定義は、peak ごとに (P·A_w/P_ref)^0.23。channel ごとに先に圧縮すると、遠い channel の裾（−100 dB）が重みを持ちすぎる（数値実験の v1、単音の位置が 300 cent 以上ずれた）。そこで、各 deposit の圧縮を、その位置の臨界帯域の power で決める。

**単位。** power は「実数の信号の平均二乗」にそろえる。
- E_c = 2·mean|z|²、deposit の power は d_k = 2|S_c|/N。
- 係数 2 は、振幅 a の正弦の正の周波数の側の |z|² が a²/4 になることによる。S1 なしの実数の入力と、試作の S1（(H2 + iH1)/2）のどちらでも同じ係数になる。違えば試作で直す。
- S1 なしでは負の周波数の像が残り、有限の hop では交差項も残るので、任意の実数の単音でこの換算が厳密になるのではない。

**順序。**
1. deposit k（位置 x_k、移した power d_k）について、臨界帯域の power P_cb(x_k) を作る。二つの変種を V2 で比べる。
   - (n) 狭い channel 版：x_k を挟む二つの channel の E_c/|H_c(x_k)|² を ERB 番号で線形に補間する。β < 1 では、これは臨界帯域の power ではなく、帯域 β·ERB の power である。混ざった channel が中間の位置に置いた小さな質量を、独立の弱い成分のように持ち上げる（試作の切り分け）。
   - (e) ERB 版：P_cb(x) = Σ_j d_j·|H_ERB,x(x_j)|²。|H_ERB,x|² は x を中心とする帯域 1.0186·ERB(x) の 4 次の gammatone の power の応答で、移した power を臨界帯域の幅で重ねた励起の pattern にあたる（Moore の loudness model が細かい spectrum から励起の pattern を作るのと同じ考え方）。臨界帯域 = ERB とする Zwicker の加算の着想には、こちらが合う。強い成分の臨界帯域の中の弱い成分の質量は減る（マスキングに似た効果）。
   - どちらも、孤立した定常の単音では、その成分の power に一致する。
2. P_cb(x_k) と d_k の大きい方を P_cb とする（下限）。範囲の端で挟む channel が一つの時は、その一つを使う。P_cb = 0 の deposit の重みは 0 とする。
3. 床の gate γ_k を掛ける（§5.6）。
4. 重みは γ_k·(d_k/P_cb)·(A_w(x_k)·P_cb/P_ref)^0.23。A_w は deposit の位置で評価する（今の peak の位置で掛けるのと同じ意味）。
5. 重みを Log2Space の隣り合う二 bin に線形に配り、du で割って密度にする。
6. 推定の位置が負、0、または端の bin の中心より外の deposit は、端の bin へ置く。重みには、外側への距離が一 bin の幅に達するまで線形に 0 へ落とす係数 max(0, 1 − 距離/bin の幅) を掛ける。それより外は 0。

**性質。**
- 床が無く、入力が理想の解析信号で、成分が定常の単音なら、重みの合計は今の peak ごとの定義と一致する（導出）。それ以外の条件での一致は主張しない。
- 今の `peak.mass` も、正弦の平均二乗そのものではない。NSGT の各 bin から閾を通って集まった power で、窓の応答、格子、抽出、bin の位置の A_w を含む。旧い front end との単音の比較は試作で取り、共通の倍率と周波数に依存する差を分けて記録する。
- 一つの臨界帯域に入る二つの成分は、強さを足してから圧縮される傾向を持つ。帯域の外へ離れた成分は、別々に圧縮されて足される。Zwicker, Flottorp & Stevens（1957）の着想に沿うが、二 channel の逆補間は有限の hop の干渉を消さないので、厳密な区分の則ではない。この式は原著から導いたものではない（§3.5）。
- 混合では、今の peak ごとの質量と一般には一致しない。これは設計の変更として V2 で扱う。

A_w は今の A-weighting をそのまま使う（今の慣行）。外耳・中耳の伝達のモデルへ替えることは、この設計の範囲に入れない（AUD-R1 M2）。

**計算量。** G(f) は事前の表と補間で求め、|H_c(x)| は挟む二つの channel の分だけ計算する。これで S4〜S5 は channel の数に比例する。数値実験の Python は C×C の応答を作るので O(C²) だった（AUD-R2 H5）。近似を入れたら、その誤差を V2 の中で評価する。

**弱い成分の扱い**（数値実験、β = 1、局所に帰属した質量の抑えの診断）。弱い成分が強い成分の近くにあると、弱い成分の channel は強い成分に占められ、その power は強い成分の位置へ移る。1 kHz の音の 1.5 ERB 上の弱い音で、真の位置の 1 ERB 以内に帰属した質量の比は次のようになった。
- −5 dB で 1.08
- −10 dB で 0.88
- −15 dB で 0.45
- −20 dB で 0.07
- −30 dB で 0

位置は強い音の方へ 30〜150 cent 寄る。これはマスキングの model ではなく、0 は「真の位置の近くに帰属した質量が無い」という意味で、可聴性ではない。β を小さくすると弱い成分も分けられるので、この抑えは弱まる。全体に対する 5% の条件と 32 本の上限は無くなる。

**採らなかった案。**
- channel の利得で遠い channel を抑える案（v5）：混合音で質量が保存されなかった。
- 遅れ L の整合度から広がり σ を読み、対称の二点に分ける案（`AUD-1/spread_v7.py`）：倍音列の山を 20〜58 cent ずらした。漏れの小さな成分でも整合度が下がり、支配的な成分が割れるためである。

### 5.6 連続性

Flora と B-1 の PCM oracle の門（§2.3 の 3）は、丸め誤差の差の入力から作った二つの場が、bin ごとに 1e-3 以内で一致することを求める。

**版 1 の主張の誤り。** 版 1 は「各段が連続なので門は自動的に通る」としたが、これは誤りだった（AUD-R2 H1）。
- **S が 0 になる反例**：E と S を別々に使うと、E > 0 で S = 0 になる入力がある。無音の後、hop の最後の sample に impulse を入れると、その hop の出力は最後の sample だけが非ゼロになる。その直前の二つの sample を 1e-9 の程度で変えると、S の偏角を任意の方向へ向けられ、質量が 1000 Hz と 2000 Hz の間を跳ぶ。
- **圧縮は 0 の近くで Lipschitz でない**：P^0.23 は 0 の近くで Lipschitz 連続ではなく、密度と H の正規化は小さな質量の誤差を増幅する。

**版 3 の構成。**
- **質量と位置を同じ複素数から取る。** 質量 |S|、位置 arg S なので、S が 0 に近づくと質量も 0 に近づく。
  - 対象の周波数の区間で G が正の下限を持ち、A_w が有界で、P_cb ≥ d なら、圧縮の後の質量は定数倍の d^0.23 以下になる（AUD-R3 で確認）。だから E が非ゼロのまま位置だけが変わる旧い反例の、有限の質量の跳びは抑えられる。
  - これは S の零点の近くの局所の改善であり、全段の連続性の証明ではない。数値実験（`spread_v7.py`）の impulse の例の 6e-5 は、採らなかった二点の分割も使った処理の、deposit 一本の最大の差である。総質量は 0 から約 0.0023 へ変わり、摂動も複素の入力で、AUD-R2 の実数の PCM の反例そのものではない（AUD-R3 M1）。
- **連続な床の gate。** `mix − own` の丸め誤差の残り（振幅で信号の 1e-6 程度）が 0.23 乗で目立つ質量にならないように、deposit ごとに γ_k = max(0, 1 − T/ρ_k) を掛ける。
  - ρ_k = P_cb(x_k)/du(x_k)。du はその位置の Log2Space の bin の ERB 番号の幅（隣り合う二 bin を補間）。
  - T は今の peak 抽出の絶対の床（`PeakExtractConfig::nsgt_default` の 1e-6）。今の床は「NSGT の bin の power を du で割った密度」に掛かるので、ρ_k を「その位置の臨界帯域の power を一つの bin の幅に置いた時の密度」として単位をそろえた。
  - gate は P_cb で決まるので、一つの deposit をいくつに分けても同じ値になる（減算の床 max(d − F, 0) はこれを満たさず、利得の斉次性も壊すので採らない。AUD-R3 H3）。
  - gate を掛けると、利得の不変は P_cb ≫ T·du の領域での近似になる（§5.8）。
  - 床の役割（丸めの残りを抑えること）との対応は V3 で確かめる。
- **閾値の判定を置かない。** 完全な窓の支持、局所の床、候補の採否のような離散の判定は置かない。SF-1 の v4 の Flora の門の不合格は、これらの判定で説明できると考えられる（推測。記録は門の不合格だけで、原因は特定していない）。
- **範囲の外の位置。** §5.5 の 6 の端の扱いで、範囲の外へ出る deposit は連続に 0 へ落とす。G で割ることは filter の減衰を逆に補正するので、filter の減衰だけでは範囲の外の deposit の小ささを保証しない（AUD-R3 M1）。

**残る不連続。**
- 偏角の枝（推定の位置が ±fs/2 をまたぐ所）。端の扱いで範囲の外の deposit は 0 になるので、最終の scan には出ないと見込む（試作で確かめる）。
- 共有の密度の正規化の床。固定した形の非ゼロの密度を拡大して総質量が eps を越えると、H は 0 から peak で正規化された場へ跳ぶ。前段の連続な床ではこの性質は消えない。今の門の扱いのままにする（§6.5 で正規化を変えないため）。

**主張の範囲。** 全入力での数学的な連続性は、受け入れの条件にしない。S の零点の近くの改善、既存の床を含む運用の許容差、既存の門を分けて扱う。V3 で、今の門と、AUD-R2 と `spread_v7.py` の二つの onset の反例を、実際の density と H／R／C の差まで通して判定する。

### 5.7 遅れと warm-up

**証拠の遅れ。** §5.2 の表のとおり。β が決まれば、帯域ごとの遅れが決まる。

**使える時刻は変わらない。** hop K が frame K−1 を読む。

**帯域の遅れは揃えない。** 蝸牛の進行波と同じく、低い帯域ほど証拠が古い。AMT の Hohmann の delay は再合成用で、認知の整列に採らない（AUD-R1 H4、ledger §9.3.13〜§9.3.14）。

**gap の後の publish は、今の規則のまま。** 混合と listener の stream は、UI、spectral history、研究の tap のために NSGT の power を計算し続ける。gap の後の publish の規則は、今の `window_samples()`（nfft 16384、341 ms）のままにする。これは旧い NSGT の窓の支持を保つための publish の規則であり、新系の IIR の回復の精度を決める規則ではない（AUD-R3 M4）。
- 版 1 の「インパルス応答の残りの energy 1e-7、約 85 ms、f32 で一致」は撤回する。energy の残りと振幅の残りを取り違えていた。残りの energy 9.98e-8 は振幅の残り 1.9e-4 にあたり、0.23 乗の圧縮の後では質量の約 2% になる（AUD-R2 H4）。
- 新系の filter は IIR で有限の窓を持たないので、回復は近似である。連続時間の 4 次の filter で、中心周波数の定常の音を止めた後の振幅の残りは exp(−u)·Σ_{k=0..3} u^k/k!（u = 2πbT）。T = 341 ms で質量の比（0.23 乗）に直すと次のとおり（AUD-R3 の計算）。
  - 最低の中心 14.6 Hz：β = 1/4 で約 2.6%、β = 1/3 で約 0.42%。
  - 55 Hz：β = 1/4 で約 1.1%。
  - 床、再配置、S1、S6、H／R／C を含まない値で、最終の score の失敗を示す数ではない。
- 選んだ β と余白の、最も遅い channel の残りを V4 で数える。余白の最低の channel を減らせば残りは減る。
- 主の habitat の gap と deterministic な listener の無効化は run を終えるので、この回復が効くのは実時間の listener などに限る。listener は既定で report と UI だけに使われる。
- LOO の observer に NSGT を残す必要は無い。ただし worker の共通の待ちの規則と、出生の時の状態の複製は保つ。

**ステップの応答**（数値実験、β = 1、6 倍音の複合音、真の倍音の 1 ERB 以内に帰属した質量の初回の到達）
- 新系：10／50／90% が、root 110.7 Hz で 10.7／10.7／21.3 ms、root 1003.1 Hz で 10.7／10.7／21.3〜32 ms。
- SF-1 の「主観の質量」とは測り方が違う（AUD-R2 M3）。S6 の scan、H／R／C、publish、位置の収束、因果の S1 の遅れを含まない。優劣の比較には使わない。

**準拠の注意。** 遅れは遅れの予算を新しく置いた結果ではなく、帯域の選び方の結果として出てくる。DCC 地図 §6 のとおり、知覚の統合・分解能と解析の遅れを別に記録する。

### 5.8 音量によらないこと

- 履歴の全体に一定の利得 g を掛けると、S と E は g² 倍、位置は不変。床の gate が無い理想の式では、重みは g^0.46 の共通の倍率になり、H と R の正規化で消える（導出）。
- 床の gate γ_k は利得で変わるので、実際の新系の不変は、P_cb ≫ T·du の領域と §2.3 の 2 の条件（正規化の eps を十分上回る、既定の `gamma_root = 1`、利得を途中で変えない）での近似である。今の経路の床と eps と同じ種類の近似で、厳密な不変は主張しない。
- 線形の filter と、冪の圧縮と、相対の比較だけで作るので、再生の音量の仮定は要らない。
- 代わりに、音量に依存する現象（level で帯域が広がる tuning、上への広がりのマスキング、絶対の閾、level に依存する粗さ）は、受け入れの範囲の外になる。これを含めるには、非線形の蝸牛のモデルと音量の仮定が要る（§10 の判断 1）。

## 6. 初期の構成

### 6.0 選んだ構成の現行の仕様

M2 で演奏の経路へ移す時の定義はこの節にまとめる。§5 の数値と過去の版の構成は、根拠と履歴として残す。試作は branch `research/auditory-system-20261023` の `src/core/auditory_shadow*.rs` と `auditory_statistics.rs`（test の中だけ、commit `90f06fa1` 以降）。

- **入力**：実数の PCM（S1 なし）。
- **filter**（S2）
  - 4 次の複素 one-pole の cascade、正の角度の pole、各段の利得 1 − r（中心で利得 1）。
  - 帯域 b = β·1.0186·(24.7 + f_c/9.265)、β = 1/4。
  - 係数は f64 で作って f32 に丸め、状態と sample ごとの演算は f32。
- **格子**
  - 1000 Hz を基準とした LTFAT の ERB 番号 9.2645·ln(1 + 0.00437 f) の上に、間隔 min(1/4, 0.75β) = 0.1875 ERB。
  - 余白は 55〜8000 Hz の両側に 1.5β ERB。
  - 試作では 170 channel、範囲 46.001〜8175.326 Hz。
- **hop の統計**（S3）
  - channel ごとに、hop の未正規化の E_h = Σ|z|² と S_h = Σ z[n]·conj(z[n−1]) を作る。hop の最初の sample は、前の hop の最後の z を使う。
  - 直近 n_c = max(1, ceil(fs/(hop·0.75·ERB(f_c)))) 個の hop の和を、channel ごとの ring で保つ。
  - ring の未観測の部分は、run の開始前の無音として 0 で始める。窓が満ちるまでも分母を縮めない。
  - 実数の平均二乗 E = 2·ΣE_h/(n_c·N)、位置 f̂ = fs·arg(ΣS_h)/2π、deposit の power d = 2·|ΣS_h|/(n_c·N·G(f̂))。
- **再配置**（S4）：G(f) = Σ_c |H_c(f)|² は事前の表（ERB 番号の 1/128 の格子）と線形の補間。内部の周波数は 1 Hz〜fs/2 − 1 Hz に clamp する。
- **対応する sample rate**：全 channel の中心が Nyquist より下にあること（既定の Log2Space で最高の中心は約 8175.3 Hz）。満たさない rate は、構築の前に通常の設定の error で拒む（AUD-R5 H1）。
- **入口**：完全な hop だけを受け付ける。runtime の呼び出し側（worker、listener、LOO、body）は完全な hop を送る（AUD-R5 M1）。
- **圧縮**（S5、§5.5 の順序）
  - P_cb(x) = Σ_j d_j·(1 + ((x_j − x)/b_ERB(x))²)^(−4)、b_ERB(x) = 1.0186·ERB(x)。gate の前の deposit から作る。
  - 実装は、ERB 番号 1/32 の bucket に power の 0〜6 次の moment を集め、query の ±4 ERB 番号にかかる bucket を 6 次の展開で評価する。
    - 省いた寄与の上界は「4 ERB 下側の応答の係数 × 省いた power」（1 kHz で係数 6.42e-5）。
    - 展開の剰余は総 power の 3e-8 未満（AUD-R4 の独立の上界は 1.75e-8）。
    - 全 deposit の直接の和との比較で、49 の入力の合否は一致した。
  - P_cb = max(P_cb, d)。
  - 床の gate γ = max(0, 1 − T/(P_cb/du))、T = 1e-6、du は位置の Log2Space の bin の ERB 番号の幅を補間したもの。
  - 重み γ·(d/P_cb)·(A_w(x)·P_cb/P_ref)^0.23。P_cb = 0 なら 0。
  - 範囲の外の deposit も P_cb の集計には入る。
- **配置**：元の推定の位置の log2 座標で、隣り合う二 bin に線形に配り、du で割る。端の bin の中心より外は、一 bin の幅で線形に 0 へ落とす。負と 0 の位置は 0。
- **平滑**（S6）：今の leaky（`analysis.tau_ms`、既定 10 ms）。
- **履歴の操作**
  - **reset**：filter、前の sample、ring、cursor、S6 を 0 にする。
  - **clone**：これらすべてを複製する。
  - **body の skip**：S1〜S3（hop の和と ring）を進め、S4 以降を行わない。選ばれた時は S4〜S6 を gap の分の間欠の更新で行う（§7）。
- **gap の後の publish**：今の worker の規則（`window_samples()`、既定の nfft 16384 で 341.333 ms）。front end の側の warm-up の返り値ではなく、worker の窓と frame の id を基準にする（AUD-R5）。
- **Flora の判断の窓**：V2 では 47 hop（0.5 s）。音高、respawn、出生は 8 hop。

### 6.2 S1 の要否と予備の案

**S1 の要否。** 実数の PCM をそのまま S2 に通すと、遠い channel の瞬時周波数は、正と負の周波数の像の干渉で狂う。数値実験（β = 1、1/4 ERB）では、単音で位置の誤差が最大 0.97 cent（格子をまたぐ最大は 1.6 cent）、見当違いの位置に落ちた質量が最大 2.7% だった。理想の解析信号を入れると、どちらも 0 になる。

試作（AUD-M1）は、Niemitalo の全域通過の対の公表の係数（各枝 4 段）を使った。
- 55〜8000 Hz で、負の周波数の像を 44 dB 以上抑える。
- 追加の群遅延は 55 Hz で 4.3 ms、1 kHz で 0.29 ms。
- 余白の最低（14.6 Hz）では抑えが 23.5 dB まで下がる。

要否は V2 で決める。実数の入力と S1 付きの入力で consumer の判断が変わらなければ、S1 は置かない。

**広がりの変種**（分けられない分類で偽の協和の山が残った時）。
- 各 channel で、遅れ L_c = round(fs/(4 b_c)) の整合度 κ_L = |Σ z[n] conj(z[n−L])| / sqrt(Σ|z[n]|² Σ|z[n−L]|²) を hop の中で取る。L が hop より長い channel は、必要な長さの z の履歴を保つ。
- σ_c = arccos(κ_L)·fs/(2π L_c) Hz を deposit の幅とし、重みを標準偏差 σ_c の Gaussian として Log2Space の bin に配る。σ_c が bin の幅より十分小さい時は、今の二 bin の線形の配分に連続に移る。
- 一つの成分だけの channel は κ_L がほぼ 1 なので、幅はほぼ 0 で鋭いまま残る。融合した組は幅を持ち、組の重心の偽の unison の谷を埋める。
- 設計段の数値実験（`AUD-1/spread_beta_v9.py`）では、β = 1/3 の倍音列は広がりを足しても崩れなかった。広がりで組を二点に戻す形（v7、v9）は、frame ごとに位置が揺れて不安定だったので使わない。

**予備の案**（V2 で、分けられる分類に今の経路より悪化する consumer が残った時だけ）。
- **漏れの補正**：filterbank は線形で既知なので、推定した成分から隣の channel への漏れを予測して位置を直す。
- **低い帯域だけ長い観測**：分けられない組の構造を一つの hop の統計から読むのは難しい。必要な観測の長さは、入力の仮定、雑音、誤差の基準に依存する（AUD-R3 M2）。低い帯域の channel だけ、channel の出力をもう一段長く観測する。

どちらも、選ぶ前に V2 で判断の差を比べる。

### 6.3 蝸牛のモデルの選択

AUD-R1 H3 のとおり、Hohmann 型と CARFAC は差し替えのきく部品ではない。

**線形の Hohmann 型（推奨）。** 判断 1 で相対の量を選んだ場合の推奨で、相対の量から一意に決まるのではない（AUD-R2 M6）。推奨の理由は、T2 との実装の共通、複素の tap、公表された構成、費用。
- 入出力：PCM → 複素の channel の出力。
- 状態：channel ごとに 4 つの複素数。
- 非線形：無い。
- 校正：要らない。
- tap：A。
- LOO：tap A で z(mix − own) = z(mix) − z(own) が厳密に成り立つ（初期は使わない）。
- 音量に依存する現象は表せない。β < 1 では、帯域は人の蝸牛より狭い。

**CARFAC。**
- CAR、OHC、IHC、AGC を一体にした非線形のモデル。level に依存する tuning と圧縮を持つ。
- 校正（dBFS と音圧の対応）、非線形の履歴、版と IHC の型の固定、LOO の stream ごとの非線形の状態と出生の時の初期化が要る。
- Hohmann 型と同じ意味の複素の位相の出力は持たないので、S3〜S4 の読み出しをそのまま使えない。

**動的な compressive gammachirp**（Irino & Unoki）。level に依存する非対称な filter。校正と非線形の状態の要件は CARFAC と同じ側にある。

非線形のモデルの二音抑制は、ERB の filter での近い成分の混ざりを和らげる可能性がある。ただし作業の前提を相対の量にしたので、初期の範囲では比べない。

後で相対の量の前提を変える時の費用（版 1 から）：S2 を非線形のモデルに替えると、tap A の複素の出力という読み出しの契約が保てなくなる場合がある。その時は、stream ごとの非線形の状態と出生の時の初期化、校正の数値、検証のやり直し、sample の採用のやり直しが要る。

### 6.4 音高の読み出し

- H は今の common root の kernel のまま、分けられた成分の位置から根音を作る。
- 時間の自己相関による音高（Meddis & Hewitt 1991）は、分けられない倍音だけの音、欠けた基音、位相に依存する音高で H と違う答えを出す候補である。今の consumer にはその違いを使う判断が無いので、初期には入れない。
- 入れる条件：分けられない高い倍音が主になる body（強い高次と弱い低次）が sample で使われ、その音の H の場が V2 の正解と大きくずれる時。lag の状態の費用と、自己相関の音高を候補の H の場へ写す規則を、そのとき別に設計する。

### 6.5 Landscape と T2 との接続

**Landscape。**
- `subjective_intensity`、H／R／C の field、`_eff` の view は、型を保つ。
- `nsgt_power` は今の NSGT の power のまま（UI、report、spectral history、研究の tap）。
- Flora の資源の power は、今の FFT と \|K\|² の配分のまま。
- test と診断の専用の近似の LOO（NSGT の power と peak の抽出を使う）は、移行の時に新系に合わせて直すか消す。
- H01 と R01 の正規化、密度の正規化の共有の床、F1〜F4 の規則は変えない。

**T2。** 共有は初期にはしない。共有できるのは次の三つがそろう場合に限る（AUD-R2 M5）。
- 同じ実数の入力と同じ履歴。
- pole の向きと共役の規約の対応。T2 は負の角度の pole に実数の PCM を入れる。
- 同じ帯域（β = 1）。

S1 を入れた入力や β < 1 の filter は、T2 の入力ではない。T2 を演奏の経路で使う判断の時に、改めて比べる。

### 6.6 皮質の段

Chi, Ru & Shamma（2005）の spectro-temporal modulation、Elhilali の coherence は、consumer が決まるまで作らない（AUD-R1 M10）。H と R の kernel は、機能としては音高と粗さの中枢の処理にあたるが、それを神経の対応の検証とは呼ばない。各読み出しには、出所、観測の範囲、使える時刻を付ける。同じ音を複数の読み出しに通しても、独立した証拠は増えない。

## 7. 費用

費用は独立した stream ごとに数える（AUD-R1 M7）。

**stream の種類。**
- 混合の habitat：1 本。新系と、今の NSGT の power（UI、tap、資源）。
- presentation：listener が有効な時に 1 本。新系と NSGT の power。
- Voice の LOO：自己除外のある Voice ごとに 1 本。新系だけ。
- 同期の body：後述。
- Flora の資源：今のまま。新系の費用には入らないが、実時間の合計には入れる。

非線形の段の後で F(mix) − F(own) として代用することはできない。どの stream も S1〜S7 を全部通す。

**1 stream・1 hop あたりの演算**（見積もり、実測ではない。選んだ構成）。
- S2〜S3：170 channel × 512 sample × 約 52 演算（4 段の複素の漸化式に約 40、E と S の和に約 12。AUD-M1 の数え方）で、約 4.5 M。
- 比べると、今の 16384 点の複素 FFT は 5N log₂N ≈ 1.15 Mflop で、これに帯域の疎な積と peak の抽出が加わる。演算の数の比から費用の比を断定しない。
- S4：deposit ごとに G の表の補間と位置の変換（atan2、log）。
- S5：ERB 版の文脈は bucket の集計と、query ごとに最大 258 bucket の f64 の 6 次の展開。範囲を固定すると O(C + B)（B は bucket の数、1381）だが、「channel の数に比例して小さい」とは言えない。未測定。
- S7 は今と同じ。
- channel の間に依存が無いので、SIMD で並べて計算できる。漸化式は時間の方向に逐次。
- 実時間の費用は V5 で測るまで結論しない。

**状態の大きさ**（選んだ構成、主な配列の payload。allocator の overhead を含まない。AUD-R4 M3）。
- filter の状態：170 channel × 4 段 × 複素 f32 で 5440 byte。
- 統計の ring：299 項で 3588 byte。
- ERB 版の文脈：1381 bucket に f64 の moment 7 個と f64 の中心で、約 88.4 KB。clone ごとに複製される。
- G の表は Arc で共有する。
- これに前の sample、読み出しと scan、scratch、publish の量が加わる。stream の総量はこれより大きい（AUD-R2 H5）。

**同期の body**（AUD-R2 H5）。
- IIR の filter は、選ばれなかった hop の PCM を ring に書くだけでは履歴を保てない。
- そこで、全 source の S1〜S3（filter と、hop の和と ring）を毎 hop 進め、S4 以降は選ばれた時だけ行う。今の `skip` は「S1〜S3 だけ進める」、`process_body_gap` は「S4〜S6 を gap の分の平滑で行う」に対応させる（統計の窓を足した後の形。AUD-R4 M1）。
  - 選ばれた hop の S3 は、その hop の最初の直前の z も要る。出生、reset、skip を通して、S2 の最後の状態から取れるように保つ。
  - S6 は今の間欠の更新を保つ。最後の更新から g hop 後の今の密度を q、前の状態を y とすると、y_new = a^g·y + (1 − a^g)·q。これは途中の q を毎 hop 使う平滑とは一般に等しくなく、今の経路も同じ近似をしている（AUD-R3）。
  - V4 で、S1〜S2 と今の hop の S3 は毎 hop の処理と一致すること、S6 はこの式と一致することを確かめる。毎 hop の処理との bit の一致は求めない。
- 費用は「全 source の S1〜S3」「選ばれた source の S4 以降」「出生用の共有の stream」「代表音の `observation_frames` hop の再解析」に分けて数える。
- 代表音の render の長さは、今の窓に合わせて決められている。新系の短い支持区間に合わせて見直せるが、初期は変えない。

**出生、reset、退場。**
- 出生では、混合の stream の状態（filter、前の sample、統計の ring と cursor、ERB 版の文脈の scratch、S6）を複製する。今の契約（出生の前の履歴 = 混合の履歴）と同じ。
- gap では状態を 0 にし、今の規則（窓が満ちるまで）の間は publish しない。
- 退場中の尾は今と同じく stream として残る。

**危険。**
- 今の記録では、自己除外の Voice の `Observer::process` の平均は 0.30 ms/hop だった（L-1 の記録、snapshot の確保を含まない。AUD-R2 が範囲を確認）。
- 解析の thread 一本で多くの Voice を処理すると、出力が途切れうる。30 人という数は普遍的な上限ではない。
- 新系で 1 人あたりの費用が増えれば、扱える人数は下がる。下げる手段は次の三つ。いずれも V2 と V5 で選ぶ工学の近似。
  - channel の間隔を広げる。
  - 低い channel を間引いた rate で計算する（多 rate。anti-alias の filter とその遅れを §5.2 の表に足す）。
  - S1 を省く。
- 人数が今より下がる場合は、作者の判断にする。

## 8. 限定した検証

各検証に、変える判断、既存の根拠で足りない理由、選択肢を見分けられる理由を付ける。

**V1 filter の数値の一致**
- 内容：閉じた形の周波数応答との差。T2 の f64 の channel との差は、pole の向き、共役、利得の規約を明記して比べる（β = 1 の時だけ）。
- 変える判断：S2 の実装を、定義どおりの filter として受け入れるか。
- 足りない理由：数値実験は Python で、Rust の実装の正しさは保証しない。
- 見分け：pole、利得、正規化の誤りを検出する。
- 試作の取得（β = 1）：閉じた形との振幅の相対の差は最大 2.9e-5、T2 との相対の RMS の差は最大 2.9e-5。

**V2 consumer の判断の比較**（中心の検証。手順は試作への追補 3 で固定した）

入力
- 入力の一覧（周波数、振幅、位相、長さ、onset の sample、観測の hop）を manifest に書き、PCM の bytes と SHA-256 を保存する。すべての構成と今の経路に同じ bytes を通す。
- 分類は、単音、0.75〜3 ERB の二音、F0 55〜440 Hz で傾きの違う倍音列、強い音の近くの弱い音、15 Hz の組、LOO で A を除いた後に残る B と C の近い組、近い mode を持つ body、onset を含む過渡。

参照
- 定常の分類：合成音の成分の一覧 (f_j, P_j = a_j²/2) から、成分ごとの質量 (A_w(f_j)·P_j/P_ref)^0.23 を作り、Log2Space の二 bin に配り、du で割り、同じ H／R／C に通したもの。今の subjective intensity の定義（peak ごとの圧縮）を、分解が完全な場合に当てはめたものにあたる。未分離の成分にも個別の圧縮を当てるので、人の知覚の正解ではなく、consumer の側の工学の目標である（AUD-R3）。
- 過渡の分類：onset の hop から、定常の参照の scan に同じ S6（onset の前は 0）を因果に掛けたもの。filter の遅れを含まない理想の即時の観測で、この参照との不一致は推定の誤差と遅れの両方を含む。
- 観測：定常の分類は最後の 8 hop、過渡の分類は onset から 8 hop。

判断と集計（consumer ごと、分類ごとに分けて判定し、合算しない）
- **音高**（pitch_core の HillClimb）
  - production の候補の生成と選択の規則（順位の 1e-6、動くための改善の 0.1、留まる規則）をそのまま使う。乱数の候補と同点の乱数は seed を固定し、すべての構成で同じ列にする。
  - 起点は各成分とその 1/2、2/3、3/2 の位置。
  - 選んだ目標が参照と 6.25 cent（Log2Space の半 bin）より離れるか、動く／留まるが食い違えば不一致。
  - 同点に近いものは除外しない。PCM 照合の 1e-3 は、ほぼ同じ PCM から得た二つの score の点ごとの差の許容で、候補の価値が同じと見なせる差ではないので、V2 には使わない（AUD-R3 H2）。近い差の判断の数は診断として別に書く。
- **respawn の peak bias**：production の山の列挙。参照の各山について、6.25 cent 以内に新系の山があるか。
- **出生**：range-local の PMF の L1 距離を連続な量のまま比べる。範囲は 55〜8000、110〜880、440〜3520 Hz。占有は空、tension は 0。
- **Flora**：6 つの biomass と資源の状態で、観測の窓の始めの状態から 47 hop（0.5 s、T0 の歩調の basin の中心 2 Hz）進めた時の、各 cell の biomass の変化の累積の符号の不一致。Flora の判断は biomass の時間の積分で決まり、1 hop の符号は Flora の判断ではない。追補 3 の 1 hop と追補 4 の 8 hop の符号の数は診断として残す。音高、respawn、出生は 8 hop の窓のまま。
- 判断の対象が 0 になった（分類、consumer）は、合格ではなく「対象なし」とする。

分類の分け方（§5.4）
- **分類は組ごとに数値で決める**（AUD-M1 追補 5）。入力の全成分の組について、LTFAT の ERB 番号の差を 0.75（登録した工学の境、§5.2）と比べ、manifest に組ごとに書く。
  - **二成分の入力**（単音、二音、弱い音、15 Hz の組、LOO の近い組、近い mode の body）：組が 0.75 以上なら分けられる分類、未満なら分けられない分類。110/150 Hz（1.034）は分けられる分類。
  - **複合音**（倍音列と過渡、manifest の `mixed_complex` の 11 件）：入力全体を分けられる分類として consumer の門で判定し、そのうえで 0.75 未満の組（110 Hz の 12 倍音列で 2 組、220 Hz で 1 組など）は区間の診断を別に記録する。全部の組が 0.75 以上の複合音も同じ扱い。
  - 門は、分けられる分類の consumer の判定（下の「結果を見た後の目標の改訂」）。分けられない組の区間の値は診断。
- **分けられない分類**：成分の間隔が 0.75 ERB 未満。15 Hz の組、LOO の近い組、近い mode の body。

基準と選択
- 分けられる分類：音高、respawn、Flora は「新系の不一致の数 ≤ 今の経路の不一致の数」、出生は「新系の L1 ≤ 今の経路の L1」。（分類、consumer）ごとに判定する。
- 分けられない分類：門にしない（§5.4）。偽の協和の山（組の成分 y1 < y2 の区間 [y1, y2] の中の C score の最大の正解からの超過、R01 の最小の不足）を、新系と今の経路で記録し、登録した限界とする。判断の一致の数も診断として記録し、行動の変化として登録する。
- （追補 3〜6 の規則。現行は次の「結果を見た後の目標の改訂」）分けられる分類のすべての（分類、consumer）で基準を満たす構成のうち、遅れが一番短いものを採る。比べる構成は、β ∈ {1/4, 1/3}、統計の窓あり、P_cb の文脈は狭い channel 版と ERB 版（§5.5）。S1 は、S1 なしで満たすなら置かない。

**結果を見た後の目標の改訂**（2026-10-24、統括。AUD-M1 追補 6 の後）

旧基準では 4 構成とも未達だった。この結果は消さずに残す。そのうえで、目標を次のように改訂した。結果を見た後の変更であり、consumer の判断が保存されたという主張ではない。引き換えの設計の判断である（AUD-R4 H1）。

- **門として保つもの**
  - 離散の判断（音高、respawn）は、分けられる分類のすべてで今の経路以上。選んだ構成は満たした（110/150 Hz を含む）。
  - 出生と Flora は、単音、二音（0.75〜3 ERB）、倍音列、弱い音で今の経路以上。選んだ構成は満たした。
- **登録した差**（今の経路より悪い。§5.2 の「旧基準での結果」の 1 と 2）
  - 110/150 Hz の組の定常の Flora と出生（入力、振幅の比、観測の窓を §5.2 に列挙した）。
  - F0 110 Hz の 6 倍音の onset の Flora。
  - 差を許す範囲は、この取得の入力に限る。「低い帯域」「1 ERB 前後」に一般化しない。
- **登録した限界**：分けられない組（§5.4）。
- **この差の扱い**
  - 最終の判断は、作者の試聴と採用（M4）に残す。
  - V3（PCM の自己除外の不変）は、両方の経路が同じ偏った場を作れば通るので、生態の差を許す根拠にはしない（AUD-R4 H1）。
  - sample の生態の指標（占有、PR など）は門にしない。指標から聴こえ方や sample の成否を決めないためである（指標と聴こえを結び付けない作者の方針）。採用の判断は作者の試聴で行う。
  - 試聴の材料には、登録した差が出やすい場面（低い F0 の onset、近い組）を含める。

**V3 PCM の自己除外の不変**
- 内容：Flora 40、B-1 84 の今の門を新系で通す。AUD-R2 H1 の onset の反例を、実際の density と H／R／C の差まで通す。
- 変える判断：新系を LOO に入れられるか。
- 足りない理由：連続性は要件として置いたが、実装が不連続を持ち込みうる（偏角の枝、床、早すぎる publish）。
- 見分け：今の門の合否。

**V4 時刻と未知**
- 内容：前置きの無音、gap、観測済みの無音、出生の複製、warm-up の publish の規則、観測の印と実際に消費された frame と回復の時刻、listener の観測の id と消費の hop、同期の body の履歴の確認（§7）、gap の後の 341 ms の規則での IIR の残り（§5.7）。
- 変える判断：publish の規則と、出生の時の状態の複製の定義。
- 足りない理由：定常の一致は、履歴の取り違えや未来の参照を検出しない。
- 見分け：欠測の間に観測を更新しないこと、無音では観測があることを分けて確かめる。

**V5 実時間**
- 内容：まず今の producer の形の小さな場合で、1 stream の 1 hop の費用と LOO の N 人を、release の build で測る。その後、切り替えの後に宣言の負荷で測る。宣言の負荷は、既存の実時間の取得の集合（22 場面、FI-1b の規則、timing lock）。
- 変える判断：channel の間隔、多 rate、S1 の有無、LOO の上限。
- 足りない理由：演算の数の見積もりだけでは、cache、publish、待ちを評価できない。
- 見分け：hop の予算 10.67 ms と miss の数。

**行わないもの。**

## 12. 人の聴覚の限界との照合と改善案

作者の問い（2026-10-24）：限界が人の聴覚の限界と一致するなら採用、そうでなければ理由と改善案。

### 12.1 結論

一致するとは言えない。三つの限界の**境界の位置**は人に近い。しかし**境界の向こうの扱い**が人と違う。人は、分けられない成分を「分けられないもの」として、包絡のうなり、粗さ、周期の音高、不確かさとして聴く。新系は、それを確かな位置を持つ一つの成分に変えてしまう。

### 12.2 限界ごとの照合

**1. 0.75 ERB 未満の組の融合**
- 境界の位置は人に近い。
  - 非調和の複合音の内側の部分音の聴き分けは、0.75 ERB でほぼ偶然の水準（Moore ほか 2006、要旨、§3.5）。
  - 倍音が分解されるのは約 10 次まで（Bernstein & Oxenham 2003、Shackleton & Carlyon 1994、§3.5）。F0 の弁別の閾は、すべての倍音が 12 次より上で頭打ちになる（Houtsma & Smurzynski 1990、要旨）。
  - 新系の融合は、F0 110 Hz で約 10 次、220 Hz で約 11 次より上の隣り合う部分音で始まる（§4）。
- 境界の向こうの扱いは人と逆になる。
  - 人は、ごく近い二音を平均の高さの一つの音として聴き、うなり（音の大きさの揺れ）を伴う。差が約 15 Hz を超えるとうなりは粗さに変わり、臨界帯域を超えると粗さは消える（CCRMA の講義資料、二次資料）。
  - 純音の組が最も不協和になるのは、差が臨界帯域の約 1/4 の時（Plomp & Levelt 1965、要旨）。Zwicker の臨界帯域で 1 kHz の 1/4 は約 40 Hz、ERB で約 0.31。Greenwood の改訂（臨界帯域の約 40%）でも約 0.49 ERB。どちらも新系が融合させる範囲（0.75 ERB 未満）の内側にある。
  - 新系は、その組を一つの滑らかな質量にし、R の kernel は組の中間に偽の協和の谷を作る（§5.4）。人で最も粗い間隔を、モデルは最も滑らかとする。
  - 分解されない倍音の列から、人は弱いながら周期の音高を得る（Houtsma & Smurzynski 1990：20〜30 次だけの音でも、旋律の音程の同定は偶然より上）。この情報は、包絡の周期にある。新系は、融合した質量を倍音の間の位置に置き、スペクトルの成分として H に渡す。
- 照合の範囲：Moore ほか 2006、Plomp & Levelt 1965、Houtsma & Smurzynski 1990 は要旨だけ確かめた。15 Hz の目安は二次資料で、硬い境ではない。

**2. 低い帯域の onset の後の位置の揺れ（約 100 ms）**
- 時間とともに精度が上がる点は人に近い。短い音ほど周波数の弁別の閾は大きい（Micheyl, Xiao & Oxenham 2012、12 研究の 583 測定の再解析）。この効果が低い周波数で大きいとする先行の記述もあるが、同じ再解析では、周波数と持続時間の交互作用は統計的に支持されなかった。
- 違う点が二つある。
  - 人の短い音は「粗い」（閾が大きい）のであって、別の位置に確かな成分が現れるのではない。新系は、filter が落ち着くまでの間、質量を誤った位置に確かに置く（110 Hz の 6 倍音の onset で Flora 377 対 63）。
  - ERB 幅の 4 次の gammatone を人の末梢の近似とすると、その群遅延は 110 Hz で約 17 ms。採用した 1/4 ERB の filter は約 4 倍遅い。人は粗い情報を早く得て、それを細かくしていく。新系には、この早く粗い経路が無い。

**3. 強い成分の近くの弱い成分の寄り**
- 向きが人と逆。人では、部分的にマスクされた音の高さは、妨害の音から離れる向きにずれる（低い妨害音で上へ、高い妨害音で下へ、少なくとも 300 Hz 未満で。Terhardt & Fastl 1971、CCRMA の解説で確認、原典は未照合）。
- 新系では、強い方へ寄る。β = 1/4 の定常の解析値（filter の応答と再配置の式、圧縮の前の質量、`units/AUD-1/weak_pull.py`）で、1 kHz の強い音から 0.75 ERB の弱い音は −20 dB で 10〜14 cent、−30 dB で 15〜23 cent、1 ERB では −20 dB で 2〜3 cent 寄った。1.5 ERB では −30 dB でも 1.4〜3.2 cent。
- ERB の文脈の圧縮が、この弱い音の重みをマスキングに似た形で下げる。0.75 ERB の −20 dB で単独の時の約 1 割、−30 dB で約 2%（同じ式からの見積もり）。寄りの影響はその分小さいが、向きは残る。

### 12.3 改善案

人の聴覚は、二種類の情報を使う。分解された部分音の**位置**（スペクトルの音高、H）と、分解されない成分の**時間の包絡**（うなり、粗さ、周期の音高）である。新系は前者だけを持つ。改善は、一つの量で後者を足すことにまとまる。

- **channel の包絡の揺れの深さ**：hop ごとに Σ|z|² に加えて Σ|z|⁴ を積む。一つの定常の成分だけの channel では揺れは 0。二つの成分が入ると、揺れの深さは 2√(w₁w₂)/(w₁+w₂)、速さは二つの差の周波数になる。filter の後の 1 回の積和の追加で、今の filter の費用に比べて小さい。

この量の使い道は三つある。

- **A. 位置の確かさ**（今の範囲の中。H／R の意味を変えない）
  - 揺れの深い channel の質量は、位置の確かな点として置かない。重みを下げ、残りは不確かな成分として臨界帯域の幅に配る（今の ERB の文脈の励起の pattern を使える）。
  - 限界 3：定常の解析値で、0.75 ERB の −20 dB の寄りが 14 cent から約 3 cent になった（重み (1 − 揺れの深さ)^k、k = 1〜4、`units/AUD-1/purity.py`）。−30 dB では弱い音がどの channel も占めないので寄りは変わらない。これは filter が分けていない（人ではおそらくマスクされる）場合で、重みは ERB の文脈の圧縮で既に約 2% に下がっている。
  - 限界 2：落ち着く前の channel は、入力の成分と CF の過渡の二つを含むので、揺れが出る。誤った位置の確かな成分ではなく、粗く不確かな成分になる見込みがある。人の短い音の扱いに近い。onset での効果は時間の領域の試作で確かめる必要がある。
  - 0.75 ERB 未満の組は、A だけでは二つに分かれない（同じ試算で、0.3、0.5 ERB の等振幅の組は中間の一つの山のまま）。
- **B. 包絡からの粗さ**（範囲を広げる。R の意味が変わる）
  - 揺れの深さと速さから、臨界帯域ごとの粗さを作る。公表のモデルでは、Aures（1985）、Daniel & Weber（1997）の型にあたる。
  - 限界 1 の偽の谷を除き、人で最も粗い間隔をモデルでも粗くする。
  - 作者が以前に試した方向（`67a5c81` の Hilbert 版の R）にあたる。今回は包絡を位置の情報と分けて持つので、H をなまらせない。
  - 今の R の kernel（部分音の位置の組の干渉）との合わせ方、候補の位置の R をどう作るかは、設計が要る。V2 と試聴をやり直す。
- **C. 包絡の周期からの音高**（後で足りる）
  - 分解されない倍音の列の周期の音高を H に足す（§6.4 の時間の自己相関の音高）。費用が大きく、上の倍音の重みは小さい。B の後でよい。

### 12.4 作者の判断と R の計算方式（2026-10-24）

- 作者は B（包絡からの粗さ）を範囲に入れた。R の意味が変わる。§10 の作業の前提 2（観測の基盤と H／R の入力だけを替える）は、R についてはこの判断で広がる。
- 作者の問い：これで、R の kernel の畳み込みより良い計算方式が可能になるか。

**今の方式の位置づけ。**
- 今の R は、各候補の位置で、点の質量に Sethares 型の曲線（ERB の距離 u に対し exp(−3.51u) − exp(−5.75u)、山は約 0.22 ERB）を掛けて足す（`src/core/roughness_kernel.rs`）。unison の近くは σ 0.06 ERB の抑えで 0 にする。既にある成分の質量に比例する。
- これは、定常の純音の組の経験の曲線（Plomp & Levelt の系統）を、位置の分かった成分に重ねたものである。定常の純音だけなら、臨界帯域の channel の包絡の揺れは、組ごとの項（間隔だけで決まる）の和になる。今の畳み込みは、包絡のモデルのこの特別な場合にあたる。

**公表の模型の照合**（2026-10-24、subagent の調べと統括の確認。原典の本文が手に入らないものは実装と二次資料による）
- Daniel & Weber（1997、Acustica 83）は原典が手に入らず、MoSQITo と SQAT の実装で確かめた。47 channel（0.5 Bark 間隔）の励起、包絡の揺れの深さに揺れの速さの重み（例えば中ほどの帯域で 79 Hz に山）、隣の帯域との包絡の相関、和。実装の窓は 200 ms。
- ECMA-418-2（第 4 版 2025、本文で確認）：53 帯の因果の再帰の filter、block 16384（341 ms）、hop 4096（85 ms）、包絡の DFT、揺れの速さの重み（約 72.7 Hz まで）、平滑（立ち上がり 62.5 ms、立ち下がり 500 ms）。検証は振幅変調の正弦と工業音で、二音や音程は無い。
- Vencovský（2016）：蝸牛の流体の模型、30 ms の frame。和声的な二音で検証、純音の組は無い。
- 包絡の経路で、純音の組の Plomp & Levelt の曲線を再現したと確かめた模型は見つからなかった。
- 和音の協和の評定の予測（Harrison & Pearce 2020、本文で確認）：組の和の模型の Hutchinson & Knopoff（1978）が r = .77、包絡の模型の Wang ほか（2013）が r = .17（位相の係数を外すと部分相関 .46）。ただし前者は記号の（理想の）スペクトル、後者は音声を入力にしており、模型と入力の違いが混ざった比較である。

**結論の訂正。** 前の段落の案（今鳴っている音の粗さを包絡から直接測る方が良い）は、音楽の協和については支えられない。
- 公表の包絡の模型は、窓が 200〜341 ms で、hop 10.7 ms の実時間の判断に合わない。純音の組の検証も無い。和音の評定では、組の和の模型の方がよく当たった。
- 組の和の形（今の kernel の畳み込み）が弱いのは、入力に分けられない組が融合して入る時である。記号の入力の H&K には、この問題が無い。
- そこで B は、粗さの模型を替えるのではなく、**R の入力を包絡で直す**形にする。
  - 分けられない組の入った channel では、包絡の揺れの速さが二つの差の周波数、深さが振幅の比を与える。channel の位置（power で重みを付けた平均）と合わせて、二つの成分の位置と質量を R の入力に戻す。
  - H には渡さない（人も聴き分けない）。H と R に別の入力を渡す（AUD-R1 H2 の tap の分離）。
  - 差がおよそ 15 Hz 未満の組は、kernel がほぼ 0 なので、戻さなくてよい。戻すのは、差が約 15 Hz から 0.75 ERB までの組で、うなりの周期は今の統計の窓の中に入る。遅れは増えない。
- 包絡から測る今鳴っている音の粗さは、一つの音源の振幅の揺れ（近い mode のうなりなど）の扱いとして、後で足りる。
- kernel を filterbank から導き直す案は、検証された模型が無いので採らない。今の kernel を保つ。kernel の山（約 0.22 ERB）は、Plomp & Levelt の約 1/4 臨界帯域（1 kHz で約 0.31 ERB）と Greenwood の約 40%（約 0.49 ERB）より低い側にある。これは別の問いとして残す。

以下の二つの段落は、照合の前の見立てとして残す。

**良くなる所（照合の前の見立て）。**
- **今鳴っている音の粗さ**（場の水準、`roughness01_scalar`、正規化の基準）は、ERB 幅の channel の包絡の揺れから直接測れる。公表の粗さのモデルの形である。分けられない組、一つの音源の振幅の揺れ（体の中の近い mode のうなりなど）、雑音、過渡、三つ以上の成分の位相の関係、音量への依存を含む。成分の位置を前処理が取れるかに依らない。
- **候補の位置の R**（そこに音を置いたらどれだけ粗いか）は、まだ鳴っていない音の予測なので、組の和の形が残る。ただし次の二つが良くなる。
  - kernel を、同じ filterbank の重なりと、粗さのモデルの揺れの速さの重みから導ける。経験の曲線と unison の抑えの手当てが要らない（差が 0 に近づくと揺れが遅くなり、粗さは 0 になる）。予測と、後で測る粗さが同じモデルになる。
  - 既にある音の側は、分けられた成分の位置に加えて、分けられない組を channel の包絡の揺れの速さ（差の周波数）と深さ（振幅の比）から補える。中間の偽の成分を R に渡さない。この補いは R の入力だけに使い、H には渡さない（人も聴き分けない）。
- 量の依存（今は既にある質量に比例）も、採るモデルの側から決まる。

**良くならない所と未決（照合の前の見立て）。**
- 候補の R は、定常の音の組を前提にした予測のまま。
- ERB 幅の包絡は、今の 1/4 ERB の channel の複素の出力を隣どうし足して作れる（filterbank の和）。別の ERB 幅の bank を持つ案もあり、T2 の蝸牛型の前処理との共有の判断に関わる（後で足りる）。
- 公表のモデル（Aures 1985、Daniel & Weber 1997、ECMA-418-2 の Sottek のモデルなど）の構造、窓、遅れは原典で照合中。モデルをそのまま採るなら、受け入れはそのモデルとの数値の一致、登録した因果の差、宣言の負荷での実時間による。

### 12.5 R の二つの量の整理（2026-10-24、作者の指摘を受けて）

作者の指摘：うなりが検知できるなら、今鳴っている音の R はそこから検知できる。今鳴っていない音には別の方法（kernel の畳み込み）が要り、その kernel とうなりの検知の応答を完全に一致させるのは難しい。

§12.4 の「結論の訂正」は言いすぎだった。公表の模型の照合が示したのは次の二つまでである。
- 実装の窓が長い（200〜341 ms）こと。これは包絡を FFT で解析する実装の選び方で、うなりを測るのに要る時間は原理としておよそうなりの一周期（差 15〜100 Hz で 10〜67 ms）である。
- 一つの包絡の模型（Wang ほか 2013）の和音の予測が弱かったこと。入力（音声と記号）の違いが混ざった比較で、うなりから粗さを測ること自体を否定する証拠ではない。

そこで R を二つの量に分けて、どちらも採る。
1. **今鳴っている音の R**：ERB 幅の帯域の包絡の揺れ（うなり）から直接測る。分けられない組、一つの音源の振幅の揺れ、雑音、三つ以上の成分の位相の関係を含む。
2. **今鳴っていない音（候補の位置）の R**：予測なので kernel の畳み込みを使う。
   - kernel は、1 の検知器が二つの純音に返す応答を、間隔の関数として計算した表にする。今の Sethares 型の曲線と unison の抑えは、これに替わる。
   - 既にある音の側の入力は、分けられた成分に、1 の揺れの速さと深さから戻した分けられない組を足したものにする（§12.4）。中間の偽の成分を使わない。
3. **一致の範囲**
   - 定常の純音の組では、1 と 2 は作り方から一致する。
   - 定常の音の混合でも、候補を足した時に増える揺れは、候補と既にある成分の組ごとの項の和になる。ただし帯域の水準での正規化や、揺れの深さの非線形の変換があるので、近似になる。
   - 一致しないのは、まだ鳴っていない音との位相の関係、振幅の揺れ、雑音、過渡である。予測では原理的に知りえないので、2 はそれらを平均した値になる。
4. **検知器の揺れの速さの重みを決める基準**：純音の組の応答が Plomp & Levelt（1965）の曲線に合うこと。人の data に一度だけ合わせ、1 と 2 の両方がそれに従う。公表の模型（Daniel & Weber など）の重みをそのまま使うと、純音の組の山が約 0.53 ERB（1 kHz で 70 Hz）へ寄る見込み（未確認）で、これは Plomp & Levelt より広い。

### 12.6 推奨の設計（2026-10-24、§12.1〜12.5 をまとめる）

**原理。** 人は二種類の情報を使う。分解された部分音の位置（場所の情報）と、帯域の中の時間の包絡（うなり、粗さ、周期）である。前者は細かいが遅く、後者は粗いが速い。H と R のそれぞれで、今鳴っている音を測る量と、まだ鳴っていない候補を予測する量を分ける。

**二つの経路**
1. **場所の経路**（今の 1/4 ERB の bank、変えない）
   - hop ごとの統計に、Σ|z|⁴（包絡の揺れの深さ）と、包絡の短い遅れの相関（揺れの速さ）を足す。
   - 揺れの小さい channel（一つの成分に占められた channel）だけを、位置の確かな成分として出す（A）。揺れの大きい channel の質量は、位置の成分として H に渡さない。ぼかして渡すこともしない（H のなまりを戻さない）。
   - 揺れの速さと深さから、分けられない組（差 約 15 Hz〜0.75 ERB）の二つの位置と質量を戻す。R の予測の入力だけに使う。
   - LOO の observer もこの経路だけを持つ（mix − own の PCM から同じ統計を取る）。
2. **包絡の経路**（新しく足す。混合の stream に一本だけ）
   - ERB 幅の因果の複素 filter の bank（0.5 ERB 間隔で約 63 帯）。1/4 ERB の channel を足し合わせて作る案は、隣の channel の位相の差が大きく、単純な和では帯域の形が崩れるので採らない。
   - 帯ごとに包絡の揺れを、揺れの速さの重み（因果の IIR）を通して測る。
   - 揺れの速さの重みは、検知器の純音の組への応答が Plomp & Levelt（1965）の測定に合うように一度だけ決める。中心周波数ごとに Hz で取った曲線に合わせれば、臨界帯域の定義の違い（Greenwood の指摘）を避けられる（原典の図の照合は未）。

**R**
- 今鳴っている音の R：包絡の経路の出力の和。場の水準、`roughness01_scalar`、report、listener に使う。
- 候補の R（Voice、出生、Flora の配置が読む場）：kernel の畳み込み。kernel は包絡の経路の検知器の純音の組への応答の表。入力は、場所の経路の確かな成分と、戻した分けられない組。
- 定常の純音の組では二つは一致する（§12.5）。

**H**
- 候補の H：今の harmonicity の kernel をそのまま使う。入力は、場所の経路の確かな成分だけ。分けられない上の倍音と、落ち着く前の onset の channel は入らない。
  - 人の音高も、分解された低い倍音が主に決める。分解されない倍音は場所の音高を与えない。
  - onset では、filter が落ち着いた成分から順に H に入る。誤った位置の成分は入らない。時間とともに音高が定まる人の振る舞いに近い。
- 分解されない倍音の周期の音高（C）：包絡の経路の帯ごとの包絡の周期から、根音の証拠を H の入力に足す。費用が大きいので後の段にする。包絡の経路の上に、後から足せる。
- 今鳴っている音の H を測る量は、今の consumer が要らないので作らない。

**遅れ**
- 場所の経路は今と同じ（110 Hz で約 96 ms、1 kHz で約 30 ms）。
- 包絡の経路は、ERB 幅の filter（110 Hz で群遅延 約 17 ms）と、うなりの一周期程度（10〜67 ms）。今鳴っている音の粗さは、場所の経路より早く出る。

**費用の見込み**（演算の数の見積もり、未計測）
- 場所の経路の追加（Σ|z|⁴ と遅れの相関）：filter の費用の 1 割前後。LOO の observer にもかかる。
- 包絡の経路：混合の stream だけで、1/4 ERB の bank の約 4 割。
- M3 では、observer が 13 個の場面の analysis の thread が最大 8.4 ms（hop 10.7 ms）だった。追加の後は余裕が小さくなるので、V5 で確かめる。

**変わらないもの**
- H／R／C の型（Log2Space の scan）、場の式、habituation、行動の規則、Flora の資源の経路、時刻の契約。

**検証**
- 検知器：純音の組の応答と Plomp & Levelt の測定の一致。
- V2：分けられない組の分類（偽の谷が消えること）、弱い音、onset。
- V3、V4：PCM の自己除外の門と時刻の契約（場所の経路の追加の統計にも、同じ連続性が要る）。
- V5：宣言の負荷。
- 試聴：作者。

### 12.7 検知器と組の復元の試算（AUD-E1、2026-10-24）

記録は `.orchestration/units/AUD-E1/`（machine の中）。Python の定常の解析と、一つの channel の時間の領域の試算。

**比べる相手。** Plomp & Levelt の測定を Hz で当てはめた Sethares の式。Sethares の公開のコード（`disscurve2.cpp`）で確かめた：d = e^(−3.51 s Δf) − e^(−5.75 s Δf)、s = 0.24/(0.0207 f_min + 18.96)、振幅は小さい方。これは P&L の正規化した曲線の当てはめであり、P&L の測定そのものではない。
- 山の差の周波数：125 Hz で 19.5、250 Hz で 22.7、500 Hz で 26.4、1 kHz で 35.7、2 kHz で 56.1 Hz。
- 今の kernel（ERB の距離で山 0.22 ERB）の山：同じ順に 8.4、11.4、17.4、29.5、53.8 Hz。低い帯域で P&L より狭い。

**検知器**（ERB 幅の 4 次の gammatone の帯、0.5 ERB 間隔、帯ごとの包絡の揺れに揺れの速さの重みを掛け、深さの二乗に帯の power の割合を掛けて足す）
- 揺れの速さの重みを AM の粗さに倣って 70 Hz に山を置くと、純音の組の山は 35〜64 Hz になり、P&L より広い側に寄った（125 Hz で 35〜39 Hz）。
- 重みを P&L の形に当てはめた。実現できる因果の形：一次の high-pass（2.76 Hz）× 一次の shelf（21.9 Hz 以下で 0.475 倍）× 二次の Butterworth の low-pass（127.3 + 0.0342·f_c Hz）。
  - 山のずれ：125 Hz と 250 Hz で 0、500 Hz で +6 Hz、1 kHz で +2 Hz、2 kHz で −8 Hz。
  - 正規化した形の誤差：rms 0.03〜0.05、最大 0.06〜0.16（最大は 125 Hz）。
  - 実現できない形（低い側の傾きを自由にした形）の誤差もほぼ同じだった（loss 0.0068 対 0.0087）。
- P&L の低い側（差 5 Hz 前後で既に山の半分）に合わせると、検知器は 3 Hz 程度の遅いうなりまで数える。今鳴っている音の粗さのうち、遅いうなりの分は、その一周期の遅れで出る。

**組の復元**（1/4 ERB の一つの channel の時間の領域の出力、二音の平均に CF を置く）
- 遅れ D = 64 sample の自己相関 A(mD)（m = 0〜3）から二成分の Prony 法で解くと、差 5、10、20、40 Hz、振幅比 0 dB と −6 dB、平均 125 Hz と 1 kHz のすべてで、差の周波数が正確に戻り、振幅比の誤差は 1.6 dB 以内だった。
- 絶対の位置は fs/D = 750 Hz ごとに折り返すが、channel の平均の位置（今の lag 1 の統計）で決まる。
- D = 512（hop の間隔）では、差 40 Hz が折り返した（fs/D = 93.75 Hz）。D = 64 を使う。
- 試算の平均の長さは 300 ms。統計の窓がうなりの一周期より短いと、交差項が消えず偏る。遅いうなりの組の復元には、うなりの一周期程度の窓が要る（差 3 Hz で約 360 ms）。この遅れは原理的に避けられない。
- 雑音、三つ以上の成分、変化する音での頑健さは未確認。
