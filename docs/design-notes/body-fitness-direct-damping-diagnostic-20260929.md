# 直接部分音モデル：Harmonic減衰の単一介入診断

2026-09-29。[直接モデルv1契約](body-fitness-direct-model-contract-20260929.md)の意味判定は不合格だった。保存された728候補のうち157候補で誤差上限を超え、score最大差0.447470、旧score差0.1以上の順位逆転3対を独立再計算でも確認した。結果を[独立検算](../../target/body-fitness-direct-model-20260929/semantic-v1-independent.md)に保存した。本書は次の診断の取得前定義であり、v1の不合格を取り消さない。

## 問いと変更する一項目

実Harmonic backendには、発音後のspectral energy低下に応じて高次部分音を強く減衰させる処理がある。v1は全区間をenergy=1で代表した。今回の問いは、この省略だけで静的Harmonicの低次質量の不足をどの程度説明できるかである。位相干渉、NSGT応答、peak検出、motion、ADSR等の寄与を同時に同定する試験ではない。

身体、候補、環境は保存済み `semantic-v1.jsonl` の全728件を使う。旧72-frameの音声・解析を再実行せず、同じ保存された旧密度を比較先とする。今回新しく計算するのは直接モデルへの介入値だけであり、独立した検証集合ではない。

Harmonicのk番目の基礎部分音（確定ratio列の順番、1始まり）について、v1のlane powerに次の係数を掛ける。unisonで分かれたlaneにも元のkを使う。

```text
T = 72 * 512 / 48000 = 0.768 sec
E(t) = 0.3 + 0.7 exp(-t / 0.5)
D_k = (1/T) integral_0^T E(t)^k dt
p_l_new = p_l_v1 * D_k
```

時定数0.5秒、floor 0.3、gainの指数0.5*kは隔離版 `src/life/sound/oscillator_bank.rs` に由来する。powerの指数はkになる。強度1の単発onsetを連続時間の自由減衰で代表する。実drive波形、64 sampleごとのgain更新、時間平均と聴感指数の非可換性は残る近似であり、実backendの完全な再現とはしない。

Dはf64の正項の二項展開で計算する。

```text
D_k = sum(j=0..k) binomial(k,j) * 0.3^(k-j) * 0.7^j * F(j*T/0.5)
F(0)=1; F(x)=-expm1(-x)/x
```

最近接bin、同binのpower合算後の聴感指数、A-weighting、帯域境界、Modalの式、全判定値は変更しない。SineとModalの結果はv1の保存値を保持する。追加係数のfit、結果を見た時定数・観測時間の変更、失敗familyの除外は行わない。

## 計算と判定

Pythonによるf64の独立計算を診断用に使う。まずHarmonicについて介入前のv1を再構成し、保存済みの正規化bin質量とのL1が1e-5以下、score差が1e-6以下であることを全対象で確認する。この照合に失敗した場合は、介入値をv1に対する確実な差と報告せず、境界・丸め・定義の不一致を先に記録する。

解析積分の確認には、k=1,2,6,16,64の固定点で独立の複合Simpson積分（16384区間）を使い、絶対差1e-10以下を要求する。これは数式計算の検証であり、旧音響モデルへの適合条件ではない。

全728候補を保持し、family/環境別のscore・level誤差、平均・最大の誤差変化、正規化質量L1、閾値未達件数を記録する。全104候補群のscore最大候補と、旧score差0.1以上の候補対の順位逆転も再計算する。旧の選択用density_mass_effは保存環境行にないため、抽選weightsの独立導出や実runtimeの選択一致は主張しない。

既存のscore 0.025、level 0.0125、明確な順位逆転0の条件を維持する。診断の改善だけを本番採用、全対象合格、同hop成立へ読み替えない。この単位ではsrc/や実消費者を変更せず、資源費用はv1の凍結binaryの費用screenと分ける。
