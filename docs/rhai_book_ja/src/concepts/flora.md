# Flora — スペクトルの成長

Floraは、指定した周波数範囲にスペクトルの重みを成長させる。成長は周波数帯域の
資源を消費し、資源はゆっくり回復する。成長を維持するには、一定以上の密度が必要になる。
聞こえた音の倍音性が高く、資源の残る場所で新しい成長が生じる。鳴らなくなる状態も
この規則に含まれる。これらは作曲のための規則であり、聴覚認知についての主張でも、
音の交代が続くという約束でもない。

PopulationとFloraが互いに作用する経路は音だけであり、内部状態を直接受け渡さない。
habitat busの音からLandscapeが作られ、Floraは慣れが作用する前の評価水準と倍音性を読む。
Floraでは資源の消費と回復が帯域の疲労を既に表す。VoiceとListenerTwinは引き続き慣れが
作用した地形を読む。既定ではFloraは成長と種まきに使う協和性と倍音性からも、
自分が実際に出したhabitat PCMを引く。他のFloraの音は残る。
臨界帯域内の競合は、音にならない質量にも作用する資源消費のkernelが担う。
`send(presentation_bus)`なら自分の音が環境に入らないので、混合したC/Hをそのまま読み、
H/Rのobserverは作らない。`send(habitat_bus)`なら環境に作用するが直接は聞こえない。
共有の拍観測には引き続きすべてのhabitat音が入る。

配置前に`flora().leave_self_out(false)`を指定すると、自分の音を含む混合したC/Hを読み、
H/Rのobserverは作らない。資源の外部消費では引き続き自分のPCMを除く。
Voiceの既定値は`false`、Floraは`true`であり、違いはFloraの一個体が多くの部分音を持ち、
自分の倍音格子で成長と種の位置を支えられるためである。undergrowth-v2の観察では、
地のドローンを外してもこの格子が続いた。その自己支持を残したい場合は`false`を選べるが、
すべての場面で音高が固定される保証ではない。presentationだけに送るFloraは、
どちらの設定でも混合したC/Hを読む。

資源を消費するのは、音にならない部分も含むFlora自身の質量と、ほかのhabitat音の
powerである。後者も、混合したhabitat音から自分のhabitat PCMを引いて測る。
powerの基準は振幅0.03の正弦波の平均二乗（`0.03²/2 = 0.00045`）に
固定し、Floraの振幅を変えても動かさない。観測がない状態を無音とはみなさない。
初回の有効な観測までは資源の初期状態を保ち、その後の欠落では最後に観測した
外音消費を保持する。成長のobserverは配置前の混合した解析履歴を写して始まる。
解析の欠落で観測が無効になった場合、演奏の処理は従来の混合解析と同じく終了する。
自己を除いたC/Hの代わりに混合したC/Hを使わない。周波数の座標系が変われば、古い成長と
種のscanを破棄して新しい観測を待つ。reportには実際に使った成長と種の値を出す。

`flora()`で再利用可能なFloraSpecを作り、`place(spec, placement)`で配置するとFloraを
参照できる。配置後も振幅と生態の速さの倍率を変更できる。次の例では、Populationの
Voiceが作る音とFloraが同じ環境に作用する。

```rhai
let sun = place(harmonic().brain("drone").sustain().amp(0.04), at(110));
let moss = flora().amp(0.03).fade(0.5)
    .tone("sine").residual(false).send(habitat_bus | presentation_bus);
let m = place(moss, consonance(110).range(1, 16));
wait(2);
m.amp(0.015);
release(m);
wait(1);
release(sun);
```

配置時には自分の音がまだ無いため、種の初期分布には混合した地形の値を使う。

`consonance(lo, hi)`では、その範囲の、慣れが作用する前の協和度の正規化前の重みから初期分布を作る。
重みの合計がゼロなら一様分布を使う。`random(lo, hi)`は最初から一様分布を使う。
どちらも密度による選択、個数1、緊張度0、既定の間隔を必要とする。間隔の既定値は
`consonance`が1 ERB、`random`が0。同じ値を明示した指定も受け付ける。
その他の配置先、`at`、`line`、`.peak()`、既定値と異なる指定はスクリプトエラーになる。
範囲の両端は1〜20000 Hzの内側に置き、幅は初期Log2Spaceの1ビンに当たる1/96 octave
以上とする。後で周波数空間が変わり、範囲内のビンがなくなるとFloraは休止する。
範囲内にビンが戻れば再開する。

| メソッド | 指定できる値 | 既定値 | 配置後の変更 |
|---|---|---|---|
| `pace` | 1/64〜4 | 1 | 可能 |
| `amp` | 0〜1 | 0.03 | 可能 |
| `fade` | 0〜60秒 | 2 | 配置前のみ |
| `tone` | `"sine"`、`"resonant"` | `"sine"` | 配置前のみ |
| `residual` | 真偽値。拡散した重みを帯域雑音として鳴らす | `false` | 配置前のみ |
| `leave_self_out` | 真偽値。成長と種のC/Hから自分の音を除く | `true` | 配置前のみ |
| `send` | BusまたはBusSet | 両方の出力先 | 配置前のみ |

配置前に`residual(true)`を指定すると、帯域雑音の層を有効にできる。

`amp`は目標振幅の基準となる倍率であり、上限を表す。一定の音量を保証する値ではない。
フェード、振幅の追従、消えつつある音によって、一時的な出力は変わる。

`amp`と`fade`はf32への変換前後で有限でなければならない。範囲外の値や無限大などは
スクリプト評価時のエラーになる。`pace`は警告を出して対応範囲の境界へ収める。
NaNと負の無限大は下限、正の無限大は上限を使う。境界は48 kHz、hop 512、既定gridで
求めた。下限は0.5 Hzの拍でも退場が有限時間で終わる条件、上限は4 Hzで全周波数範囲を
更新してもobserver一本分の費用以内に収まる条件に基づく。

配置後の変更は保留され、次の`wait`、`flush`、または有効範囲の終了時にUpdateFlora
として発行される。`release(m)`も解放を保留し、同じイベント内で更新の後に
ReleaseFloraを発行する。解放時のフェードにはFloraSpecの`fade`を使う。
解放を指定した後の変更や重複した解放は、警告とともに無視する。

有効範囲を作る動詞は、そこで配置したFloraを終了時に解放する。入れ子なら内側の
Floraを先に解放する。明示した解放のフェードが残る場合は、スクリプトの終了時刻を
延ばす。終了時まで解放されなかったFloraは、Finishの後にフェードアウトする。

Flora の API は Experimental である。力学は作曲上の規則であり、この API の安定性の分類は聴覚認知についての根拠の分類とは別である。

## 拍に合わせた部分音の交代

すべてのFloraは、新しく確認された拍の観測がある間、部分音の出生と通常の交代を、
各Floraの局所時計が通過する機会まで保留する。biomassと資源の変化は止めない。
拍を聴かない方式を選ぶ設定はなく、`flora().metric()`は削除した。

時計の追従はPopulationの`metric()`と同じCouplingClockを使う。確信度に応じて
速さと位相を拍へ寄せ、結合の強さは0.95、初期位相は個体ごとに異なる。
初期の速さには場面のtempo basinの中心を使い、指定がなければ2 Hzとする。
ただしFloraが読む拍は、habitatの実音だけから得た共有の観測である。
fluxと選択中の音響recurrence経路、同じ文化的事前分布を使い、Voiceの内部onset指令や
Floraのlane指令は入力しない。共有の観測はFloraの配置前から進み、Flora自身の
実際のhabitat音も含む。その音によって拍が確認され、維持される循環も許す。

保留中の音は、最後に持っていたtonal windowに今残る超過質量だけを使う。
その質量はresidualから一度だけ引く。windowが空になった場合、範囲外への移動、
最小分離の違反、releaseでは拍を待たずに退場を始める。
出生と通常の交代はhop内のsample時刻で適用する。出生時の振幅slewは維持し、
退場する音には次節の代謝tailを使う。
すべての終端や、実音から検出したonsetが拍と一致する規則ではない。

拍が未確認、観測が未知、または古い間はhopごとの連続した割当に戻る。保留候補を捨てて現在のbiomassから
選び直す。時計をresetしたり、古い候補をまとめて鳴らしたりはしない。

## 歩調と消え方

すべてのFloraは、`temporal_basin(lo, hi)`を拍の速さの事前設定として使う。
初期の速さは中心の周波数（未指定なら2 Hz）である。
すべてのFloraは、確かめられた新しい拍に確信度と結合強度0.95に従って近づき、
拍が未確認、または観測が古い間は中心へ戻る。`flora().pace(k)`は、この拍に対する
生態の速さの倍率を身体の性質として指定する。既定値は1で、配置後も`m.pace(k)`で変更できる。
拍の周波数をfとすると、生態の時間はk*f/2倍で進む。成長は毎秒4kf、資源回復は
20/(kf)秒、消費は0.6/(kf)秒となり、拡散と種まきも一緒に速くなる。位相の補正は拍の機会だけを動かす。この規則は句の長さを認知する模型ではない。

退場する部分音は、代謝に基づく有限の尾を残す。全体の`fade`は
解放時間の上限であり、`fade(0)`なら直ちに終わる。尾が固定数の音の枠を占める間、
新しい音の出生が待たされる場合がある。独立した`rate`と`renewal`は削除した。
`pace(k)`はこれらの共通の時間を倍率化し、拍の速さが一定なら退場尾を1/k倍にする。
出生の振幅slewと全体のfadeは実時間のまま維持し、拍の時計と発音機会は変更しない。

sample 17は持続音の場面で、`temporal_basin(2, 4)`を使う。中心3 Hzは中立の2 Hzの
1.5倍である。拍を運ぶ声部を明示していなくても、実音から拍が確認されれば歩調は変わる。
このbasinは作曲上の選択であり、新しい既定値や最適値ではない。
