# Flora — スペクトルの成長

Floraは、指定した周波数範囲にスペクトルの重みを成長させる。Landscapeに沿う成長と
局所的な広がりに、自分が鳴らした音による疲労を組み合わせる。これらは作曲のために
設けた規則であり、聴覚認知についての主張ではない。

PopulationとFloraが互いに作用する経路は音だけであり、内部状態を直接受け渡さない。
habitat busの音からLandscapeが作られ、Floraはその実効的な評価水準を読む。
全体の慣れが有効なら、その作用を受けた水準を使う。両方の出力先を選ぶと、Flora自身の
音も解析を経て戻ってくる。`send(presentation_bus)`なら音は聞こえるが環境には入らず、
`send(habitat_bus)`なら環境に作用するが直接は聞こえない。

現在の規則では、倍音を含む持続音の周囲で、数秒のうちにほぼ静止したスペクトルへ
落ち着く場合がある。疲労があっても、音の交代や変化が続くとは限らない。
共鳴音を使うと動きが続く場合もあるが、倍音関係への集中は弱くなる。
持続的な変化を約束する仕組みではなく、こうした規則の響きを聴くための構成要素である。

`flora()`で再利用可能なFloraSpecを作り、`place(spec, placement)`で配置するとFloraを
参照できる。配置後も振幅、成長速度、疲労を変更できる。次の例では、Populationの
Voiceが作る音とFloraが同じ環境に作用する。

```rhai
let sun = place(harmonic().brain("drone").sustain().amp(0.04), at(110));
let moss = flora().amp(0.03).rate(0.5).fatigue(6).fade(0.5)
    .tone("sine").residual(true).send(habitat_bus | presentation_bus);
let m = place(moss, consonance(110).range(1, 16));
wait(2);
m.amp(0.015);
release(m);
wait(1);
release(sun);
```

`consonance(lo, hi)`では、その範囲の協和度の正規化前の重みから初期分布を作る。
重みの合計がゼロなら一様分布を使う。`random(lo, hi)`は最初から一様分布を使う。
どちらも密度による選択、個数1、緊張度0、既定の間隔を必要とする。間隔の既定値は
`consonance`が1 ERB、`random`が0。同じ値を明示した指定も受け付ける。
その他の配置先、`at`、`line`、`.peak()`、既定値と異なる指定はスクリプトエラーになる。
範囲の両端は1〜20000 Hzの内側に置き、幅は初期Log2Spaceの1ビンに当たる1/96 octave
以上とする。後で周波数空間が変わり、範囲内のビンがなくなるとFloraは休止する。
範囲内にビンが戻れば再開する。

| メソッド | 指定できる値 | 既定値 | 配置後の変更 |
|---|---|---|---|
| `amp` | 0〜1 | 0.03 | 可能 |
| `rate` | 毎秒0.05〜4 | 0.5 | 可能 |
| `fatigue` | 0〜600秒。0で疲労を無効化 | 6 | 可能 |
| `fade` | 0〜60秒 | 2 | 配置前のみ |
| `tone` | `"sine"`、`"resonant"` | `"sine"` | 配置前のみ |
| `residual` | 真偽値。拡散した重みを帯域雑音として鳴らす | `true` | 配置前のみ |
| `send` | BusまたはBusSet | 両方の出力先 | 配置前のみ |

数値はf32への変換前後で有限でなければならない。範囲外の値や無限大などは
スクリプト評価時のエラーになり、境界値へ丸められることはない。

配置後の変更は保留され、次の`wait`、`flush`、または有効範囲の終了時にUpdateFlora
として発行される。`release(m)`も解放を保留し、同じイベント内で更新の後に
ReleaseFloraを発行する。解放時のフェードにはFloraSpecの`fade`を使う。
解放を指定した後の変更や重複した解放は、警告とともに無視する。

有効範囲を作る動詞は、そこで配置したFloraを終了時に解放する。入れ子なら内側の
Floraを先に解放する。明示した解放のフェードが残る場合は、スクリプトの終了時刻を
延ばす。終了時まで解放されなかったFloraは、Finishの後にフェードアウトする。
