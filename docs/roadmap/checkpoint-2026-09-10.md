# 時間構造DCCの停止地点

日付: 2026-09-10
状態: 短時間の参加実装と研究比較を保存し、全階層の設計メモ・完成計画を確定した。新計画のM0は未着手。

## できていること

| 範囲 | 到達点 | 確認の限界 |
|---|---|---|
| 和声・協和 | 既存のR/H/C地形と音高の適応を維持している。今回の中心は時間構造であり、和声カーネルの再設計ではない | 全階層の和声的期待や終止を実装したわけではない |
| 短時間の参加 | 通常Voiceで身体の固有周期、参加周期、音長を分離した。実音の文脈に応じて鳴る・待つ・見送る。明示的な同期と参加を区別する | 現行の参加記憶は二窓×三帯域の短期表現であり、新メモの関係記憶ではない |
| 音楽的な確認 | 指定された08の比較で「縮退してない」、12で「流れは損なわれていない」という作者所見を記録した。専用の拍打ちは明示的な同期が必要な実演に限る | 全seed・長時間での自然さ、受け渡し、グルーヴの成立を一般化しない |
| 観測と研究用比較 | 実音の短期・スペクトル履歴、因果的な予測、順序・文脈・行動の対照、欠測と既知無音の区別を実装した。研究用スクリプトと検査を保存した | 予測誤差の改善をフレーズ理解や認知的妥当性の証明にしない。研究比較の成功を本番接続と同一視しない |
| 全時間階層の設計 | アーティキュレーション、拍・小節、グルーヴ、反復・変奏、フレーズ、section、全曲文脈の表現・更新・生成結合・検証条件を定めた | 実装・パラメータ同定・実機性能・聴取実験の達成とは別である |
| 完成までの計画 | 現行実装からM0–M9、全T1–T7と四判定までの依存、成果物、失敗時の戻り先を定めた | 計画の完成であり、時間構造DCC全体の完成ではない |

短時間の採用範囲は[時間的ニッチの記録](../design-notes/rhythm-temporal-niche.md)を参照する。
研究の経過と原理上の到達点は[日英の設計台帳（旧設計台帳（旧技術ノート第9章））](../design-notes/technote-ledger.ja.md)に記録した。

`no_actionable_issues`、`issues: []`となった。実際の応答と版の対応は
[レビュー記録](../design-notes/dcc-hierarchy-review.md)に保存した。
受入原稿のSHA-256は`8b88ebcc987e6a9b4a8923f68748469c544387b2ba38c1e1d47f094122d681d9`であり、
停止地点の記録を追加する際にも、この原稿は変更していない。

統一するのは、観測した関係を保持・予測し、局所的な生成へ返すP/M/Aの契約である。
全ての時間尺度を一つの遅い振動子へ置き換える設計ではない。

## できていないこと

- 新メモに沿う二領域の受動認知、順序付き関係記憶、変奏・想起、フレーズ境界と終止、section・全曲文脈の統合実装。
- 長い文脈が、局所音を揃えた条件でも発音・持続・release・応答を変える生成結合。
- グルーヴ、受け渡し、変奏、帰還、終止を聴取者の判断へ対応づける検証。
- 保持時間、更新率、閾値などの認知的な同定。これらはDCCの原理から一意に導出済みではない。工程では認知仮説、学習する値、工学的な容量・計算上限を分けて検査する。
- 新しい全階層モデルを同時に動かした実機の計算可能性、遅延、4／16／64 Voiceと長時間演奏の受入。
- 公開Manifestoの時間能力の現在形記述を、実装根拠または設計目標へ文ごとに照合・改訂するO02の実行。
- 全T1–T7について、実装契約・認知課題・意図した関係の可聴性・作者採用の四判定。完成計画の28セルは未達のまま保持する。

既存の個別実装や特定の試聴での成功は保持するが、新モデルの合格へ自動転記しない。

## 再開位置

[完成計画](temporal-dcc-completion.md)のM0から再開する。

1. このcommitを基準として、source・設定・採用済み試聴条件の内容ハッシュを固定する。
2. T1–T7の刺激、回答、対照、採点、データ分割、必須比較の合否条件と特徴一覧を登録する。
3. 想定する全経路の数値preflightと、記憶・参加trace・事象headの模擬検査を進める。人の収集前に必要な条件を満たす。
4. その後、M1の因果的な受動経路から実装する。下位の波形予測の全面的な成功を、長い時間構造への着手条件にしない。

今回は停止地点の保存までとし、M0の新しい実験・実装へは進めていない。

## 保存範囲

前回の`a5447e1`以後に積み上げた時間参加の実装、観測・研究比較、テスト・CI、Rhai資料、
試聴所見、技術ノート、全階層設計とレビュー記録を一つのcheckpointへ保存する。
`.claude/`と`.codex`はローカルのエージェント設定として対象外とする。
`target/`配下の試聴音源・実験出力とignoredの実行ログはローカルに残るが、このcommitには含まれない。
したがって、別環境で過去の試聴音源まで復元するには該当成果物の保持または再生成が必要である。
楽器本体へ録音経路は追加せず、保存する比較音源には分離rendererを使う。
