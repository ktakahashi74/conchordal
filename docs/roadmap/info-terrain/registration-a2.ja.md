## 1. 改訂の理由（A-1 の実測で分かったこと）

### 1.1 原型版は、微小でゆっくりした単調な変化に過敏である

- **実測。** sine だけの Flora の驚きの平均が 1.56 になり、統制刺激と既存のサンプルのどれよりも高かった。
- **WAV の直接の解析**（主要な 8 bin、9〜12 s）。
  - 驚きの平均は 1.42。
  - 51 % のフレームで、現在の値が直前 1 秒の範囲の外にあった。
  - 1 秒の窓の中の変化の幅は、中央値 0.41 dB、90 パーセンタイル 2.05 dB。
- **部分音の毎秒の変化**（report）。周波数は中央値 0.05 cents/s（最大 2.7）、振幅は中央値 0.47 dB/s。
- **仕組み。** 原型の `½ z²` は、履歴の標準偏差で正規化されるので、尺度に依存しない。母標準偏差で計算すると、等間隔で 0 でない直線のランプは、傾きによらず `|z| = sqrt(3(n+1)/(n−1))` を与える。`n = 92` では `|z| = 1.751`、`S = 1.533` である。

### 1.2 拡張版は、起動時の過渡が長く、残差の平均がほぼ 0 などの条件の下では、自己正規化によって約 0.5 に収束する

- **実測。** 周期の刺激では、驚きの平均が 0.23（2〜6 s）から 0.50（14〜20 s）へ上がった。白色雑音では、最初から 0.50 だった。
- **診断**（440 Hz の bin の内部状態を hop ごとに記録）。
  - 重みと残差分散を 0 から始め、`EMA(a)` は、その bin が静かな相のときの振幅（0.035）で初期化されていた。
  - その後の大きな相で、正規化した目標が大きくなり、残差分散 `v̂` が約 3800 まで膨らんだ。
  - `τ = 1 s` で、古い分散の寄与が真の値の程度（約 1）まで落ちるのに、およそ 8 秒（ln 3800 ≈ 8.24）かかる。新しい床 `δ² ≈ 0.0149` まで落ちるには、およそ 12.5 秒かかる。いずれも、続く残差と更新の停止を無視した概算である。
- **定常での値。** `S′ = e² / (2 v̂)` は、残差の分散で自分自身を正規化している。
  - 分散の推定が真の分散 `σ²` に近く、床と上限が効かなければ、`E[S′] ≈ ½ (1 + μ_e² / σ²)` になる。
  - 約 0.5 になるのは、残差の平均がほぼ 0 のときである。過去の EMA の有限標本の変動や、残差との依存は、この近似に含めていない。

1.1 と 1.2 は、登録した定義の性質で説明できる。実装の誤りを示す所見は見つかっていない。

## 2. 改訂の内容

### 2.1 知覚の床（両方の版）

**目的。** 弁別閾より小さな偏差で、驚きが過大に評価されるのを抑える。閾下の驚きを 0 にする規則ではない。0 でない偏差には、正の驚きが残る。

**根拠と、その限界。**

- **Jesteadt, Wier & Green 1977**（*JASA* 61:169–177）。純音の強度の弁別閾は、レベルとともにわずかに下がり、Weber の法則から少し外れる（near miss）。判定基準は 71 % 正答である。ここでは、この定性的な所見だけを根拠とする。
  - 当てはめの式とレベルごとの値は、原典でも二次文献でも照合していないので、根拠に含めない。近い主題の二次文献として Augustin 2008（*J Math Psychol* 52:37–47）があるが、式の掲載は確認していない。
- **Miller 1947**（*JASA* 19:609–619）。広帯域の雑音について、要旨は、感覚レベル 30 dB を超えるとおよそ 0.41 dB（50 % 検出の基準）としている。同じ桁であることの参考にはなるが、1 dB の直接の根拠ではない。
- **弁別閾の意味。** 弁別閾は、課題の上での判別成績の基準である。それより下なら知覚されない、という境界ではない。
- **authored な移し替え。** 純音や広帯域音の閾値を、NSGT の各 bin、ゆっくりした変化、予測の残差に移すのは、すべて authored の部分である。再生の感覚レベルは校正していないので、1 dB が実際に「中程度の感覚レベル」に当たるとも、床として「控えめ」であるとも断定しない。

**値。**

- `ΔL = 1.0 dB` とする。上の文献が示す弁別閾と同じ桁の値として選んだ authored の値である。振幅の相対変化に換算すると、増加の側は `δ = 10^(ΔL/20) − 1 ≈ 0.122`、減少の側は `1 − 10^(−ΔL/20) ≈ 0.109` になる。
- 両側に増加の側の値 `δ ≈ 0.122` を使う。この対称の近似は authored である。
- パワーを入力とする版では、`δ_P = 10^(ΔL/10) − 1 ≈ 0.259` を使う（第3節）。

**原型版。**

- 驚きの分母を `sd_eff = max(sd, δ · m)` とする。`m` は現在を除く窓の平均で、既存の無音の判定の後なので `m > 0` である。
- 偏差が `|a − m| = δ m` のとき、`|z| ≤ 1`、`S ≤ 0.5` になる。等号は `sd ≤ δ m` のときに限る。
- 一定の履歴（範囲が厳密に 0）の扱いは変えない。驚きは欠測（逸脱が大きくても欠測）、精度は 1 とする。
- 精度 `1 / (1 + c²)` は変えない。

**拡張版。**

- 目標は `B = EMA_{t−1}(a)` で正規化されている。そのため床 `v_eff = max(v̂, δ²)` は、振幅の単位では `δ B` にあたる。これは「EMA を基準とする相対残差の床」であり、予測振幅に対する 1 dB の差と一致するのは、予測振幅が `B` に等しいときだけである。
- 驚きは `S′ = min(e_t² / (2 v_eff), −ln 1e-12)`、精度は `1 / (1 + v_eff)` とする。精度の上限は `1 / (1 + δ²) ≈ 0.9853` になる。原型版の上限は 1 なので、これは仕様上の非対称である。どちらの精度も、聴取上の予測精度とは同定していない。
- 床は、評価に使う分母にだけかける。残差の分散の更新そのもの（`v̂` の値）は床で切り上げない。
- 登録 §9 の `v_floor = 1e-12` は `δ²` に置き換える。

**含意。**

- 床は `m` と `B` に比例するので、正の一様な利得に対して、両方の版は不変のままである。
- 弁別閾はレベルと刺激の種類に依存する。一定値 1 dB は単純化である。周波数の変化は、bin の振幅の変化を通してだけ間接的に扱う。

### 2.2 拡張版の起動と再初期化

- **重みの初期値と戻し先。**
  - 重みは「直前の値をそのまま予測する」形 `w₀ = (0, 1, 0, …, 0)` から始める。
  - 登録 §4 の「重みが非有限なら `w = 0`」、および非有限値で状態を戻す規則も、すべて `w₀` に戻すことに置き換える。
- **残差の統計の初期値。** `v̂ = δ²`、`μ_e = 0` とする。状態を戻すときも同じ値にする。
- **`EMA(a)` の初期化。**
  - 窓が埋まった後、条件を満たす最初のフレームで行う。条件は二つ。bin が無音でないこと、その bin の窓の平均 `m_b`（現在を除く）が有限で正であること。
  - 窓が埋まった時点で条件を満たさなければ、満たす最初のフレームまで毎フレーム試す。
  - 初期値は、その時点の `m_b` とする。登録 §4 の「現在振幅」は、これに置き換える。
  - 初期化したフレームでは、RLS も残差の EMA も更新せず、指標を欠測とする。この扱いは変えない。

### 2.3 変えないもの

次は登録 §1〜§9 のままとする。

- 窓、`minProb`、欠測の順序、無音の判定、集約、配送、不変性の要件、刺激。外部照合の手順は、第3節の床の扱いを除いて変えない。

## 3. 実測（A-1 と同じ手順を A-2 で繰り返す）

- 登録 §7 の 7.1〜7.4 を、A-2 で同じ seed、同じ刺激で実行する。A-1 の値と A-2 の値を表に並べ、差を報告する。
- **外部照合での床の扱い。**
  - 規則 S（soundgen 3.0.0 の再現）は、原典を再現する版なので床を入れない。A-1 の値をそのまま使う。
  - 規則 O の 3 版（R-O、N-O、N-P-O）には、それぞれの入力の単位で床を入れる。R と N-P はパワーなので `δ_P ≈ 0.259`、N は振幅なので `δ ≈ 0.122` を使う。
  - 主な対比は、N-O の A-2 と A-1 の差（床と起動の改訂の効果）である。R-O と N-P-O の A-2 と A-1 の差は、補助として記録する。原典との差（S と O）には、床の効果も混ざる。
  - ブートストラップの再標本は、A-1 と共通の seed で作る。

### 3.1 改訂の効果についての仮説（合否の閾値は置かない）

床が効くのは、`sd < δ m`（原型版）または `v̂ < δ²`（拡張版）のときだけである。偏差の大きさそのものでは決まらない。この条件に照らして、次を予想する。

- **sine だけの Flora：** 窓の中の散らばりは、多くの bin で `δ m` より小さいと見込まれる（窓の中の変化の幅は中央値 0.41 dB）。そのため原型版の驚きの平均は、A-1 の 1.56 より下がると予想する。下がる大きさは予想しない。
- **純音：** 床は分母を大きくする方向にしか働かないので、原型版の驚きの値が増えることはない。床が効く bin（`sd < δ m`）で偏差が 0 でなければ、驚きは下がる。床が効かない bin では変わらない。履歴が一定で全欠測になる bin は、0 とは区別して数える。
- **白色雑音と pink 雑音：** bin の振幅の窓の中の散らばりは、多くの bin で `δ m` より大きいと見込まれる。その場合、床はほとんど効かない。
- **周期と逸脱：** 切り替えの区間では窓の中の散らばりが大きいので、床は効きにくいと予想する。ただし `sd < δ m` となる bin や時刻では変わりうる。
- **拡張版：** 初期化に由来する起動の過渡は縮小すると予想する。RLS の学習による過渡は残りうる。窓の平均による初期化も、周期や窓の長さによっては相に依存しうる。

### 3.2 二層分類

- 弁別閾は、確立した心理音響の量である。
- `ΔL = 1 dB` という値の選び方、対称の近似、床を分母の下限として入れる形、NSGT の bin と予測の残差への移し替えは、authored 層とする。
