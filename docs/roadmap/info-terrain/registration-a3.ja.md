## 1. 位置づけと主張の範囲

**動機。** 探索 A4 では、序列が単一の驚きでは表せず、複数の次元の組み合わせが要ることが示唆された。

**着想の元。** 期待自由エネルギー（EFE）の分解である。

- 方策の価値は、外在的な価値（選好）と認識的な価値（情報利得）に分かれる（Friston et al. 2015, *Cogn Neurosci* 6:187–214）。
- 探索には二つの型がある。一つは、曖昧でない観測で隠れた状態を推定する型。もう一つは、不確かでも学べる結果で構造を学ぶ型である（Schwartenbeck et al. 2019, *eLife* 8:e41703）。

**EFE との違い。** 本登録の量は、EFE ではない。

- EFE は、方策の下での予測分布と観測空間から導く量である。
- 本登録の量は、現在の事後分布から求める曖昧さの指標と、実現した情報利得の指標である。
- EFE には「リスク＋曖昧さ」と「選好の費用 − 情報利得」の二通りの分解がある。本登録の合成値は、前者から曖昧さを、後者から情報利得を借用した独自の合成である。どちらの分解とも同一ではない。
- 合成値は「EFE に着想を得た受動的な合成値」と呼ぶ。「豊かさ」とも EFE とも呼ばない。

**生成モデル。** 観測の確率的な揺らぎ（stochasticity）と状態の変化（volatility）を同時に学ぶモデル（Piray & Daw 2021, *Nat Commun*, doi:10.1038/s41467-021-26731-9）。

**三条件。**

- **条件1：** 構成要素の応答に根拠がある。MMN は、自由エネルギーに基づく学習のモデルが最もよく説明した（Lieder 2013）。精度の追跡（Barascud 2016）、学習への報酬（Gold 2019）も根拠になる。ただし、この ERB セルのモデルや合成値に対応する聴取機構が同定されているわけではない。条件1は部分的な根拠にとどまる。
- **条件2：** 明示した工学規則として書く。
- **条件3：** 新しい人のデータは要らない。

これらは受動的な診断の例外の範囲での位置づけであり、生成への結合の根拠にはならない。

## 2. 観測の単位

- **セル。** runtime の Log2Space の全体を、Flora と同じ規則で 1 ERB 幅のセルに分ける（`E(f) = 21.4 log10(1 + 0.00437 f)`、0.5 ERB 未満の端は併合、bin は中心で割り当てる）。
- **観測。** セル `c` の対数振幅 `o_c = ½ ln(Σ_{b∈c} P_b + ε_P)`。`ε_P = (1e-4 · M)²` で、`M` は A-1 と同じ。
- **無音の扱い。** 本登録は「有音のときに条件づけた診断」とする。
  - `Σ_{b∈c} P_b < ε_P` のセルは、その hop では予測も更新もせず、状態を凍結し、欠測とする。
  - 再び鳴ったときは、凍結した状態から続ける（無音の間の経過時間は扱わない）。
  - 音の消失は観測しない。そのため、音の有無の切り替えそのものは、この診断の対象外である。
- **全体の欠測。** `M = 0` のときは、全セルを欠測とする。
- **時刻と順序。** 更新は解析の hop ごとに行う（既定 ≈ 10.7 ms）。A-1 の欠測の順序（取りこぼし → 再充填 → 開始）に従う。

## 3. 生成モデルと推論

### 3.1 原典の式（照合済み）

```
x_t ~ N(x_{t−1}, v_t)
o_t ~ N(x_t, s_t)
z_t = 1/v_t = η_v⁻¹ z_{t−1} ϵ_t,   ϵ_t ~ Beta(0.5 η_v / (1 − η_v), 0.5)
y_t = 1/s_t = η_s⁻¹ y_{t−1} ε_t,   ε_t ~ Beta(0.5 η_s / (1 − η_s), 0.5)
λ_v = 1 − η_v,   λ_s = 1 − η_s
カルマン：δ = o − m;  α = (w + v)/(w + v + s);  m ← m + α δ;  w ← (1 − α)(w + v)
粒子の重み：b^l ∝ b^l_prev · N(o | m^l, w^l + v^l + s^l)
```

### 3.2 推論の手順

1. **予測。** 各粒子の `z` と `y` を、Beta の乱数で一歩進める。
2. **重みの更新。** `b^l ← b^l_prev · N(o | m^l, w^l + v^l + s^l)`。対数の重みで計算してから正規化する。
3. **カルマン。** 各粒子の `m^l` と `w^l` を、上の式で更新する。
4. **評価。** ここで、再標本化の前に、`A`、`N`、`S_x`、ESS、`v̂`、`ŝ` を計算する。同じ粒子の仮説の上で、更新の前後の分布を比べるためである。
5. **再標本化。** 有効粒子数 `ESS = 1 / Σ (b^l)²` について、`ESS / L < 0.5` のときだけ行う（原典どおり）。系統的再標本化で、`(v, s, m, w)` を組として複製し、重みを一様に戻す。
6. **初回の観測。** 状態の事前分布 `N(o_first, 1)` を作るためだけに使う。その hop では更新せず、指標は欠測とする。

### 3.3 原典からの変更（すべて authored）

- **観測の対象。** 「報酬」の代わりに、セルの対数振幅を観測とする。
- **時間の単位。** 更新を hop 単位にする。
- **値。** 粒子の数 `L = 64`（原典は約 100）、`λ_v = λ_s = 0.01`（hop あたり）、`v_0 = 0.01`、`s_0 = 0.05`。
  - `λ` から変化の時間尺度は直接は導けないので、時間尺度は主張しない。
  - 64 粒子で十分かどうか、5 秒で学習が終わるかどうかは、確認していない扱いとする。
- **乱数。** splitmix64 による決定論的な列を使う。
  - 一様乱数は開区間 (0, 1) にとる。
  - Beta の乱数は、Marsaglia–Tsang 法で作った二つのガンマ変量の比とする。形状母数が 1 未満のときは補正をかける。
  - 独立な乱数の列を、セル、ストリーム、粒子の遷移、再標本化の別に割り当てる。
- **数値の規約。**
  - 推論と指標の計算は、すべて `f64` で行う。
  - 分散 `w`、`v`、`s`、`w + v + s` が有限で正であること、および更新の前後の `m` が有限であることを、毎 hop 確かめる。満たさなければ、そのセルを再初期化し、その hop は欠測とする。再初期化では、`m = o_t`、`w = 1`、`v = v_0`、`s = s_0`、重みを一様にする。
  - 重みは対数で持ち、log-sum-exp で正規化する。最大の対数重みより 700 以上小さい粒子は質量 0 とし、その対数重みを `−∞` にする。`−∞` の粒子は、再標本化で選ばれない限り復活しない。その数を記録する。
  - KL は対数重みの差で計算する。事後の重みが 0 の項は、演算の前に除く。事後の重みが正で、予測の重みが 0 の項が現れたら異常とみなし、そのセルのその hop を欠測とする。
  - `A`、`N`、`S_x` のどれかが非有限になったら、そのセルのその hop を欠測とする。

## 4. 指標（セルごと、hop ごと）

- **床つき曖昧さの指標 `A`。** `A = ½ ln(2πe) + ½ Σ_l b^l ln max(s^l, s_floor)`。
  - `s_floor = (ln 10^(1/20))² ≈ 0.01325` は、1 dB を対数振幅の標準偏差に対応させる規約である（authored）。知覚の分散を実証的に裏づけたものではない。
  - 床は評価のときだけかける。推論に使った尤度そのもののエントロピーではない。
  - 微分エントロピーなので負の値をとり、座標の尺度に依存する。
- **粒子の仮説についての実現した情報利得 `N`。** `N = Σ_l b^l ln(b^l / b^l_pred)`。`b_pred` は、予測の段階の重み（再標本化の後なら一様、そうでなければ前の重み）である。
  - 粒子は履歴に由来する `m` と `w` も持つので、`N` は `(v, s)` だけに周辺化した情報利得とは同一でない。
  - 動的な分散の追跡を、構造の学習と同一視しない。
- **粒子に条件づけた状態の情報利得 `S_x`（対照）。** `S_x = Σ_l b^l KL(N(m^l, w^l) ‖ N(m^l_prev, w^l_prev + v^l_t))`。KL の向きは、事後分布から事前分布へとする。混合分布としての `x` の周辺 KL ではない。合成値には入れない。
- **現在のスペクトルと地形の不一致 `R`（参考）。** `R = Σ_c p_c ln(p_c / q_c)`。
  - `p_c` は、有音のセルの中で正規化したエネルギーの割合であり、無音のセルでは `p_c = 0` とする。全セルが無音の hop では、`R` は欠測とする。
  - 地形を作る設定（config の内容と、`[psychoacoustics.habituation]` の有効・無効と初期状態）は、実測のたびに記録する。既定では habituation は無効である。
  - `q_c ∝ exp(β C̄_c)` は、全セルで正規化する。`C̄_c` は、同じ hop の地形の `consonance_field_level_eff` のセル内平均、`β = 4` とする。
  - `R = −H(p) − β E_p[C̄] + ln Z` なので、地形が平坦ならエネルギーを広げた音ほど低くなる。組織を報いる保証はない。そのため合成値には入れず、参考として記録するだけにする。

**合成値。** `V = Ñ − Ã`。

- **集約の集合。** 各 hop について、`A`、`N`、`S_x` がすべて定義されたセルの集合をとる。初回の観測や数値の異常で欠測したセルは除く。
- **重みつき平均。** `Ã`、`Ñ`、`S̃_x` は、その集合の上で、エネルギーの重みを総和 1 に正規化し直した重みつき平均とする。集合が空の hop は欠測とする。
- **時間平均。** 刺激ごとの値は、定義された hop についての時間平均とする。定義されたセルの数と hop の数を、あわせて記録する。
- 重みを 1 とすること、和ではなくエネルギー重みの平均にすること、刺激ごとに評価区間の時間平均をとること、`S_x` と `R` を除くことは、すべて authored の選択である。単位が nat で揃っていることから、重み 1 が導かれるわけではない。

## 5. 第1段：分離と回復の検証

### 5.1 合成した系列

**格子。** 3 × 3 の条件をとる。`v ∈ {1e-4, 1e-3, 1e-2}`、`s ∈ {1e-3, 1e-2, 1e-1}`。seed は、`v` を外側、`s` を内側にした行優先の順で、101〜109 を割り当てる。

**生成式。** hop 単位で作る。

```
x_0 = ln 0.1
x_t = x_{t−1} + N(0, v)
o_t = x_t + N(0, s)
```

**長さ。** 20 秒ぶん（48 kHz、hop 512）。

**入力の経路。** 二つの経路で入れる。各条件・各経路を 1 回ずつ実行する。

1. **直接入力。** `o_t` を、モデルの一つのインスタンスにそのまま入れる。
2. **解析経路。** 1000 Hz を含むセルの中心周波数の純音を合成する。振幅包絡を `exp(o_t)` とし、hop の中心の間は線形に補間する。位相は連続させる。正規化はしない。この音を NSGT の解析経路に通し、そのセルの観測を使う。評価するのは指定したこの一つのセルだけで、他のセルへのエネルギーの漏れは対象外とする。

### 5.2 記録と合否の基準（事前に固定）

評価区間 10〜20 s での、`v̂ = Σ_l b^l v^l` と `ŝ = Σ_l b^l s^l`（評価の時点、§3.2 の 4）の、時間中央値をとる。真の値との比較は `log10` で行う。推定が求まらない条件は、不合格として数える。基準は次の三つで、直接入力と解析経路のそれぞれについて、すべてを満たすことを求める。

- **順序：** 9 条件について、`log10 v̂` と真の `log10 v` の Spearman 順位相関が 0.8 以上。同順位には平均順位を使う。`ŝ` と `s` についても同じ。
- **値：** `|log10 v̂ − log10 v| ≤ 0.5`（およそ 3 倍以内）が 9 条件のうち 7 条件以上。`ŝ` についても同じ。
- **混線：** `s` を固定して `v` だけを変えたとき、`log10 ŝ` の変化の幅（3 条件の最大と最小の差）が、`log10 v` の変化の幅（2）の 0.3 倍以下。これが `s` の 3 水準のすべてで成り立つこと。`v` を固定して `s` を変えたときも同じ。

**有効な hop の割合。** 各条件で、評価区間の hop の 90 % 以上で推定が定義されていなければならない。満たさない条件は不合格とする。

**乱数の割当。** 系列の生成には上の seed を使う。推論の乱数には、その seed に 50000 を足したものを使う。

**安定性。** 基本の設定（seed 101〜109、粒子 64、初期値 `(0.01, 0.05)`）から、一度に一つの要因だけを変えた次の 4 つの変種で、上の判定を繰り返す。これは実装の検査であり、設定の選択には使わない。

1. seed +1000（1101〜1109。系列と推論の両方に適用）
2. seed +2000（2101〜2109。同上）
3. 粒子の数 128
4. 初期値 `(v_0, s_0) = (0.001, 0.5)`

**合格しなかった場合。** 基本の判定か、安定性の変種のどれか一つでも不合格なら、第2段には進まない。A-3 は採用せず、結果を所見として記録する。

**リセット。** 刺激ごとに、次をすべて初期化する。

推論の乱数の seed は、`7001 + セルの番号` とする（ストリームごとに別の列）。

### 6.2 仮説

評価区間は 5〜20 s とする。

**欠測の基準。** 各刺激・各評価区間で、次の二つを満たさない刺激については、その刺激が関わる比較をすべて「成り立たなかった」と数える。

- 数値の異常による欠測の率が 5 % 以下であること。率は、評価区間の中で、数値の異常により欠測した有音の（セル, hop）の組の数を、有音の（セル, hop）の組の総数で割ったものとする。
- 定義された hop が 90 % 以上であること。値は時間平均で比べる。比較は固定した刺激の上での向きの判定であり、刺激一般についての統計的な主張はしない。同じ値（差が `1e-9` 未満）のときと、欠測で値が求まらないときは、「成り立たなかった」と数える。

- **H-A：** V1 と V2 の `Ã` は、V3 と V4 の `Ã` のどれよりも大きい（4 つの組がすべて成り立つこと）。
- **H-N1：** V6 の 3 本の `Ñ` は、V1、V2、V3 の `Ñ` のどれよりも大きい（9 つの組がすべて成り立つこと）。
- **H-N2：** V4 について、集約した値（§4）で `ΔN = Ñ(0–5 s) − Ñ(15–20 s)` と `ΔS = S̃_x(0–5 s) − S̃_x(15–20 s)` を求める。各区間の定義された hop の数と、セルの数を併記する。予測は `ΔN > 0` かつ `ΔS < ΔN`。
  - これは限定された減衰の予測である。V4 は音高がランダムでも、250 ms の周期と音の持続という学べる構造を持つ。また `λ > 0` のモデルでは、定常でも `N` が消える保証はない。
  - V3 についても同じ `ΔN` を記録する。これは参考の対照であり、初期化の過渡と学習の効果を区別するものではない。
- **H-V：** V1 と V2 の `V` は、V6 の 3 本の `V` のどれよりも小さい（6 つの組）。V4 の 15〜20 s の `V` は、V6 の 3 本の `V` のどれよりも小さい（3 つの組）。純音や V3 とサンプルの間の向きは定めない（記録だけ）。

### 6.3 記録する診断

セルと hop ごとに、次を記録する。

- ESS と最大の重み
- `N` の分布と、予測の重みの最小値
- 重みが数値的に消えた（正規化の前に下限を下回った）粒子の数
- `s_floor` が効いた割合
- 有音のセルの数

`N` の上限が `ln L` になるのは、予測の重みが一様のときだけである。一般には、正の予測の重みについて `−ln min_l b_pred^l` が上界になる。

## 7. 実装上の要件

A-1 から引き継ぐ。

- 既定 off、受動的。地形にも生成にも、どの経路でも渡さない。
- ストリームごとに独立に計算する。
- 集約と配送は専用チャネルで行う。
- 不変性は、off で bit 一致、on で決定論的な出力の一致として検証する。

## 8. 二層分類

- **原理層の候補：** 宣言した生成モデルの下での、カルマンの式とガウス分布の KL・エントロピーの数式としての恒等式だけ。
- **authored 層：** 次のすべて。
  - 粒子による近似、再標本化の規則、学習則
  - 観測との対応（セル、対数振幅、無音の凍結）
  - 値（`L`、`λ`、初期値、`s_floor`、`β`）
  - 合成の形と重み、時間平均
- 原典との照合は、生成モデルの式を写したことを確かめるものである。知覚量を原理層に移す根拠にはしない。
