## 0. 1年を経て見えたこと（改訂の出発点）

2025-12-25 の初版マニフェストは、「記号グリッドの解体」「直接認知結合（DCC）」「生きた現象としての演奏」という核を打ち立てた。1年間の実装と実証（`technote-ledger` §9.3.1〜§9.3.134、DR-1〜DR-42）を通じて、**揺るがない原理**と、**初版スケッチが甘かった／抜けていた前提**の両方がはっきりした。

- **1年で実証された核**：
  - 音名・音階・拍子記号を一切持たず、実音から計算する聴覚地形（R・H・C・慣れ）の上で生態系が調和を自己組織化できる。
  - 音だけで結合する異種の住人（Population / Flora / Rain）と共有の音響空間（部屋・距離）により、記号によらない音楽的説得力が生まれる。
  - バイナリ境界による Air-Gap と単一コアのネイティブ／ブラウザー両立は現実の楽器として成立した。
- **1年で露呈した初版の空白・緊張**：
  - 「協和の引力（R/H/C）」だけでは音は安定点に落ち着いて止まり、自律的な動き・旋律は創発しない（温度抽選はランダム、温度0は固着、PD/FI/SH/SONG/NR-1 はいずれも未達）。
  - 人の音楽的期待の大半は聴取経験・文化（Layer 3/4）に根差しており、「コーパスを入れない第一原理生成」との緊張が未言語化のまま。
  - 音楽的説得力を実際に支えた「響き（身体の共鳴・テクスチャ・空間）」が、初版の「周波数軸×時間軸」の二軸図式から抜け落ちていた。
  - 2026年9月の改訂で時間軸節に実務的な現状注記が入った結果、「宣言文」と「実装報告書」が混在している。

## 1. 決めるべき 5 つの核心論点（M1 → M2 へ渡す判断）

### 論点 1：「協和の引力」の先に、「動く力」をどう位置づけるか
初版は「失われた音楽の重力を取り戻す」と書いたが、重力（協和）は静止点をつくる力であり、音楽を前へ運ぶ力そのものではない。

- **選択肢 A（生態と順応の力学として明記）**：動きの源を「慣れ（順応による地形の侵食）」「個体の代謝・寿命・交替（出生と死）」「他者の音や余韻への応答」という**生態系の非平衡**に置き、協和はその中で瞬間ごとの引力として働く、と書き直す。
- **選択肢 B（未解決の第二原理として正直に掲げる）**：周波数軸の引力（協和）は実装できたが、時間軸で「協和から離れて戻る認知的必然性（期待と逸脱の力学）」は Conchordal がこれから解く中心課題である、と未解決の問いとして明記する。
- **推奨**：**A＋B の併用**。現在すでに動いている非平衡の源（順応・代謝・交替・響きの変容）を正面から述べつつ、「旋律的な期待と帰結の原理」は未踏の問いとして誠実に残す。

### 論点 2：「コーパス非依存」と「文化・経験（Layer 3）」の緊張をどう引き受けるか
初版は生成AIの統計模倣を退け、第一原理を掲げた。しかし1年の研究（§9.3.56、§9.3.104、NR-1）で、普遍的生理（Layer 1）と文化的選好・聴取履歴（Layer 3）は別層であることが明確になった。

- **選択肢 A（三層モデルをマニフェストへ昇格）**：音楽の根拠を ①普遍的聴覚生理（Layer 1：粗さ・融合・順応）、②聴き手の文化と選好の座標（Layer 3：作曲者が選ぶ重み・親しみ）、③生態系と身体の力学、の三つに明快に分けて記述する。「模倣しない」のは既存の楽曲・和声進行のコピーであり、文化や聴取履歴という層の存在自体は否定しない（§9.3.134 の作者判断「文化は履歴と考えれば否定しない」と整合）。
- **選択肢 B（純粋な生理原理主義に留める）**：文化層には踏み込まず、感覚原理の限界をそのまま受け入れる。
- **推奨**：**選択肢 A**。この1年で獲得した最大の理論的成果（Principle / Candidate / Author rule と聴き手5層）を、専門用語を噛み砕いた宣言の言葉でマニフェストに反映する。

### 論点 3：「響き（身体・テクスチャ・空間）」を第三の柱にするか
初版は「周波数軸（ピッチと和声）」と「時間軸（リズムとグルーヴ）」の二軸構成だった。

- **選択肢 A（三軸または「身体と空間」節を新設）**：周波数（和声）・時間（リズムと流れ）に加え、**響き（身体の共鳴・統計的テクスチャ・共有空間）**を独立の柱として位置づける。Flora（場としての植生）・Rain（統計的テクスチャと共鳴体）・共有の部屋（物理空間）という1年の発見が自然に収まる。
- **選択肢 B（既存の二軸の中に吸収して記述）**：二軸のまま「身体」節を少し加筆する。
- **推奨**：**選択肢 A**。物理的な振動現象（身体と空間）× 聴覚認知（周波数と時間）という冒頭の一文（「音楽とは、物理的な振動現象と、それを受け取る人間の認知システムとの間に生じる相互作用の劇である」）とも最も美しく響き合う。

### 論点 4：作曲者（Author rule・シナリオ）の役割をどう書き切るか
1年の実践で、最も音楽的な手応えを生んだのは、すべてを自動生成することではなく**「聴覚原理（地形）の上で、作曲者が住人の性向・環境条件・時間の大弧を設計すること」**だった。

- **選択肢 A（「原理の敗北」ではなく「新しい楽器のかたち」として肯定する）**：すべてを自動化するのではなく、**人間の聴覚原理に根差した生態系という楽器を、作曲者が演出・調律する共創**こそが Conchordal の実践形であることを明確に書く。
- **選択肢 B（完全自律の創発を最終目標として維持し、現行のシナリオは過渡期と書く）**。
- **推奨**：**選択肢 A**。初版がすでに書いた「作曲者はマイクロマネージャーではなく生態系の演出家」という名表現を、1年の実感に裏打ちされた中心命題へ引き上げる。

### 論点 5：文体・射程・現状注記の整理（引き算）
- **時間軸節の「2026年9月時点の実装では…」および旧4帯域表**：実装の到達点と監査は `technote`／`architecture-current.md` へ完全に移し、マニフェストから実務報告書的な注記を抜く（4帯域の初期案も削るか、歴史的一文に留める）。
- **生体信号フィードバック・役割の溶解・他芸術（視覚／文学／建築）への射程**：
  - 選択肢 A：「長期的な地平（Horizon）」として1節にコンパクトにまとめ、本体の音楽論の密度を上げる。
  - 選択肢 B：初版の分量を維持する。
  - **推奨**：**選択肢 A**。1年目の実績（実際に鳴っている楽器・ブラウザー演奏・音響生態系）を厚くし、遠い未来予想は簡潔に締めた方がマニフェストとしての説得力が増す。

## 2. 現行マニフェスト（`manifesto.ja.md`）節ごとの改訂方針案

| 現行の節 | 方針 | メモ |
|---|---|---|
| 冒頭宣言 | **維持・微調整** | 冒頭1文は極めて強い。「自律エージェントが調和を見つける」に加え「響きの場」のニュアンスを少し補う |
| 調和の探求：ピタゴラスから現代へ | **維持（圧縮可）** | 歴史的系譜として完成度が高い。AI 批判の段に「模倣の拒否と、認知的経験（文化）の違い」への橋渡しを1文足す |
| 直接認知結合 | **改訂（中核）** | 三層（普遍生理／文化・選好／生態の力学）を平易に導入。生体閉ループと役割の溶解は「地平」へ整理 |
| 音楽の認知的ランドスケープ（周波数軸／時間軸） | **大幅改訂** | 4帯域表と2026年9月の実装注記を削除。**「響き（身体・テクスチャ・空間）」**を加え、「協和の引力」と「動き（離れて戻る問い）」の対比を明記 |
| 音響生命の創発 | **改訂** | 個体（Voice）・群集（Population）だけでなく、場として育つ植生（Flora）や分布のテクスチャ（Rain）を含む「多様な住人が音だけで結びつく生態系」へ拡張 |
| シナリオ：時間に形を与える | **維持・強化** | 有限作品と終端のない生態系に加え、作曲者の能動的な設計（環境・性向・空間）を積極的に位置づける |
| 直接認知結合の射程 | **圧縮** | 視覚・文学・建築の一般化は「長期的な射程」として簡潔にまとめる |
| 終わりに | **更新** | 公開1周年（2026-12-25）の到達点と、これから解く問い（「動き・時間・響き」）で締める |
