## 実装と再実行

`scripts/evaluate_phrase_expectation.py`は研究用PCM16音源と採点用の正解を別々に保存する。
観測器は保存したWAVを読み直し、サンプル列だけを受け取る。正解の周波数、発音時刻、
cycle番号、評価区間、将来イベントを観測器・予測器へ渡さない。
正解情報は観測の照合と評価区間の集計にだけ使う。

PythonとNumPyを使う。今回のNumPyは2.3.5。既存の環境に追加する場合は、専用venvを使う。

```bash
python3 -m venv /tmp/conchordal-phrase-venv
/tmp/conchordal-phrase-venv/bin/python -m pip install 'numpy>=2,<3'
/tmp/conchordal-phrase-venv/bin/python scripts/evaluate_phrase_expectation.py \
  --output target/phrase-expectation/new-run --change-rule pooled
```

既存の出力先は上書きしない。実行済みの最終出力は
`target/phrase-expectation/2026-09-06-contour-verified/`。
`manifest.json`に条件、モデルの数値設定、Python・NumPy版、ソースと成果物のhashを保存した。
各条件はWAV、正解、音声観測、予測と誤差を持つ。`validation.json`が照合結果、
`assessment.json`が要約、`audition.html`が試聴入口となる。

## 刺激と観測の範囲

24 kHz、mono、PCM16。1音0.22秒、標準の発音間隔0.36秒で、音は重ならない。
8音の連続周波数の輪郭を6回反復してから、後半4回を評価する。標準条件の切替時刻は17.88秒。
seed 1・21・42と、数値設定を変えず比較した別の輪郭seed 7・57・113を使う。
全6 seedで次の10条件、計60音源を用意した。

| 条件 | 操作 |
|---|---|
| repeat | 同じ輪郭を続ける |
| altered | 後半の各輪郭で隣接する2音を入れ替え、その変更した輪郭を反復する |
| shuffled | 後半は輪郭ごとに音の順序を並べ替える |
| transposed | 後半で全体を0.37オクターブ上げる |
| timbre | 後半でsineから3倍音の音へ変える。定常音のRMSを揃える係数を使う |
| quieter | 後半で振幅を0.25から0.12へ落とす |
| pause | 後半の途中へ1.2秒の休止を入れ、同じ輪郭を再開する |
| renewal | 初めから音の順序と発音間隔を不規則にする |
| noise | 同じ発音時刻・包絡で雑音を鳴らす |
| silence | 全無音 |

A・B・Cに使うrepeat・altered・shuffledでは、発音時刻、振幅、音長、音色と
各輪郭内の音高集合を揃える。採点に使う音程変化そのものの分布は並べ替えで変わるため、
予測の対照も同じ過去の音程変化を観測する。音高集合の一致だけで対照が十分とは扱わない。

音声観測は10 msごとの振幅から発音の始まりを検出し、過去2048サンプルの正規化した
自己相関のピークから周期を求める。100〜1200 Hzを探索し、周期性0.9未満は採用しない。
3回の観測が30 cent以内で安定してから音高を報告する。これは分離した周期音の研究用観測であり、
重なった声部、持続中の音高変化、雑音的な音色の一般的な音高推定ではない。

48条件の周期音3840音をすべて対応付け、最大の音高誤差は0.492 cent未満、
音高を確定するまでの遅れは最大約112 msだった。雑音480音は発音を検出したが、
音高は全て観測不能とした。全無音では架空の音を報告しなかった。
これは既知の合成刺激との照合であり、人間の音高知覚との一致率ではない。

## 予測の契約

対象は連続量の音程変化`log2(f_next / f_previous)`。直前2音程に似た過去の文脈から、
次の音程の密度を予測する。対照は同じ過去の音程を、順序の条件付けなしで予測する。
どちらも最大128件の履歴と同じ幅のGaussianを使い、広い共通の事前分布を混ぜる。
文脈の支持が少ない場合は対照へ戻す。音名・音階・拍子・phraseラベルは渡さない。

毎回、現在の音高を見る前に予測密度を決め、観測後に採点してから履歴を更新する。
前半は立ち上がりの区間、後半は次の未観測イベントへの評価区間であり、
後半も過去になった観測から更新する。凍結したモデルによる一括評価ではない。
音高不明の音を挟んだ場合は、その前後を直接つなぐ音程を作らない。

評価値は同じ観測音程に対する`log2(文脈付き密度 / 対照密度)`の平均、単位はbit/event。
密度比の予測利得であり、聴き手の確信度・楽しさ・終止感の値ではない。
研究スクリプト全体は音声やレポートを保持するため、予測モデルの履歴上限を
そのまま本番のメモリ・RT保証へ読み替えない。

## 結果

| 条件 | 6 seedの平均予測利得の範囲（bit/event） |
|---|---:|
| 同じ輪郭 | 1.338〜2.275 |
| 一部を入れ替えた輪郭の反復 | 1.551〜1.894 |
| 順序を崩す | −0.051〜0.034 |
| 移調 | 1.230〜2.035 |
| 音色変更 | 1.338〜2.275 |
| 減音 | 1.338〜2.275 |
| 休止して再開 | 1.338〜2.275 |
| 不規則な順序・発音間隔 | −0.053〜0.142 |

音色・音量だけを変える条件でも利得はほぼ同じだった。途中の移調では、その境界を跨ぐ
最初の音程自体が変わるため、全区間の完全一致は求めない。系列全体を移調する場合の
予測不変性は、別の回帰テストで確認した。

この比較では、反復する音程の順序を記憶する観測対象に利点があった。
一方、変更後の輪郭も繰り返せば予測できる。平均利得は変化の場所を示さず、
一部変更の利得が元の輪郭より高いseedもある。8音のphrase全体の表現や、
まとまりの認知が成立した結果ではなく、直前2音程による条件付けの結果である。

過去の予測損失の95%点＋2 bitを超えるものを変化候補とする初期判定は、
altered・shuffledとも6 seed中1つでしか候補を出さなかった。立ち上がりの大きい誤差も
履歴に含めるこの判定では、変化時点の検出を合格にできない。結果を見て閾値を下げ、
同じseedを未使用の検証として再利用することはしない。

休止候補は、直近の発音間隔の中央値の2.5倍が無音で経過した時点で報告する。
途中で再開する音源と、同じ無音の途中でファイルを切った音源は、共通する過去から同じ候補を出す。
ファイルの終端を終止の正解として予測器へ教えない。休止検出から「ここで終わった」は導けない。

## 学習済みの文脈で誤差を較正する

作者の回答後、既存の開発用seed 1・21・42で見逃しを調べた。最初の変更に対する損失は
3.46〜5.31 bitだったが、判定閾値は7.27〜7.41 bitだった。閾値を押し上げた上位の誤差は、
類似した文脈の支持がほぼ0だった学習初期の音に由来した。何も知らない段階の誤差と、
既に学んだ予測からの逸脱を同じ集合で較正していた。

`--change-rule supported`では、予測する時点で類似文脈の支持が2以上ある場合だけ、
その後に観測する損失を較正履歴へ加える。現在の候補判定にも同じ支持条件を要求する。
支持は文脈類似度のkernelの総和であり、人間に必要な反復回数を表す値ではない。
95%点＋2 bit、最小16件、最大128件という較正の式・履歴上限は保つ。
予測密度そのもの、Gaussianの幅、事前分布、音高観測器、音源生成は変更しない。
未知の文脈では、学習済みの予測への違反を主張せず、観測からの学習は続ける。
旧方式は`--change-rule pooled`で比較でき、研究ツールの既定値はsupportedとする。

未使用のseed 181・263・419と検出・誤検出の条件を、測定前に`plan.json`へ保存した。
実装と検証コードの写し・hashも測定前に固定した。開発用30条件の後、未使用の3 seedで
旧較正／新較正×10条件を比較し、合計90条件を実行した。
出力先は`target/phrase-expectation/2026-09-06-supported-calibration/`。

```bash
python3 scripts/evaluate_phrase_expectation.py \
  --output target/phrase-expectation/new-supported \
  --seeds 181 263 419 --validation-seeds 181 263 419 --change-rule supported
python3 scripts/evaluate_phrase_expectation.py \
  --output target/phrase-expectation/new-pooled \
  --seeds 181 263 419 --validation-seeds 181 263 419 --change-rule pooled
```

|---|---|---|
| 181 | 最初の変更音、約0.11秒後 | 最初の変更音、約0.11秒後 |
| 263 | 最初の変更音、約0.11秒後 | 変更後の3音目、約0.83秒後 |
| 419 | 最初の変更音、約0.11秒後 | 最初の変更音、約0.11秒後 |

雑音・無音にも音程の変化候補を出さず、今回の不規則入力3条件での候補も0だった。
途中の移調は、新しい音程が生じる最初の音で候補が出た。

## 混合音の周期性と、音声欠落の扱い

現行の短いlagでの自己相関は、220 Hzと233 Hzの等振幅の混合を約226.7 Hzとして受理した。
自己相関のピークは約0.98でも、その周波数を出している独立した音源はない。
220 Hzと約311.1 Hzの混合も約105.7 Hzとして受理した。ピークの高さを、
一つのVoiceの音高を同定した確信度と解釈してはいけない。

研究用の`--coherence-check`を追加した。推定周期の整数倍の位置で、窓の半分まで
自己相関の整合を調べる。全て0.9以上の場合だけ受理し、各位置の局所ピークを補間して
得た周期の中央値で周波数を推定する。観測窓は従来どおり2048 sample / 24 kHzであり、
未来の窓を加えない。3回連続した安定観測、音程予測、較正の設定は保つ。
このオプションの出力は波形の周期性であり、音源数やVoiceの識別ではない。
指定なしでは従来の観測式を使う。

検査用の実行経路を`AcousticObserver.process(start_sample, audio)`へ移した。
入力chunkの大きさと無関係な240 sampleの格子で処理し、未完のhopやファイル末尾から
イベントを作らない。sample indexの正方向の飛びを`input_gap`として報告し、
音声窓・発音間隔・短い文脈を切る。欠落期間をゼロで埋めない。再接続時に既に鳴っている音は
開始を観測できないため、実際の静穏を2 hop確認してから次の発音を受け付ける。
`predict_notes(..., input_gaps=...)`も欠落をまたぐ音程を採点しない。
過去の学習履歴は保持するが、欠落前後を新しい遷移として学習しない。
逆順・重複のsample indexと非有限入力はエラーにする。

## ListenerTwinへの受動接続と、通常sampleでの限界

`src/listener_twin/contour.rs`へ観測器と短い音程の予測器を移し、`--report`時に有効にした。
入力はrender後のpresentation音声とsample indexだけである。生成側のVoice ID、
Scenarioの予定、発音指令、音高を渡さない。既存のListenerStateやDCCの圧力へ値を戻さず、
独立した`listener_contour`レコードとして報告する。レポートを使わない演奏では観測器を構築しない。

| フィールド | 意味 |
|---|---|
| `event` | `periodic_episode`、`unresolved_episode`、`silence_gap`、`input_gap` |
| `time_sec` | 証拠を利用できたsample時刻。約10 msの内部格子で処理し、将来の音声は読まない |
| `generated_frame_id` | その観測を出したpresentation hop。遅延したLandscapeのframeではない |
| `onset_sec` | エネルギーで区切った音響区間の開始。`silence_gap`では直前の区間の開始、`input_gap`ではnull |
| `periodic_frequency_hz` / `periodicity` | 利用可能になった時点の波形周期性。Voiceの音高や、その区間全体で持続した音高の主張ではない |
| `delta_log2` / `gain_bits` / `loss_bits` | 直前の利用可能な観測との音程、順序なしの対照に対する利得、条件付き密度の損失。採点できない場合はnull |
| `context_support` / `calibration_events` / `error_threshold_bits` | 観測前の文脈と較正履歴による基準。人間の確信度ではない |
| `error_candidate` | 較正済みの局所的な予測への逸脱候補。phrase境界や終止ではない |
| `gap_threshold_sec` / `missing_start_sec` | 実音の静穏を扱う閾値と、欠落開始時刻。静穏と欠落を混同しない |

周波数が取得できた時点は、区間開始から大きく遅れる場合がある。`onset_sec`から
`time_sec`まで同じ音高が鳴っていたとは解釈しない。また、レコードを次のレコードまで
現在の音高として保持する契約ではない。入力欠落の直後に鳴っている音は開始を観測できないため、
静穏を確認してから次の区間を受け付ける。欠落をまたぐ音程は作らない。

Rustのメモリ確保・再確保は0件だった。これは観測器自身の検査であり、既存のworker、

### 比較した予測対象

`scripts/evaluate_spectral_expectation.py`へ、実音の周波数分布を使う研究用比較を実装した。
**対象は次の相対的な周波数分布であり、音源の音高や分離された旋律ではない。**
既存の音程観測を置き換えた実装ではなく、別の候補の比較である。

- 55〜7040 Hzを48 bins/octのLog2Spaceと同じ格子へ対応させ、Hann窓を通したFFTの
  powerを近隣のbinへ質量として配分し、総和1に正規化する。これは研究用FFT特徴であり、
  runtimeのNSGTやH/R/Cの推定と同一ではない。
- 約85.3 msの後方窓を120 ms刻みで読む。観測窓は重ならず、次の採点窓は予測時点より後に始まる。
  この格子は計測の間隔であり、生成側の拍・発音時計へは接続しない。
- 直前の分布のlog周波数重心を基準に、次の分布を相対位置へ写す。

  結果として、無音を挟む旧単旋律刺激では採点が成立しない場合がある。

人間の驚きのbitsとは同一視しない。観測数や履歴平均に対する改善だけで順序記憶を採用しない。

## 2026-09-07：局所的な揺れと持続する音響状態の比較

`scripts/evaluate_acoustic_state.py`を追加した。実音の周波数分布を20枚ずつ、隣接する

  離れた音域へ動く量を保つ。音高の同定や音源分離を行った値ではない。

一方、集合間の距離は集合内の音の順序を捨てる。順序だけが変わる対照に候補が出ない結果を、
順序の認識や旋律の理解とは呼ばない。短い軌跡を残すブロック較正も、旋律の表現ではない。

## 2026-09-07：成分間の時間関係の観測

### 観測する対象

`scripts/evaluate_component_relations.py`を研究用に追加した。既存の周波数成分の観測から、
帯域間の振幅変調の関係を取り出す。Voiceの識別子、音源数、旋律やphraseの正解は入力しない。
成分のエネルギー上昇の時刻も捨てない。作者が聞いた間隔順序のA/Bは単一帯域の並びであり、
帯域間の相関だけでは表現できない。今回の観測は、その置き換えではなく補助である。

成分のパワーを55〜7040 Hz、1 octave当たり16 bin、計113 binのlog2周波数格子へ投影する。
Gaussianの幅は0.075 octaveで、各成分のパワー総量を保つ。振幅の40 msと200 msの因果フィルタの
差を変調特徴とし、直近200フレーム・2秒の共分散を求める。入力は10 msごと、報告は100 msごと。
平均パワーの局所的な峰のうち、占有率10%以上、変調の標準偏差が絶対値0.001と平均振幅の3%の
両方以上のものを選ぶ。最大32帯域の全組について符号付き相関を報告する。

一定の持続音にはエネルギーがあっても、変調の相関を計算する証拠がない。
`no_modulated_pair`は関係なし・無音・独立を意味しない。エネルギーを持つ峰の数も別に報告する。
入力欠落や観測時刻の不連続では状態を初期化し、再び完全な窓を待つ。
観測開始時点で鳴っている音から、架空の立ち上がりを作らない。
フィルタは過去の連続区間に依存するため、証拠の開始時刻を直近2秒へ切り詰めない。
状態は有界だがPythonの収集用配列は音源長とともに増え、本番の処理予算を検証した実装ではない。

1. どの聴覚認知現象をモデル化するかを定める。
2. その現象に必要な表現、保持、干渉、更新、まとまり、時間尺度について、実験知見が制約する範囲を示す。
3. 制約を満たす数学モデルを選び、未同定の自由度と対立するモデルを残す。

5. 認知上の対照と生成時の作用を検証する。予測成績だけで音楽的な単位やDCCへの整合を確定しない。
