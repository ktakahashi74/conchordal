## 1. 判定

**作者が方針を判断する材料としては、条件付きで利用できる状態です。採用(A4)の段階にはまだありません。**

契約草案は、計画の Task 2 が挙げる15問すべてに、推奨する挙動と検査を対応させています。また、次の点を一貫して区別しています。

- 代表描画を正本とすること
- 既存の F2 許容差(score 0.025、level 0.0125、旧 gap 0.1 以上での厳密な順位逆転 0)と、過去の失敗記録を保持すること
- 新たに提案する許容差と、作者・所有者の決定を分けること

引用された数値は、同梱の結果文書と照合した範囲で整合していました。確認したのは、v1 の 157/728、v2 の 159/728、anchor 介入の 93/728(159 − 85 + 19)、最大誤差 0.5726536512/0.2675193250、345 対中 4 逆転です。

ただし、A1(音高・構造変更の意味)を作者が判断する前に、pitch Update がどの Tone に作用するのかを定義する必要があります(所見1)。また、A4 と Phase 3 の開始条件に含まれる「合意済みの F2 表現」は、既存の近道候補(v1、v2、anchor 介入)がすべて描画照合に不合格である現状で何を意味するのかが未定義です(所見7)。

anchor 介入の精度条件は不合格で、全 suite 回帰も未解決の失敗を残しています。本レビューは、全域で成立する高速モデルの実現可能性について判断していません。

## 2. 実質的所見

区分の意味は次のとおりです。

- **欠陥:** 文書内の矛盾、未定義、記載誤り
- **作者提案:** 数値や方針の選択そのもの。値の妥当性は判定せず、内部整合だけを見ています。

### 所見1 — pitch Update が作用する Tone の範囲が未定義

- **重大度:** 高(A1 判断の前に解消が必要)
- **区分:** 欠陥
- **場所:** contract 71行、97–99行、146–155行、156–164行、653行(A1)/timbre.md 149–151行

pitch Update は「既存 Tone をその場で再調律する」とされています。一方で、Off 後の Tone は「自由状態を保持する」とされ、新しい On はそれぞれ別の Tone として扱われます。この組み合わせでは、次の問いに答えられません。

- 同じ source に保持されている Off 済み Tone や、過去の On の Tone にも pitch Update は作用するのか。
- 作用するなら、自由応答が Off 後に外部から変更されることになる。
- 作用しないなら、timbre.md が問題視している「一個体が二つの音高を鳴らす」状態が通常の発音ごとに残る。

表の「繰り返しの pitch Update で状態数が有界」という利点も、どちらの解釈を採るかで意味が変わります。

**最小修正:** pitch Update の対象(励振中の handle のみか、source の全 Tone か)と、Off 済み Tone の扱いを command 表に一行で追加してください。あわせて、発声ごとの音高移動を「On/Off の列」として lowering するのか、「Update」として lowering するのかも明記してください。

### 所見2 — Off 時点での係数の不連続が未定義

- **重大度:** 中
- **区分:** 欠陥
- **場所:** contract 181–186行(motion の Hz offset)、118–121行(Harmonic の励振依存 damping)、97行

Off 後、組み込み身体は「offset の加算をやめ、位相と振幅を保ったまま指令係数・自由係数で鳴る」とされています。しかし `motion` は最大で約 24.5 cents RMS の周波数 offset です。これを Off 時点で即座に外すと、瞬時周波数に段差が生じます。

同様に、Harmonic のスペクトル damping は励振強度に依存するため、drive が 0 になった瞬間に自由応答のスペクトル均衡が跳ぶかどうかが決まっていません。

**最小修正:** Off 時点で offset と damping を「凍結する」「規定の ramp で戻す」「即時に外す」のいずれにするかを A2 の選択肢として明記してください。あわせて、その選択を検査する項目を 72 行の検査欄に加えてください。

### 所見3 — 複数 Tone 間の乱数の共有と、合成(merge)の条件が不足

- **重大度:** 中
- **区分:** 欠陥
- **場所:** contract 124–125行、156–158行、173–176行

揺らぎの駆動は「Tone ごとではなく source clock の一歩ごとに一度進める」とされています。しかし、Modal の雑音励振のように重なり合う Tone が同じ乱数列を使うのか、Tone ごとの独立した substream を使うのかは書かれていません。共有すれば、雑音が相関して干渉の仕方と実測費用が変わります。

また、merge の条件には「初期状態・位相の一致」がありません。Tone の初期化乱数は別の substream から取られるため、発振器身体では merge の前提が崩れます。

**最小修正:** 雑音励振の乱数を共有するか Tone ごとに独立させるかを明示してください。merge の条件には「同一の初期位相・状態の基準」を追加してください。

### 所見4 — 確率的な身体でのエネルギー照合の参照が未定義

- **重大度:** 中
- **区分:** 欠陥(許容差の値そのものは作者提案)
- **場所:** contract 342–344行、349–352行/B5 569–574行

窓ごとの基準 `1e-10 + 0.001·|rendered|` は、特定の seed による一回の描画実現値との比較になっています。雑音励振を持つ Modal について、期待値として予測する self-model はこの基準をほぼ満たせません。基準が参照するのが「固定乱数の実現値」なのか「アンサンブルの期待値」なのかが定義されていないため、近道が構造的に不可能になるのか、それとも別の基準が必要なのかが決まりません。

**最小修正:** 各消費者の行に、参照量の種類(実現値か期待値か)を追加してください。B5 に従い、その決定は消費者の所有者と作者に委ねてください。

### 所見5 — 標本化率に対する不変性が Sine/Harmonic 以外で未定義

- **重大度:** 中
- **区分:** 欠陥
- **場所:** contract 69行、110–117行、123–126行

「標本化率を変えても drive の持続時間と定常の意味が保たれる」という検査は、Sine/Harmonic の一次再帰式でしか成立根拠が示されていません。Modal の雑音 drive や kick のインパルスは、標本ごとの値のままだと標本化率によってエネルギーが変わります。

加えて、「drive amplitude per sample」という表現は、標本単位の量であるかのように読めてしまいます。

**最小修正:** 不変性の要件を「身体の能力領域として宣言する」形に改め、宣言のない身体は unsupported とする一文を加えてください。表現は「標本時刻で指定される無次元レベル」に改めてください。

### 所見6 — 容量16 Tone/source と、長い減衰・発声頻度の関係が未検討

- **重大度:** 中
- **区分:** 作者提案 A3 に付随する欠陥
- **場所:** contract 163–165行、271–279行、291–293行、300–303行

新しい On は新しい Tone slot を消費します。一方、廃棄できるのは残響が 1e-6 を下回るか、60 秒の上限に達したときだけです。そのため、減衰の長い Modal が短い間隔で発声すると、通常の onset が拒否され、それが「資源条件の失敗」になり得ます。

また、どの発声を「既存 Tone への再 kick」として lowering し、どれを新しい On にするかが決まっていないため、この負荷は見積もれません。

**最小修正:** A3 に「許容する最長減衰 × 最大発声頻度 ≤ 16」という整合条件を加えるか、発声の lowering 規則を Phase 3 の登録事項として明記してください。

### 所見7 — 「合意済み F2 表現」と、暫定期間の runtime 挙動が不明確

- **重大度:** 中〜高(A4 と Phase 3 開始の判断に直結)
- **区分:** 欠陥
- **場所:** contract 287–289行、348行、438行(B3)、671–673行/plan 59行、390–393行

現時点で描画照合に合格した近道はありません。契約の規則に従うと、組み込み身体を含むすべての身体が runtime では「offline 優先」となり、身体評価による同じ hop 内の出生は unsupported になります。

しかし契約は、Phase 3 の開始条件として「合意済みの F2 表現」を挙げています。それが「描画参照のみで、承認された近道はない」状態でも満たされるのかが分かりません。さらに、その間の runtime が既存の点評価(既定の OFF)を維持するのかも書かれていません。本レビューは、全域で成立する高速モデルの実現可能性を前提にしません。

**最小修正:** Phase 3 の移行は高速 F2 経路を前提にしないこと、身体評価の runtime 消費者は承認まで無効のままにすること、既定動作は変えないことを明記してください。そのうえで、「合意済み F2 表現」の最低要件(要求 identity と証拠の形式、など)を定義してください。

### 所見8 — 費用の基準と、誰が支払うのかが未定義

- **重大度:** 中
- **区分:** 欠陥
- **場所:** contract 130–133行/timbre.md 234–237行/plan 394行

「実費用は放射音から計算し、保持中の tail と habitat gain を含む」とされていますが、次の点が定められていません。

- presentation 専用の放射を費用に含めるのか。
- Voice の死亡後に鳴り続ける tail の費用を、どの個体が負担するのか。

**最小修正:** 費用の基準(habitat 送出分に限るのか)と、死亡後の tail の扱い(費用に計上しないのか、親や source の世代に帰属させるのか)を A3 か A2 の判断事項として追加してください。

### 所見9 — Off の要求時刻と実効時刻の順序規則が曖昧

- **重大度:** 低
- **区分:** 欠陥
- **場所:** contract 87–88行、97行、102–106行

release ramp がある場合、要求時刻と実効時刻は別になります。同じ tick 内での順序規則(close → update → On)が、どちらの時刻に適用されるのかを明記してください。

### 所見10 — 状態を移せない身体での pitch 変更の扱いが未定義

- **重大度:** 低
- **区分:** 欠陥
- **場所:** contract 99行、151–152行

状態移転を unsupported と宣言した身体について、音高移動の要求が来たときに core 側がどう振る舞うのか(次の On まで保留するのか、移動を不可とするのか)を定義してください。capability を読んで分岐するのであれば、「身体の種類で分岐しない」という規則とも両立します。

### 所見11 — 全 suite の失敗回数の記載誤り

## 3. A1–A4 の判断準備状況

**A1(音高・構造変更の意味): 条件付きで判断可能。**
状態移転と構造世代の区別は明確で、三つの代替案の比較も妥当です。ただし、所見1の作用範囲が決まらないと、「状態数が有界」「単音性は要求しない」という帰結を評価できません。

**A2(Sine/Harmonic の drive と自由応答、揺らぎの所有): 判断可能。ただし付帯選択を追加すべき。**
T60 0.5 秒と一次再帰式は、内部で整合しています。定常振幅は drive と等しく、標本化率にも依存しません。なお、時定数は約 72 ms になるため、鋭い立ち上がりは kick に依存する点を作者は認識しておくべきです。所見2・3・5の選択を A2 に含めてください。これは試聴の結果ではなく、Task 1 の水準判断とも独立している、という記載は正確です。

**A3(資源と退役): 提案として判断可能。**
64/16/576、queue 16、60 秒上限、5 ms fade、1e-6 境界はいずれも作者提案です。これらが音声の期限を満たすと主張していない点は適切です。所見6・8の整合条件を加えたうえで判断してください。renderer の数値的な予算配分を Phase 3 の登録に委ねる点は、B3・B4 と整合しています。

**A4(完成した契約の採用): 未準備。**
採用の前提として、少なくとも次が必要です。

- 本レビューの所見に対する処置の記録
- A1–A3 の作者決定。A4 の記述自体が、A1–A3 の決定を採用の前提とするかどうかを明記すべきです。
- B5 に基づく、追加許容差についての消費者所有者と作者の合意
- 所見7の開始条件の定義

anchor 介入の精度不合格と全 suite 回帰の失敗は、契約そのものの欠陥ではありません。ただし、F2 表現が未決定であることの根拠として残ります。Phase 3 の開始は、本レビューによって許可されるものではありません。
